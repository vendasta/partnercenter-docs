## Project Overview

This is the Partner Center documentation site for Vendasta, built with **Docusaurus 3.8.1**. The site is published at `https://docs.vendasta.com`.

## Development Commands

All commands run from the `docusaurus/` directory:

```bash
cd docusaurus
npm install          # Install dependencies
npm run start        # Local dev server at http://localhost:3000
npm run build        # Generate static site to build/
npm run typecheck    # TypeScript type checking
npm run clear        # Clear Docusaurus cache
npm run serve        # Serve built site locally
```

Node.js >= 18.0 required.

## Architecture

### Content Structure

- **All documentation lives in `docusaurus/docs/`** organized by product area
- Uses **file-system based autogenerated sidebars** - folder structure determines navigation
- Each folder can have `_category_.json` to customize label, position, and collapse state
- Landing pages use `index.mdx` files within their category folder

### Key Configuration Files

| File | Purpose |
|------|---------|
| `docusaurus/docusaurus.config.ts` | Main site config, redirects, plugins |
| `docusaurus/sidebars.ts` | Sidebar configuration (uses autogenerated) |
| `docusaurus/src/components/` | Custom React components (Cards, PageActions, Icons) |
| `docusaurus/src/theme/` | Theme overrides (MDXComponents, TOC, Root) |

### Redirects

URL redirects are managed in `docusaurus.config.ts` via `@docusaurus/plugin-client-redirects`. When moving or renaming pages, add a redirect to preserve links:

```ts
{ from: '/old/path', to: '/new/path' }
```

## Content Guidelines

### Markdown Rules

- **CRITICAL: Never use `>` character in markdown** - creates unintended blockquotes. Use "greater than" in text or `→` for UI paths
- Use Docusaurus callouts: `:::tip`, `:::info`, `:::warning` (not blockquotes)
- Sentence case headings: `## Set up a domain`
- **Bold** for UI elements, `code` for commands and filenames

### Frontmatter

```yaml
---
id: file-name
title: Page title
sidebar_position: 1
description: Short description
---
```

### Category Configuration

Use `_category_.json` in folders to customize sidebar:
```json
{
  "label": "Display Name",
  "position": 5,
  "collapsed": true,
  "link": { "type": "doc", "id": "folder/index" }
}
```

Link categories to actual overview documents - avoid generated-index pages.

### Details/Summary Formatting

Place `<details>` tags on own lines with blank lines around content:
```markdown
<details>
<summary>Title</summary>

Content here with blank line above.

</details>
```

### Media

- **Images go in an `img/` folder alongside the documentation files** (not in `static/img/`)
- Use relative paths: `![Alt text](./img/image-name.png)`
- Example structure:
  ```
  docs/section/feature/
  ├── index.mdx
  ├── settings.mdx
  └── img/
      ├── settings-screenshot.png
      └── feature-diagram.png
  ```
- Always include alt text describing image purpose
- Blur or replace sensitive data (PII) in screenshots
