## A presentation is not a recap

A summary of everything you found is an audit, and nobody signs an audit. A presentation points forward: here is the future state we are taking you to, here is what we will hold ourselves to, and here is the strategy that gets you there. It also has to work on people who are not in the room, and it is a conversation throughout, not a speech you deliver and then stop.

Five stages do that, always in the same order. Expand each one:

<Accordion
  items={[
    {
      id: 'insight',
      title: 'Open with insights, not with what you sell',
      badge: '1',
      content: (
        <>
          <p>Start with the specific things the prospect told you. If a landscaping owner said half her quote requests never get followed up, that line opens the meeting:</p>
          <p><em>"You told me last week that quote requests go cold if nobody follows up within a day. That's the first thing we built this plan around."</em></p>
          <p>A generic opener sounds like every rep before you. A specific callback sounds like a plan built for this prospect, because it is.</p>
        </>
      )
    },
    {
      id: 'strategy',
      title: 'Give the strategy at ten thousand feet',
      badge: '2',
      content: (
        <>
          <p>Keep this at the level of outcomes. "We'll set up automated follow-up on every quote request within one hour" is a strategy. "We'll configure a CRM automation with a conditional trigger on lead status" is a feature tour.</p>
          <p>The test: if the sentence describes a click path, it belongs in the appendix. If it describes a change the owner will notice, it belongs here.</p>
        </>
      )
    },
    {
      id: 'performance',
      title: 'Put measurement on the table early',
      badge: '3',
      content: (
        <>
          <p>Every owner is running the same math: will this pay for itself. Answer it before they ask, rather than leaving it for after the sale.</p>
          <p><em>"We'll track quote-to-close rate monthly, and I'll show you the before-and-after myself. If follow-up is really costing you jobs, you'll see it move within the first month."</em></p>
          <p>Naming how you measure it, and when you show up with the number, turns "trust me" into something the owner can check.</p>
        </>
      )
    },
    {
      id: 'tactics-ask',
      title: 'Then the tactics, and the ask',
      badge: '4',
      content: (
        <>
          <p>Now the detail and the price, only as deep as the prospect leads you. This is also where the ask lives: for the business, out loud, in the room, not in a follow-up email.</p>
          <p><em>"That's the plan: automated follow-up, a monthly report on quote-to-close, and I'll be your point of contact the whole way. Can we get you started this week?"</em></p>
          <p>Confidence here is not volume. It is not softening the ask into a question about whether you should be asking.</p>
        </>
      )
    },
    {
      id: 'appendix',
      title: 'Park the rest in the appendix',
      badge: '5',
      content: (
        <>
          <p>If a capability might matter to this prospect but you are not certain, do not build the pitch around a maybe and do not cut it either. Put it at the back and say that it is there.</p>
          <p><em>"There's a webchat feature that might be a fit for you too. I've put a page on it at the back in case you want to look at it, but I didn't want to build our whole conversation around something you haven't seen yet."</em></p>
          <p>The main pitch stays tight, and a curious owner can still go looking.</p>
        </>
      )
    }
  ]}
/>

:::tip Try it now
Write one sentence for each stage for your next prospect: the insight you heard, the strategy, how you will prove it worked, the ask, and what goes in the appendix. Say the ask out loud beforehand. If it sounds like a question about whether you should be asking, rewrite it.
:::
