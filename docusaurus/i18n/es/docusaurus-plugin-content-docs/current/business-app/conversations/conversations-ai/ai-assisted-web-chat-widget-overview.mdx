El AI-assisted Web Chat Widget es una herramienta de servicio conversacional en **Conversations AI** (incluida en todas las ediciones: Standard, Pro, y Premium) que ayuda a tus clientes a proporcionar un servicio al cliente oportuno. Permite que tus clientes estén disponibles para sus clientes más allá del horario de negocio con la asistencia de IA.

:::tip
¿Tienes una marca o franquicia con un sitio web que cubre varias ubicaciones? Consulta el [widget de chat web multiubicación](/multi-location-business-app/conversations/multi-location-web-chat), que permite a los visitantes elegir una ubicación y conversar con el AI Chat Receptionist propio de esa ubicación.
:::

## Funciones del widget de chat web

### Disponibilidad 24/7 con IA
- Responde preguntas de clientes fuera del horario de negocio
- Usa IA para entender y responder consultas
- Gestiona eficazmente las preguntas frecuentes

### Integración de equipo
- Notifica a los miembros del equipo sobre nuevos chats
- Permite que los miembros del equipo se unan a las conversaciones
- Proporciona una transferencia fluida de la IA a agentes humanos

### Interacción con el cliente
- Inicia conversaciones con mensajes de bienvenida
- Recopila información del cliente para un mejor servicio
- Admite mensajería multimedia (imágenes, archivos adjuntos)

## Beneficios para tus clientes

- **Experiencia del cliente mejorada**: proporciona respuestas inmediatas a las consultas de los clientes de tus clientes
- **Mayor eficiencia**: gestiona las consultas rutinarias automáticamente
- **Horario de servicio extendido**: ofrece soporte fuera del horario de negocio
- **Generación de clientes potenciales mejorada**: capta la información del visitante
- **Colaboración en equipo**: permite que varios miembros del equipo ayuden a los clientes

## Primeros pasos

Para comenzar a usar el AI-assisted Web Chat Widget para un cliente:

1. Asegúrate de que el cliente tenga una suscripción a Conversations AI (Standard, Pro, o Premium)
2. Instala el Web Chat Widget en el sitio web del cliente
3. Configura el asistente de IA con las preguntas frecuentes
4. Configura las notificaciones de equipo para alertas en tiempo real
5. Personaliza la apariencia para que coincida con la marca del cliente

Para más detalles sobre la instalación y configuración, consulta nuestras guías dedicadas en esta sección.

## Preguntas frecuentes

<details>
<summary>¿Hay disponible una incorporación de iframe para Web Chat en lugar del fragmento de JavaScript?</summary>

No. Web Chat admite la instalación solo mediante el fragmento de script. La incorporación de iframe no está disponible, y el fragmento no funciona dentro de un iframe personalizado. Puedes incluir el script en la lista de permitidos solo en las páginas que lo necesiten.

</details>
