Esta sección contiene documentación de herramientas y funciones obsoletas que ya no cuentan con soporte activo ni están disponibles en la plataforma actual de Vendasta. Estas páginas se mantienen como referencia histórica y para ayudar a los partners a comprender la funcionalidad heredada.

## ¿Por qué existe esta sección?

La documentación heredada ayuda a los partners que puedan estar haciendo la transición desde funciones anteriores o que necesiten comprender el contexto histórico. Aunque estas funciones ya no están disponibles, la documentación permanece accesible para fines de referencia.

## Qué incluye

- **[CalendarHero](./calendarhero/index.mdx)**: documentación del producto heredado de calendario y programación
- **[Customer Voice](./customer-voice/index.mdx)**: sistema heredado de gestión de reseñas y comentarios de clientes
- **[Proposals](./proposals/index.mdx)**: herramientas heredadas de creación y gestión de propuestas

## Notas importantes

:::warning Funciones obsoletas
Las herramientas documentadas en esta sección están obsoletas y ya no están disponibles para nuevas implementaciones. Consulta la documentación actual de la plataforma para conocer las funciones activas y las alternativas recomendadas.
:::

Si buscas funcionalidad actual, consulta:
- **Commerce** para la creación y gestión de propuestas
- **Reputation AI Premium** para reseñas y NPS (reemplazo de Customer Voice)
- **Business App** para funciones orientadas al cliente, incluida la programación
- **CRM** para la gestión de relaciones con clientes
- **Marketing** para campañas de correo electrónico y generación de leads
