## ¿Qué es la Template Library?

La Template Library ofrece plantillas de proyecto prediseñadas que puedes usar para crear plantillas nuevas en Task Manager. Estas plantillas incluyen tareas y estructuras predefinidas para tipos de proyecto comunes, ayudándote a configurar proyectos de manera más eficiente.

## ¿Por qué es importante la Template Library?

La Template Library ofrece varios beneficios para la gestión de proyectos:

- Puedes configurar proyectos rápidamente usando estructuras de tareas comprobadas
- Ahorras tiempo al comenzar con plantillas existentes en lugar de crear proyectos desde cero
- Obtienes orientación sobre qué tareas incluir para tipos de proyecto específicos
- Puedes personalizar las plantillas para adaptarlas a las necesidades específicas de tu flujo de trabajo

## Qué incluye la Template Library

La Template Library incluye varias plantillas prediseñadas:

- `Generic`: plantilla básica adecuada para varios tipos de proyecto
- `Listing Claim`: plantilla para reclamar listados de negocio
- `Review Requests`: plantilla para gestionar flujos de respuesta a reseñas
- `Build Social Media Business Page`: plantilla para crear páginas de negocio en redes sociales
- `Social Posts`: plantilla para la creación y gestión de contenido en redes sociales
- `Website Build`: plantilla para proyectos de desarrollo de sitios web

## Cómo acceder a la Template Library

Puedes acceder a la Template Library al crear plantillas nuevas:

1. Abre Task Manager
2. Haz clic en la pestaña `Templates`
3. Haz clic en `Create Template`
4. Selecciona `Select from the library`
5. Elige tu plantilla base preferida entre las opciones disponibles
6. Haz clic en `View` para ver las tareas incluidas en la plantilla
7. Personaliza la plantilla según sea necesario para tu proyecto

:::info
Los cambios que hagas a una plantilla solo se aplican al proyecto actual que estás creando. La plantilla original en la biblioteca permanece sin cambios.
:::

## Personalizar las plantillas de la biblioteca

Cuando seleccionas una plantilla de la biblioteca, puedes:

- Agregar o quitar tareas para adaptarlas a tu flujo de trabajo
- Modificar las descripciones y requisitos de las tareas
- Ajustar el orden y las dependencias de las tareas
- Establecer plazos y prioridades personalizados

:::warning
Para guardar tus personalizaciones para uso futuro, crea una plantilla nueva usando la opción `project` después de hacer tus cambios.
:::

## Crear tareas recurrentes con plantillas

Task Manager admite tareas recurrentes a través de plantillas de proyecto. La recurrencia se configura a nivel de plantilla: la estableces una vez y todos los proyectos creados a partir de esa plantilla heredan automáticamente el cronograma de recurrencia.

### Cómo crear una plantilla de tarea recurrente

1. Abre `Task Manager`
2. Haz clic en la pestaña `Templates`
3. Haz clic en `Create Template`
4. Selecciona `Create new template`
5. Agrega tus tareas y luego busca el menú desplegable `Recurrence` en cada tarea que quieras repetir
6. Elige una opción de recurrencia:
   - `Does not recur`: tarea única (predeterminado)
   - `Daily`: se repite todos los días
   - `Weekly on [day]`: se repite el mismo día cada semana
   - `Every Weekday (Mon–Fri)`: se repite de lunes a viernes
   - `Monthly`: se repite en la misma fecha cada mes
   - `Annually`: se repite una vez al año
7. Guarda la plantilla

### Cómo aplicar la plantilla

Una vez guardada, selecciona la plantilla al crear un proyecto nuevo. El cronograma recurrente definido en cada tarea se trasladará automáticamente al proyecto nuevo.

:::info
La recurrencia se establece a nivel de plantilla, no en tareas individuales agregadas a un proyecto existente. Para usar tareas recurrentes, primero debes crear o editar una plantilla.
:::

## Preguntas frecuentes

<details>
<summary>¿Puedo modificar las plantillas de la biblioteca?</summary>

Sí, puedes personalizar cualquier plantilla al crear un proyecto nuevo. Sin embargo, los cambios solo se aplican a tu proyecto actual y no afectan la plantilla original de la biblioteca.
</details>

<details>
<summary>¿Cómo guardo mi plantilla personalizada para uso futuro?</summary>

Después de personalizar una plantilla de la biblioteca, usa la opción `project` para guardar tus cambios como una plantilla nueva en tu colección.
</details>

<details>
<summary>¿Qué plantilla debo elegir si no estoy seguro?</summary>

La plantilla `Generic` proporciona una base sólida para la mayoría de los tipos de proyecto y se puede personalizar para adaptarse a tus necesidades específicas.
</details>

<details>
<summary>¿Se agregan plantillas nuevas a la biblioteca regularmente?</summary>

La Template Library contiene plantillas establecidas para tipos de proyecto comunes. Revisa la biblioteca periódicamente para ver si hay nuevas incorporaciones.
</details>

<details>
<summary>¿Puedo compartir las plantillas de la biblioteca con los miembros del equipo?</summary>

Las plantillas de la biblioteca están disponibles para todos los usuarios con acceso a Task Manager. Las plantillas personalizadas que crees se pueden compartir por separado.
</details>

<details>
<summary>¿Las plantillas de la biblioteca incluyen dependencias de tareas?</summary>

Sí, las plantillas de la biblioteca incluyen estructuras de tareas y dependencias predefinidas según los patrones de flujo de trabajo comunes para cada tipo de proyecto.
</details>

<details>
<summary>¿Puedo eliminar plantillas de la biblioteca?</summary>

No, no puedes eliminar ni modificar las plantillas originales de la biblioteca. Solo puedes personalizarlas al crear proyectos nuevos.
</details>

<details>
<summary>¿Qué sucede si no personalizo una plantilla de la biblioteca?</summary>

Puedes usar las plantillas de la biblioteca tal cual, sin ninguna personalización. La plantilla creará un proyecto con todas las tareas y la estructura predefinidas.
</details>

<details>
<summary>¿Task Manager admite tareas recurrentes?</summary>

Sí, las tareas recurrentes son compatibles a través de plantillas. Configura la opción Recurrence en cada tarea al crear o editar una plantilla. Los cronogramas disponibles incluyen diario, semanal en un día específico, cada día laborable, mensual y anual. Cualquier proyecto creado a partir de esa plantilla incluirá tareas con la recurrencia configurada.

</details>
