## Setup

### Qué incluye

#### 1. Pipeline del CRM y gestión de clientes potenciales

Para gestionar adecuadamente tus clientes potenciales, crearemos una lista inteligente y un pipeline de ventas para ti en el CRM. La lista inteligente extrae automáticamente todos los clientes potenciales de chat web y formularios en una sola lista de contactos, mientras que el pipeline hace seguimiento de las nuevas oportunidades y puede mostrar el valor en dólares de cada cliente potencial. También recibirás tareas y notificaciones para nuevos clientes potenciales.

#### 2. Conexiones de reserva, inventario, y área de servicio

* **Reserva de citas:** podemos conectar tu calendario al AI Receptionist para reservar citas en tu nombre. Si no es posible una conexión directa a través de API, el receptionist proporcionará un enlace de reserva a tus clientes en su lugar.
* **Búsqueda de área de servicio:** para negocios basados en servicios, podemos configurar una capacidad personalizada que gestiona la búsqueda de códigos postales para garantizar que los clientes potenciales estén dentro de tu área de servicio.
* **Conexión de inventario:** para tiendas minoristas con un sitio web de comercio electrónico, podemos configurar una capacidad personalizada (a través de una API abierta) para buscar información de inventario y proporcionar actualizaciones en tiempo real.

#### 3. Creación de automatizaciones

Nuestro equipo configurará de 3 a 5 automatizaciones según las necesidades de tu negocio. Estas automatizaciones te enviarán notificaciones de nuevos clientes potenciales y también enviarán seguimientos a tus clientes potenciales para asegurar que tengan una forma de contactarte.

### El proceso de configuración

El proceso implica una serie de llamadas y pasos de configuración para que tu AI Receptionist funcione de manera efectiva.

#### 1. Llamada de capacitación inicial

Nuestros expertos dirigirán una llamada de incorporación para entender las necesidades de tu negocio y ajustar los flujos de trabajo de captación de clientes potenciales preconstruidos para adaptarlos a ti. Llegaremos a la llamada con tu chat receptionist ya configurado con tu marca y un estilo de comunicación personalizado para demostrarlo. Durante esta llamada, refinaremos juntos cualquier fuente de conocimiento adicional e instrucciones de comunicación.

* **Cronograma:** una llamada de incorporación se puede reservar en tan solo un día hábil, dependiendo de la disponibilidad.
* **Para negocios de EE. UU.:** se requiere el registro A2P para validar el uso de SMS. Ten lista tu información legal del negocio para este proceso, que puede tardar hasta dos semanas en completarse.

#### 2. Configuración del AI Receptionist

Usando los refinamientos de la llamada de incorporación, terminaremos de configurar tu AI Receptionist y habilitaremos su configuración de voz. También crearemos un formulario de captación de clientes potenciales para tu sitio web, configuraremos el registro de SMS, configuraremos la mensajería de texto de llamada perdida o el seguimiento por SMS, y habilitaremos las capacidades de AI Voice para asegurarnos de que nunca pierdas un cliente potencial.

* **Cronograma:** tu AI Receptionist estará completo en 1 día hábil, o 3 días hábiles para flujos de trabajo con integraciones personalizadas.
* **Requisito:** necesitamos acceso al backend de tu sitio web para instalar el chatbot y el formulario de clientes potenciales.

#### 3. Llamada de incorporación y recorrido

Esta llamada se usará para guiarte a través del proceso de captación de clientes potenciales recién configurado. Nuestros expertos te mostrarán dónde encontrar tus clientes potenciales, cómo participar en conversaciones, y cómo crear tareas adicionales para tu equipo de ventas.

* **Cronograma:** esta llamada se puede reservar en tan solo un día hábil después de que se complete la configuración del AI Receptionist.

#### 4. Llamada de revisión a los 30 días

Esta llamada está programada para revisar tus conversaciones, determinar qué conocimiento o instrucciones personalizadas necesitan actualizarse o refinarse, y asegurar que tu AI Receptionist se esté comunicando de manera efectiva. Antes de esta llamada, nuestro equipo revisará de 5 a 10 conversaciones para proporcionar recomendaciones de mejora.

* **Cronograma:** esta llamada se reservará de 3 a 4 semanas después de completar la configuración de tu AI Receptionist.

## Preguntas frecuentes (FAQ)

<details>

<summary>¿Cómo captura clientes potenciales el chat web asistido por IA?</summary>

Cuando un cliente interactúa con el chat en tu sitio web, la IA responderá con un comportamiento conversacional simple diseñado para obtener un nombre y un número de teléfono móvil. Esto garantiza que captures el cliente potencial y puedas hacer seguimiento más tarde. La IA puede responder preguntas básicas sobre tu negocio, como ubicación y horarios, según tu perfil de negocio y sitio web.
</details>

<details>

<summary>¿Cuánto sabe el chatbot sobre el negocio?</summary>

Al chatbot se le puede dar "conocimiento" del perfil de negocio para responder preguntas básicas sobre servicios, ubicación, y horarios. También puedes cargar texto adicional para agregar preguntas frecuentes, detalles de servicio, e instrucciones sobre cómo reservar citas para que el chat web pueda conversar con precisión con los visitantes del sitio web.
</details>

<details>

<summary>¿Cómo sé cuándo llega un nuevo cliente potencial?</summary>

Recibirás una notificación por correo electrónico o SMS (o ambos) cuando un cliente use el chat web o el formulario de clientes potenciales en tu sitio web. El cliente también recibirá un mensaje informándole que un miembro del equipo se pondrá en contacto pronto. Todos estos mensajes se pueden personalizar.
</details>

<details>

<summary>¿Pueden crear automatizaciones personalizadas para mí?</summary>

Actualmente no ofrecemos la creación de automatizaciones personalizadas. La configuración incluye una lista estandarizada de flujos de trabajo diseñados para poner en marcha tu negocio rápidamente. Durante la llamada de incorporación, discutiremos tus necesidades y haremos ajustes a nuestras plantillas de automatización de captación de clientes potenciales preconstruidas.
</details>

<details>

<summary>¿Hay una opción más simple para la instalación del chat web?</summary>

Si buscas una instalación de código simple y tienes activo nuestro servicio de [Website Support](../websites/vendasta-services-website-support.md), nuestro equipo de Website Support puede instalar el código del chat web. Esto no ofrece una configuración completa de extremo a extremo del chat web, y es solo para la instalación básica de código.

</details>

<details>

<summary>¿Puede el AI Receptionist crear una cotización o reservar una cita?</summary>

Usando la base de conocimiento, podemos darle al chatbot la información que necesita para crear una cotización o estimado básico. Si conectas un calendario de Google, Outlook, o Microsoft en Business App, el AI Receptionist puede reservar citas en tu nombre.

</details>

<details>

<summary>¿El AI Receptionist cumple con HIPAA?</summary>

El AI Receptionist no cumple con HIPAA, lo que significa que no debe manejar **PHI**. La PHI (información de salud protegida) es cualquier información personal sobre la salud de alguien que pueda identificarlo, como condiciones médicas, tratamientos, resultados de pruebas, detalles de seguro, o un nombre combinado con una pregunta médica.

El AI Receptionist es conforme con HIPAA en el sentido de que puede usarse de una manera que respalde las reglas de HIPAA **siempre que no se comparta PHI**. Es seguro usarlo para tareas simples como responder preguntas generales, compartir horarios de oficina, o ayudar a reservar citas sin detalles médicos. Las organizaciones de salud son responsables de asegurarse de que la IA se use de esta manera.

</details>
