## Descripción general

GA4 Complete Build es una solución rápida y lista para usar donde un especialista publicitario crea una nueva propiedad de Google Analytics 4 (GA4), instala y conecta Google Tag Manager (GTM), y configura hasta tres objetivos, para que las analíticas estén listas para funcionar. El acuerdo de nivel de servicio (SLA) para la entrega es de **3 días hábiles**.

## Qué incluye

- Configurar un nuevo contenedor de Google Tag Manager (GTM)
- Agregar el código de GTM al sitio web
- Crear una nueva propiedad de GA4
- Conectar GTM con GA4
- Configurar nuevos objetivos en GA4 (hasta 3 objetivos)
- Revisar la configuración de objetivos después de 48 horas para asegurar una sincronización adecuada

:::note Objetivos adicionales
Configuramos hasta tres objetivos. Si se necesitan más, activa el complemento de tarifa por hora por cada conjunto de tres objetivos adicionales.
:::

## Requisitos previos

- **Acceso al sitio web**: necesario para agregar el código de GTM al sitio.
- **Un ID de inicio de sesión y contraseña de Google**: necesario para configurar GA4 y GTM.
- **Una lista de objetivos esperados**: si no se proporcionan objetivos, nuestro equipo los solicitará y sugerirá objetivos según el sitio web. Debes **aprobar los objetivos** para que los configuremos, o se pierde la opción de configuración de objetivos.

## Primeros pasos

1. **Pedido y formulario de cumplimiento**: nuestro equipo recibe el formulario de cumplimiento y comienza a crear e instalar la nueva cuenta de GA4 y Google Tag Manager. Si tenemos preguntas, nos comunicaremos por correo electrónico.
2. **Configuración de GA4 + GTM (día 1)**: configuramos Google Tag Manager, agregamos el código de GTM al sitio web, creamos una nueva propiedad de GA4, conectamos GTM con GA4, y configuramos tus objetivos (hasta 3). Esto toma de 1 a 3 días hábiles.
3. **Período de espera de 48 horas**: después de los pasos finales de configuración, un período de espera de 48 horas confirma que los objetivos han migrado y se están sincronizando correctamente.
4. **Verificación final (3er día hábil)**: nuestro equipo confirma que la configuración se completó correctamente y revisa la configuración de objetivos después de 48 horas. Nos comunicaremos por correo electrónico si hay problemas que corregir (lo que podría retrasar el SLA).
5. **Confirmación**: enviamos un correo electrónico confirmando que la construcción está completa y que todos los objetivos están configurados y sincronizando.

El SLA es de **3 días hábiles**, aunque puede retrasarse si faltan datos o hay problemas que corregir.
