## Descripción general

El [Templated Website](https://partners.vendasta.com/marketplace/products/MP-XQC6XC2VMV3B4ZJZLD6Z6ZDXKN2VTC86) es una construcción de WordPress donde eliges una plantilla diseñada profesionalmente y nuestro equipo la personaliza con tus colores, fuentes, imágenes, y contenido. Incluye una llamada de incorporación, un mockup de la página de inicio para revisión, y una ronda de revisiones importantes antes del lanzamiento. La estructura es fija, pero los toques visuales lo hacen tuyo.

## Qué incluye

* **Sitio de WordPress basado en plantilla:** elige una plantilla; la estructura es fija, con colores, fuentes, e imágenes personalizables.
* **De 3 a 10 páginas:** un sitio de 3 páginas de forma predeterminada, con hasta 10 páginas disponibles.
* **Hasta 1,500 palabras de texto:** se incluye texto genérico; el texto personalizado está disponible como complemento de servicio.
* **Cargas de blog:** hasta 4 blogs cargados como parte de la construcción inicial (4 adicionales por mes con Website Support activo).
* **Formularios del sitio web:** hasta 3 formularios, con hasta 20 campos cada uno.
* **Alojamiento seguro:** alojado en nuestra infraestructura segura y de última generación de WordPress.
* **Una ronda de revisiones importantes:** como cambiar secciones o eliminar páginas.

## Requisitos previos

Se necesitan tres componentes para construir tu sitio web, más tu contenido. Piensa en tu sitio web como una casa: el alojamiento es el terreno, el dominio es la dirección, y la plantilla es el plano.

* **Alojamiento:** tu sitio se aloja en nuestra infraestructura segura y de última generación para mantenerlo protegido y rápido.
* **Dominio:** si ya tienes un dominio, se te darán instrucciones para delegar el acceso. Si no, nuestro equipo puede recomendarte dónde comprar uno.
* **Plantilla:** elige una plantilla según la estética que mejor se adapte a tu negocio. [Explora todas nuestras plantillas aquí.](https://frameworks.yourdigitalagents.com/)
* **Detalles de incorporación:** ten listos estos para tu llamada: plantilla elegida y esquema de colores, logotipo y fuente(s), imágenes preferidas (opcional), información del negocio, y una dirección de correo electrónico para los formularios de contacto.

## Primeros pasos

### 1. Incorporación

Después de enviar el formulario de cumplimiento con los detalles de tu negocio, programarás una llamada de incorporación con un desarrollador de sitios web. Esta llamada se recomienda encarecidamente para garantizar una comprensión clara del proyecto: discutiremos tu negocio, qué ofreces, y cómo transmitir mejor eso a tus clientes, y revisaremos tu plantilla elegida para entender qué te gusta y qué se puede adaptar.

### 2. Cronogramas de publicación

Los cronogramas pueden variar, y la fecha de entrega de la primera versión se proporciona después de la llamada de incorporación. La información faltante en el formulario de cumplimiento causará retrasos.

* **Revisión inicial:** el proceso comienza dentro de 2 días hábiles de recibido el pedido.
* **Mockup de la página de inicio:** recibes la página de inicio para revisión dentro de 5 días hábiles de completar tu llamada de incorporación. Si no estás satisfecho con ella, tienes derecho a un ajuste con una plantilla diferente.
* **Entrega completa del sitio web:** después de que proporciones retroalimentación sobre la página de inicio, el resto del sitio web de 3 páginas se entrega dentro de 5 días hábiles. Los sitios de hasta 10 páginas se entregan dentro de 10 días hábiles.

:::note
Los complementos adicionales como páginas adicionales, funcionalidad de comercio electrónico, y plugins requerirán más tiempo. Se proporcionará un cronograma actualizado después de que se complete el proceso de incorporación.
:::

### 3. Revisiones y lanzamiento

Una vez que recibes la primera versión, revisa cada detalle para asegurarte de que sea preciso. El servicio incluye una ronda de revisiones importantes (como cambiar secciones o eliminar páginas).

* **Cronograma de revisión:** una vez enviadas las revisiones, los ajustes se hacen dentro de 5 a 10 días hábiles.
* **Lanzamiento:** después de que apruebes los cambios importantes, el sitio se activa dentro de 1 día hábil (pueden aplicar excepciones).
* **Cambios menores:** se pueden hacer pequeños ajustes después de que se completen las revisiones principales o después de que el sitio esté activo para asegurar que estés completamente satisfecho.

### 4. Soporte continuo

Se requiere un compromiso de 3 meses para el soporte de sitio web una vez que el sitio web se activa. Consulta [Website Support](./vendasta-services-website-support.md) para saber qué incluye y cómo hacer una solicitud. El soporte incluye:

* Hacer actualizaciones a las secciones existentes (imágenes, texto, colores, campos del formulario de contacto).
* Actualizar los plugins y temas del sitio web.
* Realizar revisiones de estado del sitio web a pedido.
* Corregir errores y proporcionar soporte urgente si tu sitio web se desconecta.

Consulta también la [Guía de pedido de sitios web](./vendasta-services-website-ordering-guide.md).

## Preguntas frecuentes

<details>

<summary>¿Pueden crear contenido personalizado escrito para mi sitio web?</summary>

Cada sitio web se completa con hasta 1,500 palabras de texto genérico. Si te gustaría texto personalizado, esto está disponible como complemento de servicio.
</details>

<details>

<summary>¿Pueden cargar blogs a mi sitio web?</summary>

Sí, nuestro equipo cargará hasta 4 blogs como parte de la construcción inicial del sitio web. Con un servicio de Website Support activo, se pueden cargar 4 blogs adicionales por mes.
</details>

<details>

<summary>¿Cómo se manejan los videos para evitar ralentizar el sitio?</summary>

Te recomendamos cargar los videos en YouTube primero. Desde ahí, podemos incrustar los videos en el sitio web sin afectar las velocidades de carga.
</details>

<details>

<summary>¿Pueden construir formularios en mi sitio web?</summary>

Sí. Podemos construir un máximo de tres formularios de sitio web, con hasta 20 campos cada uno.
</details>

<details>

<summary>¿Mi sitio web puede tener varios idiomas?</summary>

Sí, usamos el plugin GTranslate para este servicio. La versión gratuita usa un servicio de traducción estándar. Para editar traducciones, debes comprar la versión premium del plugin.
</details>

<details>

<summary>¿Puedo recolectar pagos o donaciones en mi sitio web?</summary>

Para pagos, usamos un plugin gratuito llamado Gravity Forms. Para donaciones, recomendamos el plugin GiveWP, que es gratuito pero generará cargos adicionales para instalar debido a su complejidad.
</details>

<details>

<summary>¿Qué pasa si necesito más personalizaciones?</summary>

La solución Templated Website es ideal para sitios web más simples sin personalización extensa. Si requieres una solución más personalizada, contacta a nuestro equipo y con gusto encontraremos la mejor solución para ti.
</details>

<details>

<summary>¿Tengo que alojar el sitio web con ustedes?</summary>

El sitio web debe construirse en nuestro entorno de WordPress Hosting. Después de eso, eres libre de trasladarlo a cualquier host. Sin embargo, ten en cuenta que los sitios fuera de nuestro entorno de alojamiento ya no serán respaldados por nuestro equipo.
</details>
