Si tienes un sitio web de WordPress existente y te gustaría trasladarlo a la plataforma de alojamiento de Vendasta (WordPress Hosting Pro), ¡Vendasta Services puede ayudar!

También obtendrás acceso al equipo de Website Support de Vendasta Services cuando importemos un sitio con Website Support+ activado _(compromiso de 3 meses)_.

Para la lista completa de lo que cubre Website Support+, consulta el artículo [Website Support](./vendasta-services-website-support.md).

## ¿Qué beneficios hay al importar un sitio a través de Vendasta Services?

Con Vendasta Services, tu sitio web está en manos confiables. Para importar el sitio, nuestro equipo de Website Support+:

*   Empaquetará y descargará el sitio web de la plataforma de alojamiento original
*   Cargará y configurará el sitio en nuestra plataforma de alojamiento WordPress Hosting Pro
*   Los plugins, temas, versiones de WordPress, y versiones de PHP se actualizan donde sea posible\*
*   El sitio web se revisa para el control de calidad para asegurar que todos los enlaces y elementos funcionen correctamente

_\*Los plugins o temas pueden requerir una clave de licencia para actualizar._



## Proceso de evaluación para importación y soporte

**Evaluación:**

1.  Activa el producto gratuito [Website Import Vetting](https://partners.vendasta.com/marketplace/products/MP-1751871d98cf4e7f95d55c7d2b2ff293) en la cuenta correspondiente.
2.  Completa el formulario de cumplimiento con las credenciales que necesitamos para acceder y evaluar tu sitio:
    1.  Inicio de sesión del registrador de dominio (nombre del registrador, nombre de usuario, y contraseña)
    2.  URL actual del sitio de WordPress
    3.  Nombre de usuario y contraseña de administrador de WordPress
    4.  Aunque podemos evaluar el sitio web sin acceso al registrador de dominio, no podemos evaluar el sitio sin las credenciales de inicio de sesión de administrador de WordPress. Si hay un firewall o restricción de país activo, es posible que también necesites incluir en la lista blanca nuestra dirección IP.
3.  Al recibir el formulario de cumplimiento completado, nuestro equipo evaluará el sitio web, lo que incluye revisar, entre otras cosas:
    1.  Los plugins que se ejecutan activamente en el sitio web
    2.  Cómo está construido el sitio web (es decir, Divi, Elementor, WPBakery, etc.)
    3.  Si hay temas o elementos de código personalizado que nuestro equipo no pueda respaldar
4.  Una vez que se haya evaluado el sitio web, recibirás una actualización por correo electrónico con nuestros hallazgos, ya sea reconociendo que está aprobado para importación y soporte o que fue rechazado (en cuyo caso recomendaríamos reconstruir el sitio con nuestro equipo de diseño).

:::note Requisitos técnicos
Para ser elegible para importación y soporte, tu sitio debe ejecutarse en **WordPress 6.4 o superior** y **PHP 8.3 o superior**. Los sitios que no se puedan actualizar a estas versiones pueden ser rechazados.
:::

**Importación:**

1.  Si se aprueba, activaremos [WordPress Hosting Pro](https://partners.vendasta.com/marketplace/products/MP-ee4ea04e553a4b1780caf7aad7be07cd) y el complemento [Website Import & Support](https://partners.vendasta.com/marketplace/products/MP-1751871d98cf4e7f95d55c7d2b2ff293/addon/A-7JLBR47NLD) (tarifa de configuración única + tarifa de soporte mensual de 3 meses).
2.  La importación se completa dentro de 3 días hábiles después de la evaluación.
3.  Sitio web alojado en un dominio temporal. _(por ejemplo: business-name.websitepro.hosting)_

**Activación:**

1.  Recibirás un correo electrónico para revisar el sitio en el dominio temporal. Con tu aprobación y acceso al registrador de dominio, activaremos el sitio en el dominio personalizado.
    1.  Alternativamente, puedes actualizar la configuración de DNS. Podemos proporcionarte los registros CNAME y A.

_Ten en cuenta que un sitio puede tardar hasta 72 horas en propagarse completamente. Durante este tiempo, es posible que veas una página de error de conexión insegura. El tiempo de inactividad del sitio web debería ser mínimo, pero podría durar unas horas mientras los registros DNS reasignan la nueva ruta a tu sitio web._

**Razones comunes para el rechazo de importación y soporte:**

*   No es un sitio de WordPress
*   No cumple con los requisitos mínimos de PHP 8.3 o WordPress 6.4
*   Temas, plantillas, o elementos totalmente de código personalizado que nuestro equipo no puede respaldar
*   Construido solo con bloques nativos de WordPress (Gutenberg), sin tema o constructor compatible
*   Plugins extensamente desactualizados o de versiones mixtas, especialmente constructores de páginas
*   Fuerte dependencia de Advanced Custom Fields (ACF) u otros campos personalizados complejos (se revisa caso por caso)
*   Preocupaciones de seguridad
*   Parte de un multisitio
*   Construido usando un constructor o método no compatible
*   Problemas de compatibilidad con WordPress Hosting Pro

Si nuestro equipo de Website Support+ no puede respaldar el sitio web en cuestión, te enviaremos un correo electrónico para hacerte saber que no podemos respaldar este sitio y explicaremos por qué tuvimos que rechazarlo.

## Exportar un sitio web

Si has decidido que quieres trasladar un sitio web a un nuevo host y descontinuar el soporte, podemos proporcionarte el archivo de tu sitio web.

### Qué necesitas

1.  Un entorno de alojamiento con una instalación de WordPress.
2.  El plugin All In One Import/Export instalado en tu nuevo host de WordPress.
3.  Contacta a nuestro equipo para que te proporcionemos el archivo de tu sitio web existente.
4.  Verifica que tu sitio web funcione correctamente en tu nuevo entorno antes de descontinuar el servicio.

Nuestro equipo puede proporcionarte el archivo y las credenciales necesarias para el sitio web existente, pero no podemos acceder a tu nuevo alojamiento ni realizar la importación a tu nuevo host en tu nombre.

**Nota importante:** una vez que hayas descontinuado tu alojamiento con nosotros, solo tendremos acceso al sitio web en nuestros servidores durante seis meses, después de lo cual se eliminará permanentemente.

## Preguntas frecuentes (FAQ)

<details>
<summary>¿Mi sitio es elegible para Website Support+?</summary>

Admitimos lo siguiente para Website Support+:

*   Sitios web de WordPress construidos por nuestro equipo de sitios web de Vendasta Services
*   La mayoría de los sitios web de WordPress construidos con constructores visuales aprobados
    *   Es decir, Divi, Elementor, WPBakery, etc.

Los sitios web no construidos por Vendasta Services (o con cambios significativos hechos externamente después de haber sido construidos por nosotros) necesitarán ser evaluados antes de ser aprobados para Website Support+.

Las solicitudes de soporte de sitio web se pueden enviar a [marketingservices@yourdigitalagents.com](mailto:marketingservices@yourdigitalagents.com)

</details>

<details>
<summary>Mi sitio ya está en WordPress Hosting Pro, ¿pueden respaldarlo?</summary>

Si tu sitio ya está alojado en WordPress Hosting Pro, activa el producto independiente Website Support+. Si el sitio es rechazado para Website Support+, una vez que lo evaluemos, rechazaremos el producto, y se te reembolsará automáticamente. Los sitios rechazados se pueden reconstruir con nuestro equipo de diseño de sitios web.

Las solicitudes de soporte de sitio web se pueden enviar a [marketingservices@yourdigitalagents.com](mailto:marketingservices@yourdigitalagents.com)

</details>

<details>
<summary>¿Pueden instalar el AI Chat Receptionist en mi sitio web importado?</summary>

¡Sí! Website Support+ incluye la instalación del AI Chat Receptionist en tu sitio web importado. Nuestro equipo de Website Support+:

*   Agregará el código de chat web al sitio
*   Confirmará que el widget carga correctamente en el sitio web
*   Realizará una prueba básica (abrir el chat, confirmar que se puede enviar un mensaje)
*   Agregará los colores de marca al AI Chat Receptionist

Si necesitas funciones avanzadas como configuración completa de marca más allá de los colores básicos de marca, mensajería SMS, llamadas de voz, o flujos de conversación personalizados, explora nuestro servicio [AI Receptionist Setup & Support](../ai-workforce/ai-receptionist.md).

</details>

<details>
<summary>¿Qué tipo de formularios configurarán en mi sitio?</summary>

Como parte de Website Support+, podemos convertir un formulario de contacto de terceros existente en un formulario de CRM para que los envíos fluyan directamente a tu CRM como clientes potenciales. Configuramos formularios estándar de contacto y captación de clientes potenciales.

No construimos funcionalidad avanzada de formularios, incluida:

*   Visibilidad condicional avanzada a nivel de campo (mostrar u ocultar campos según la entrada)
*   Campos calculados
*   Reglas de validación complejas
*   Formularios de varias páginas con guardar y reanudar progreso
*   Campos de pago nativos
*   Reserva de citas nativa
*   Vistas previas de formulario completamente responsivas
*   Prellenado de campos basado en lógica

Si necesitas alguna de estas funciones avanzadas, contáctanos y nuestro equipo puede definir el alcance del trabajo personalizado para ti.

</details>

<details>
<summary>¿Qué pasará con mi formulario existente y los datos de envío?</summary>

Cuando convertimos tu formulario a un formulario de CRM, el formulario heredado se desactiva y se elimina del front end de tu sitio, así que los visitantes solo ven el nuevo formulario de CRM. No eliminamos el plugin de formulario heredado, así que cualquier envío recopilado previamente permanece visible en tu backend de WordPress. Tus entradas de formulario existentes también se migran al CRM.

</details>
