## Descripción general

Express Website Build es una solución que "hacemos por ti" donde nuestros profesionales crean un sitio web económico y generado por IA de hasta 5 páginas para ti, con el primer borrador entregado tan pronto como el mismo día. Está construido en WordPress y diseñado para poner en línea el negocio de tu cliente rápidamente.

## Qué incluye

Express Website Build es un paquete completo diseñado para poner en línea el negocio de tu cliente de manera rápida y eficiente.

* **Sitio web de hasta 5 páginas:** incluye páginas esenciales como Home, About, Services, y Contact.
* **Redacción asistida por IA:** el contenido del sitio de tu cliente es generado por IA usando la información que proporcionas.
* **Construido en WordPress:** el sitio web de tu cliente se construirá en el sistema de gestión de contenido más popular y flexible del mundo.
* **Plugins estándar:** incluye plugins esenciales como Yoast SEO, Gravity Forms, y Divi Booster sin costo adicional.
* **Alojamiento seguro:** el sitio de tu cliente se aloja en nuestra plataforma de alojamiento de WordPress propia, impulsada por Google Cloud Platform, con un certificado SSL incluido.
* **Una ronda de revisiones:** obtienes una ronda de revisiones para asegurar que el sitio web cumpla con tus expectativas antes del lanzamiento.
* **Entrega rápida:** el primer borrador se entrega el mismo día hábil o el siguiente, con el objetivo de lanzar el sitio completo dentro de 15 días.

### Limitaciones del servicio

* **Personalizaciones:** Express Website Build está diseñado para la eficiencia y no admite personalizaciones extensas. Para soluciones más flexibles o personalizadas, consulta sobre nuestro producto Templated Website.
* **Tamaño del sitio web:** para garantizar un rendimiento óptimo, recomendamos que los sitios se mantengan por debajo de 50 GB.
* **Costos adicionales:** los complementos como páginas adicionales, plugins premium, o funcionalidad de comercio electrónico agregarán costos incrementales y pueden extender los cronogramas del proyecto.

## Requisitos previos

Se necesitan dos componentes para construir el sitio web de tu cliente, más el contenido de tu cliente. Piensa en tu sitio web como una casa: el alojamiento es el terreno sobre el que se asienta, y el dominio es su dirección.

* **Alojamiento:** cada sitio web se aloja en nuestra plataforma propia WordPress Hosting. Website Support y WordPress Hosting se requieren desde el primer día como productos complementarios.
* **Dominio:**
  * **Si no tienes un dominio:** recomendamos comprar uno en GoDaddy, ya que se integra con nuestra plataforma.
  * **Si ya tienes un dominio:** otórganos acceso delegándolo a `websites@yourdigitalagents.com` (para GoDaddy) o `websitesanalytics@localmarketpage.com` (para Google/Squarespace). Alternativamente, proporciona la URL y las credenciales de inicio de sesión.
* **Detalles del formulario de cumplimiento:** el logotipo de tu cliente, esquema de colores, fuentes, información del negocio, preferencias de navegación, contenido, llamada a la acción, detalles del formulario, y acceso al dominio. Completa el formulario con la mayor cantidad de detalles posible para una construcción fluida.

## Primeros pasos

El proceso está diseñado para la velocidad, avanzando desde el envío de información hasta un sitio web en vivo en unos pocos pasos clave.

### 1. Cumplimiento y construcción impulsada por IA

El proceso de construcción comienza una vez que envías el formulario de cumplimiento. Nuestros expertos desarrolladores de sitios web con IA usan tus aportaciones para crear un sitio web que represente el negocio de tu cliente, incorporando las fuentes, colores, e imágenes preferidas de tu cliente, junto con redacción asistida por IA.

* Los pedidos realizados de lunes a viernes antes de las 10:30 AM CST tendrán el primer borrador entregado el mismo día hábil.
* Los pedidos realizados después de las 10:30 AM CST se entregarán el siguiente día hábil antes de las 12:30 PM CST.
* El mockup del sitio consistirá en hasta 5 páginas y se entregará dentro de 1 día hábil.

### 2. Revisiones y lanzamiento

Después de la construcción inicial, puedes revisar y solicitar cambios.

* **Revisiones:** se incluye una ronda de revisiones (ajustes de diseño, ediciones de texto, o cambios visuales). Una vez enviada, nuestro equipo implementa los cambios dentro de 2 a 5 días hábiles. Las rondas de revisión adicionales se facturan por hora. También puedes comprar un complemento para una llamada opcional de 30 minutos con un desarrollador para revisar tus notas.
* **Lanzamiento:** después de tu aprobación final, el sitio web se lanza dentro de 1 día hábil. Si no recibimos una respuesta dentro de las 24 horas de enviar la versión final para aprobación, el sitio se considera aprobado y se activa. Nuestro objetivo es lanzar los sitios web nuevos dentro de 15 días de iniciar el proyecto.

### 3. Soporte continuo

Para garantizar que el sitio web de tu cliente esté respaldado, se requieren 3 meses de soporte de sitio web una vez que el sitio se activa (un cargo adicional). El soporte incluye:

* Actualizaciones a las secciones existentes (imágenes, texto, colores, campos del formulario de contacto).
* Actualización de plugins y temas, y realización de revisiones de estado del sitio web a pedido.
* Corrección de errores y soporte urgente si el sitio web de tu cliente se desconecta.

Una vez completado el compromiso inicial de 3 meses, puedes cancelar el servicio. Sin embargo, ya no podrás contactar a nuestro equipo para soporte. Reactivar un plan de soporte cancelado requerirá un nuevo compromiso de 3 meses.

## Preguntas frecuentes

### Lo básico y detalles adicionales

<details>

<summary>¿Pueden crear contenido personalizado escrito para el sitio web de mi cliente?</summary>

No, no proporcionamos contenido personalizado escrito con este servicio. Todo el texto web se genera con IA usando la información que proporcionas en el formulario de cumplimiento.
</details>

<details>

<summary>¿Puedo agregar una página de blog al sitio web?</summary>

Se puede agregar una página de blog comprando nuestro complemento `Hourly Charge`. Esto cubre la construcción de la página de blog y hasta cuatro cargas de publicaciones de blog (con contenido proporcionado por ti). Agregar una página de blog extenderá el tiempo de respuesta de la construcción.
</details>

<details>

<summary>¿Cómo puedo agregar videos sin ralentizar el sitio?</summary>

Te recomendamos cargar tus videos en YouTube primero. Luego podemos incrustar los videos en tu sitio web sin afectar la velocidad de carga.
</details>

<details>

<summary>¿Qué tipo de formularios puedo tener en el sitio web de mi cliente?</summary>

De forma predeterminada, proporcionamos un formulario de CRM de 5 campos para la recopilación de clientes potenciales. También puedes elegir un Gravity Form, donde los clientes potenciales se reenvían a un correo electrónico designado, o usar tu propio plugin de formulario de terceros. Usar tu propio formulario requiere que compres el plugin por separado, y se aplicarán cargos por hora para la instalación.
</details>

<details>

<summary>¿Qué cargos adicionales incurriré mensualmente?</summary>

Para garantizar que el sitio web de tu cliente funcione eficazmente, Website Support y WordPress Hosting se requieren desde el primer día como productos adicionales y complementarios.
</details>

<details>

<summary>¿Dónde debo cargar los archivos adjuntos para mi pedido?</summary>

Carga todos los archivos adjuntos en el formulario de cumplimiento o envíalos por correo electrónico a `marketingservices@yourdigitalagents.com`. No uses la sección Orders en Partner Center.
</details>

<details>

<summary>¿Cuántas imágenes puedo proporcionar para el sitio web de mi cliente?</summary>

Nuestro equipo puede agregar hasta 25 de tus imágenes como parte de la construcción estándar. Si quieres incluir más, se aplicarán cargos adicionales.
</details>

### Funcionalidad del sitio web y plugins

<details>

<summary>¿Pueden construir una tienda en línea?</summary>

Sí, nuestro producto Advanced eCommerce es ideal para construir tiendas en línea. Ten en cuenta que esto extenderá el tiempo de respuesta de la construcción.
</details>

<details>

<summary>¿El sitio web de mi cliente cumplirá con HIPAA?</summary>

Nuestros sitios web actualmente no cumplen con HIPAA. Sin embargo, podemos integrar funciones y servicios que cumplan con HIPAA que tú proporciones.
</details>

<details>

<summary>¿El sitio web de mi cliente puede tener varios idiomas?</summary>

Sí, usamos el plugin GTranslate. La versión gratuita proporciona traducciones automáticas. Si quieres editar las traducciones manualmente, necesitarás comprar la versión premium del plugin.
</details>

<details>

<summary>¿Cómo puedo obtener un feed de redes sociales en el sitio web de mi cliente?</summary>

Usamos el plugin gratuito Smash Balloon para mostrar feeds de Instagram, Facebook, X, TikTok, y YouTube. La configuración requiere tus credenciales de inicio de sesión social, y la instalación tiene un cargo adicional.
</details>

<details>

<summary>¿Puedo recolectar pagos o donaciones en el sitio web de mi cliente?</summary>

Usamos el plugin Gravity Forms para ayudarte a recolectar pagos. Para donaciones, recomendamos el plugin GiveWP. Ambos son plugins gratuitos, pero la instalación de GiveWP requiere una configuración más extensa y generará cargos adicionales.
</details>

<details>

<summary>¿Agregan algún plugin estándar a los sitios web?</summary>

Sí, un conjunto de plugins estándar como Yoast SEO, Gravity Forms, y Divi Booster se agrega a cada sitio web sin costo adicional. Un User Role Plugin también se incluye de forma predeterminada.
</details>

<details>

<summary>¿Qué pasa si quiero usar un plugin premium?</summary>

Necesitarás comprar la licencia del plugin premium y proporcionar las credenciales necesarias a nuestro equipo para la integración. Los costos de integración están sujetos a tarifas por hora adicionales.
</details>

### Más detalles técnicos

<details>

<summary>¿Necesito alojar el sitio web con ustedes?</summary>

El sitio web debe construirse en nuestro entorno de alojamiento. Después de completarlo, eres libre de trasladarlo a otro host, pero nuestro equipo ya no podrá proporcionar soporte.
</details>

<details>

<summary>¿Pueden trabajar con sitios web de Shopify, Squarespace, Wix, etc.?</summary>

No, solo construimos sitios web usando el CMS de WordPress. Otras plataformas usan servicios propietarios, lo que significa que el sitio no se puede transferir a otro host.
</details>

<details>

<summary>¿Cómo emplearán el SEO orgánico en el sitio de mi cliente?</summary>

Empleamos las mejores prácticas, incluidas etiquetas H1, metadatos, texto alternativo, redirecciones 301, migas de pan, mapas del sitio, y funciones de ADA.
</details>

<details>

<summary>¿Se incluye un certificado SSL?</summary>

Sí, todos los sitios web alojados en nuestra plataforma reciben automáticamente certificaciones SSL.
</details>

<details>

<summary>¿Qué pasa con el sitio web si cancelo el alojamiento?</summary>

Una vez cancelado el alojamiento, tu sitio web se archivará por hasta 30 días. Puedes solicitar una copia de los archivos de tu sitio web antes de la cancelación.
</details>

<details>

<summary>¿Pueden instalar analíticas o seguimiento del sitio web?</summary>

Sí, si proporcionas las credenciales o los códigos de Google Tag Manager o Google Analytics, con gusto lo instalamos en tu sitio web.
</details>
