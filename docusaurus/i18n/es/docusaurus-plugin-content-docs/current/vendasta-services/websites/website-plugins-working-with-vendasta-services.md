## ¿Qué son los plugins de sitio web?

Un plugin de sitio web agrega funcionalidad adicional a un sitio web de WordPress que no se proporciona como una configuración estándar del constructor de sitios web.

Para las tiendas de WooCommerce (comercio electrónico) en WordPress, por ejemplo, puede ser necesario un plugin para habilitar opciones específicas de clasificación de productos para los clientes que navegan por tu tienda.

Para simplificar, los plugins de sitio web se pueden pensar como uno de dos formatos:

*   Rendimiento: estos plugins ayudan con funcionalidades del sitio como velocidad, seguridad, etc., y típicamente no son visibles para los visitantes del sitio en el front end.
*   Funcionales: estos plugins, como los widgets de reserva de citas y calendarios de eventos, pueden ser vistos/interactuados por los visitantes en el sitio.

## Advertencias sobre plugins a tener en cuenta

### Proceso de integración
Integrar un plugin y los widgets del plugin asociados puede ser tan simple como agregar una cadena de código de inserción al backend del sitio o tan complejo como pasar horas configurando todos los ajustes delicados para garantizar una funcionalidad fluida.

### Cargos/tarifas adicionales
Pueden requerirse cargos adicionales por hora para los plugins con configuraciones complejas que requieren más tiempo de integración. Para cotizar los costos adicionales de integración de plugins, consideramos muchos factores, incluida la referencia a los pasos de configuración, si están enumerados en las instrucciones de integración públicas del proveedor del plugin. Buscamos recomendar plugins que hayamos usado previamente y así podamos proporcionar información más clara sobre su funcionalidad dentro del sitio y qué se requiere para la configuración.

Si hay una solicitud de plugin que no hemos usado antes, necesitamos tiempo para investigarlo y asegurarnos de que podamos implementarlo con confianza.

### Interacción de plugins
Los plugins interactúan entre sí, así que aunque un plugin pueda estar destinado a un propósito, puede entrar en conflicto con otros plugins en un sitio específico y por lo tanto no ser utilizable. Este es el caso ya sea que construyas un sitio web con nosotros o con otro proveedor o desarrollador de sitios web. Desafortunadamente, es posible que no sepamos sobre el impacto negativo de los plugins hasta que se instalen.
