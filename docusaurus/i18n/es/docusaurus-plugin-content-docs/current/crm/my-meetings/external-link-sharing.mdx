## Descripción general

El uso compartido de enlaces externos te permite generar un enlace público a una grabación de reunión, un resumen generado por IA, y una transcripción que cualquiera puede ver, incluso si no forma parte de tu organización. Esto es útil cuando necesitas compartir una reunión grabada con un cliente, prospecto, o parte interesada externa sin requerir que inicie sesión.

:::note
Las funciones de inteligencia de conversación (grabación de reuniones, resúmenes de IA, asesoramiento de ventas, y puntuación de conversación) están disponibles con CRM AI Pro. Consulta [Ediciones de CRM AI](/ai/ai-workforce/ai-sales-assistant#crm-ai-editions) para más detalles.
:::

## ¿Qué es el uso compartido de enlaces externos?

El uso compartido de enlaces externos crea una URL pública para una reunión específica. Cualquiera con el enlace puede ver la grabación, el resumen generado por IA, y la transcripción sin necesitar una cuenta o iniciar sesión. El asesoramiento de ventas, las puntuaciones de conversación, y otras perspectivas internas no se incluyen en el enlace externo.

Esto es diferente del botón interno `Share` en la página Meeting Details, que controla la visibilidad dentro de tu organización. El uso compartido de enlaces externos está diseñado para audiencias fuera de tu empresa.

## ¿Por qué usar el uso compartido de enlaces externos?

- Comparte una demostración o presentación grabada con un prospecto después de una llamada
- Envía un resumen de reunión con puntos de acción a un cliente que no pudo asistir
- Proporciona una grabación y transcripción a un colaborador externo para revisión
- Comparte una sesión de capacitación o incorporación con socios

## ¿Quién puede habilitar o deshabilitar el uso compartido externo?

Solo los usuarios autorizados pueden habilitar o deshabilitar el uso compartido externo de una reunión. Estás autorizado si eres uno de los siguientes:

- El **host** de la reunión
- El **creador** del registro de la reunión
- Un **usuario autorizado** agregado a la reunión

También necesitas acceso de escritura a la reunión en el CRM.

:::warning
La reunión debe tener una grabación antes de que se pueda habilitar el uso compartido externo. Si la reunión no se ha grabado, la opción de compartir externamente no estará disponible.
:::

## Cómo compartir una reunión externamente

1. Abre el CRM.
2. En el menú de la izquierda, selecciona `CRM`, luego selecciona `My Meetings`.
3. Abre la pestaña `Recordings` y localiza la reunión que quieres compartir.
4. Haz clic en la reunión para abrir la página `Meeting Details`.
5. Selecciona la opción `External share`.
6. Habilita `Public access` para generar un enlace para compartir.
7. Copia el enlace y envíalo a cualquier persona con quien quieras compartir la reunión.

El enlace está listo para usarse de inmediato. Los destinatarios pueden ver la grabación, el resumen, y la transcripción abriendo el enlace en cualquier navegador.

## Cómo deshabilitar el uso compartido externo

1. Abre la reunión desde `My Meetings` y ve a la página `Meeting Details`.
2. Selecciona la opción `External share`.
3. Deshabilita `Public access`.

Una vez deshabilitado, el enlace público deja de funcionar. Cualquiera que intente abrir el enlace verá una página de no encontrado.

:::tip
Deshabilitar y volver a habilitar el uso compartido externo para la misma reunión produce el mismo enlace. No necesitas redistribuir una nueva URL si deshabilitas temporalmente el uso compartido y luego lo vuelves a activar.
:::

## Qué pueden ver los espectadores externos

Los espectadores externos que abren el enlace público pueden acceder a la grabación de la reunión, el resumen, y la transcripción. El asesoramiento de ventas, las puntuaciones de conversación, y otras perspectivas internas permanecen privadas para tu organización.

| Función | Incluido en el enlace externo |
|---------|--------------------------|
| Grabación de video de la reunión | Sí |
| Título, fecha, y duración de la reunión | Sí |
| Resumen generado por IA | Sí |
| Transcripción | Sí |
| Puntos de acción | Sí |
| Temas discutidos | Sí |
| Asesoramiento de ventas y puntuaciones | No |
| Detalles de invitados y participantes | No |

La transcripción en la página externa es de solo lectura. Los espectadores externos no pueden descargar ni copiar la transcripción.

## Cómo funcionan los enlaces externos

- Cada reunión obtiene un enlace público único la primera vez que se habilita el uso compartido externo.
- El enlace permanece igual incluso si el uso compartido se deshabilita y se vuelve a habilitar más tarde.
- El enlace no expira automáticamente.
- No se requiere inicio de sesión ni cuenta para ver la grabación, el resumen, o la transcripción.
- El enlace público es independiente de la configuración de visibilidad interna. Cambiar la visibilidad interna (`Private`, `All`, o `Anyone with the link`) no afecta al enlace externo, y viceversa.

## Buenas prácticas

- **Comparte de manera selectiva**
  Habilita el uso compartido externo solo para reuniones cuyo contenido sea apropiado para una audiencia externa. Recuerda que el resumen, la transcripción, y los puntos de acción también son visibles para cualquiera con el enlace.

- **Revisa el resumen y la transcripción antes de compartir**
  El resumen y la transcripción generados por IA pueden contener detalles sensibles discutidos durante la reunión. Revísalos antes de habilitar el acceso externo.

- **Deshabilita el uso compartido cuando ya no sea necesario**
  Si la audiencia externa ya no necesita acceso, deshabilita el acceso público para evitar que se siga viendo.

- **Comunica el contexto**
  Al enviar el enlace, incluye una breve nota explicando de qué trata la reunión para que el destinatario sepa qué esperar.

## Preguntas frecuentes

<details>
<summary>¿Cualquier persona en mi organización puede habilitar el uso compartido externo?</summary>

No. Solo el host de la reunión, el creador, o un usuario autorizado con acceso de escritura pueden habilitar o deshabilitar el uso compartido externo.

</details>

<details>
<summary>¿El enlace externo expira?</summary>

No. El enlace permanece activo mientras el acceso público esté habilitado. Si deshabilitas el acceso público, el enlace deja de funcionar pero no se elimina. Volver a habilitar el uso compartido restaura el mismo enlace.

</details>

<details>
<summary>¿Qué detalles de la reunión se incluyen en el enlace externo?</summary>

El enlace externo incluye la grabación de video, el resumen generado por IA, la transcripción, los puntos de acción, y los temas discutidos. El asesoramiento de ventas, las puntuaciones de conversación, y los detalles de los invitados no se incluyen.

</details>

<details>
<summary>¿Habilitar el uso compartido externo afecta la visibilidad interna?</summary>

No. El uso compartido externo y la visibilidad interna son configuraciones independientes. Cambiar una no afecta a la otra. Puedes tener una reunión interna privada con una grabación compartida públicamente, o viceversa.

</details>

<details>
<summary>¿Qué pasa si deshabilito el uso compartido externo?</summary>

El enlace público deja de funcionar de inmediato. Cualquiera que haga clic en el enlace verá una página de no encontrado. Si vuelves a habilitar el uso compartido más tarde, el mismo enlace se activa nuevamente.

</details>

<details>
<summary>¿Puedo hacer seguimiento de quién vio el enlace externo?</summary>

El seguimiento de vistas no está disponible actualmente para los enlaces externos.

</details>

<details>
<summary>¿Puedo proteger un enlace externo con contraseña?</summary>

La protección con contraseña no está disponible actualmente. Cualquiera con el enlace puede ver la grabación, el resumen, y la transcripción mientras el acceso público esté habilitado.

</details>

<details>
<summary>¿Por qué no veo la opción de compartir externamente?</summary>

El uso compartido externo requiere que la reunión tenga una grabación. Si la reunión no se grabó, o si la grabación aún se está procesando, la opción de uso compartido externo no aparecerá. También debes ser el host, creador, o un usuario autorizado para esa reunión.

</details>
