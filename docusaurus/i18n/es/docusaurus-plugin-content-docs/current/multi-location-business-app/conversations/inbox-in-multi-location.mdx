## ¿Qué es Conversations en Multi-Location?

Si usas Conversations AI Pro o Premium para gestionar la comunicación en varias ubicaciones, la función Multi-Location Conversations ofrece una solución optimizada. Multi-Location Conversations agrupa todas las conversaciones de varias cuentas en un solo Conversations. Esto permite a los equipos gestionar de manera eficiente la comunicación con clientes a través de Google Business Messages, Facebook, Instagram, SMS y conversaciones de Web Chat, todo dentro de una sola plataforma centralizada.

## Funciones clave

**Configuración sencilla:** puedes optar por usar Multi-Location Conversations haciendo clic en el botón `Start using multi-location conversations`. Esta acción trae las conversaciones pasadas y futuras de todas las cuentas dentro del grupo a un único Conversations, fácil de consultar.

**Mensajería entre canales:** Multi-Location Conversations admite comunicación en todos los canales disponibles, incluidos Web Chat (Pro), Email, Lead Capture Forms, SMS (Pro), Google Business Messages, Facebook e Instagram.

**Cerrar y abrir conversaciones:** las conversaciones se pueden "cerrar" dentro de Multi-Location Conversations, y este estado se refleja también en las cuentas de una sola ubicación.

**Compatible con móviles:** Multi-Location Conversations está diseñado para ser compatible con dispositivos móviles, lo que te permite mantenerte conectado y responder mensajes desde cualquier lugar.

:::note
Si tu equipo gestiona comunicaciones en varias ubicaciones, te recomendamos guardar Multi-Location Conversations como marcador y mantenerlo abierto durante todo el día para asegurar respuestas rápidas a los mensajes entrantes.
:::

**Configurar chat web asistido por IA para sitios web de franquicias**

Para marcas y franquicias con un sitio web principal, el [widget de chat web multiubicación](./multi-location-web-chat.mdx) te permite agregar un solo widget donde los visitantes eligen su ubicación y conversan con el AI Chat Receptionist propio de esa ubicación. Cada conversación, contacto y cliente potencial permanece con la ubicación correcta.

También puedes usar estos enfoques, según tu configuración:

- **Un widget de chat web único en el sitio de cada ubicación**: mejor cuando cada ubicación tiene su propio sitio web y equipo. Esto mantiene bases de datos de clientes potenciales y contactos separadas para cada ubicación.
- **Un único widget de "sede central"**: las franquicias con un equipo centralizado pueden designar una cuenta de una sola ubicación como la "sede central" e instalar el widget de chat web de esa cuenta para gestionar los clientes potenciales de forma centralizada.

## Cómo usar Multi-Location Conversations

1. Ve al grupo multiubicación deseado.
2. Haz clic en `Conversations`. Aquí podrás acceder a una vista unificada de todas las conversaciones de todas las cuentas dentro del grupo.
3. Selecciona `Start using multi-location conversations` para comenzar.

## Preguntas frecuentes

<details>
<summary>¿Cuánto tiempo tarda en cargarse todas las conversaciones después de hacer clic en "Start using multi-location conversations"?</summary>

El tiempo de carga varía según la cantidad de cuentas y conversaciones que se están agrupando. Puede tardar desde unos segundos hasta varios minutos. No hay una notificación de finalización, así que te recomendamos revisar de nuevo después de unos minutos.

</details>
