## ¿Qué son las APIs de Vendasta?

Vendasta ofrece APIs públicas que te permiten completar trabajo fuera de Partner Center mediante programación. También ofrecemos un entorno de pruebas (sandbox) para realizar pruebas de integración de forma segura antes de pasar a producción. Esta guía completa cubre la disponibilidad de las APIs, los productos compatibles y los entornos de prueba.

## ¿Por qué son importantes las APIs?

Las APIs (interfaces de programación de aplicaciones) te permiten:
- Integrar Vendasta con tus sistemas existentes
- Automatizar flujos de trabajo y la sincronización de datos
- Crear aplicaciones y soluciones personalizadas
- Ampliar la funcionalidad de los productos de Vendasta
- Crear experiencias de usuario coherentes en todas las plataformas

## Qué puedes hacer con las APIs de Vendasta

| Función | Descripción |
|---------|-------------|
| **Acceso a la API pública** | Conéctate a la plataforma de Vendasta mediante programación |
| **Integración de productos** | Intégrate con productos específicos de Vendasta a través de sus APIs |
| **Pruebas en sandbox** | Prueba las integraciones de forma segura antes de implementarlas en producción |
| **Desarrollo personalizado** | Crea tus propios productos usando las APIs para proveedores de Vendasta |

## Cómo acceder a las APIs de Vendasta

### Disponibilidad de la API pública

Para los partners en ciertos [niveles de suscripción de pago](https://www.vendasta.com/pricing/), ofrecemos varias APIs que te permiten completar trabajo fuera de Partner Center.

**APIs de plataforma y de producto:**
Puedes encontrar documentación detallada de la API para la plataforma y los productos de Vendasta en [https://developers.vendasta.com/platform](https://developers.vendasta.com/platform)

**APIs para proveedores:**
La documentación de la API para crear tus propios productos está disponible en [https://developers.vendasta.com/vendor](https://developers.vendasta.com/vendor) (sin requisitos de suscripción)

### Requisitos de acceso a la API

- Las APIs están disponibles para los partners en ciertos niveles de suscripción de pago
- Consulta la [página de precios de Vendasta](https://www.vendasta.com/pricing/) para conocer los detalles de la suscripción
- Las APIs para proveedores, destinadas a crear tus propios productos, no tienen requisitos de suscripción

## APIs de producto disponibles

### Productos con acceso a la API

Tenemos APIs para los siguientes productos:

- **Brand Analytics**: accede a datos de análisis e informes
- **Business App**: intégrate con las funciones de la aplicación de negocio
- **Partner Center**: administra cuentas, usuarios y configuraciones de la plataforma
- **Local SEO**: controla las funciones de optimización de búsqueda local
- **Reputation AI**: administra reseñas y datos de reputación
- **Social AI**: automatiza la publicación y la gestión en redes sociales
  - *Nota: la API no admite todas las funciones disponibles en el producto para Social AI*

### Productos sin acceso a la API actualmente

Actualmente no tenemos APIs para los siguientes productos o servicios:

- **Snapshot Report**: herramienta de informes de una sola vez
- **Task Manager**: funciones de gestión de tareas y flujo de trabajo
- **Informes de facturación**: acceso a datos financieros y de facturación

:::tip Desarrollo de la API
Consulta la [documentación para desarrolladores](https://developers.vendasta.com/platform) para ver la lista más actualizada de APIs disponibles y sus capacidades.
:::

## Entorno de sandbox

### ¿Qué es el entorno de sandbox?

Vendasta ofrece un entorno de sandbox para el trabajo de desarrollo inicial con nuevos partners que se integrarán con Vendasta mediante la API o SSO. Este entorno incorpora datos en vivo y es una excelente manera de realizar pruebas de integración.

### Beneficios del entorno de sandbox

- **Pruebas seguras**: prueba las integraciones sin afectar los datos de producción
- **Acceso a datos en vivo**: el entorno incorpora datos reales para pruebas realistas
- **Asistencia de soporte**: nuestro equipo de soporte responde preguntas durante las pruebas en sandbox
- **Validación previa a producción**: asegúrate de sentirte cómodo antes de migrar al entorno de producción

### Cómo acceder al entorno de sandbox

El entorno de sandbox está disponible para los partners que planean integraciones de API o SSO:

1. **Contacta a soporte**: comunícate con [support@vendasta.com](mailto:support@vendasta.com) para obtener acceso
2. **Proporciona los detalles de la integración**: comparte información sobre tu integración planificada
3. **Recibe acceso al sandbox**: obtén credenciales y acceso al entorno de pruebas
4. **Comienza a probar**: inicia el trabajo de desarrollo en el entorno de sandbox seguro

### Migración de sandbox a producción

Nuestro equipo de soporte:
- Te guiará durante las pruebas en sandbox
- Responderá preguntas sobre la integración
- Se asegurará de que te sientas cómodo con tu integración
- Te ayudará con la migración al entorno de producción cuando estés listo

## Primeros pasos con las APIs

### Requisitos previos

Antes de comenzar la integración con la API:
- Asegúrate de que tu suscripción incluya acceso a la API
- Revisa la documentación de la API correspondiente
- Planifica los requisitos de tu integración
- Considera solicitar acceso al sandbox para hacer pruebas

### Proceso de integración

1. **Fase de planificación**
   - Define los objetivos y requisitos de la integración
   - Revisa las APIs disponibles para tu caso de uso
   - Determina qué productos necesitan acceso a la API

2. **Fase de desarrollo**
   - Solicita acceso al entorno de sandbox
   - Comienza el desarrollo y las pruebas en el sandbox
   - Implementa la autenticación y el manejo de errores

3. **Fase de pruebas**
   - Prueba a fondo todos los puntos de integración
   - Valida el flujo de datos y los escenarios de error
   - Trabaja con el equipo de soporte para resolver problemas

4. **Fase de producción**
   - Completa las pruebas y validaciones finales
   - Migra al entorno de producción
   - Supervisa el rendimiento de la integración
