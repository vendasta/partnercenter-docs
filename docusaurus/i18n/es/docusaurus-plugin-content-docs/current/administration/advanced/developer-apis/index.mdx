Esta sección proporciona información completa sobre las ofertas de API de Vendasta y las opciones de integración para desarrolladores. Aquí encontrarás guías detalladas, documentación y recursos para conectarte con la plataforma de Vendasta mediante programación.

## Qué está disponible

### Recursos de la API
- **APIs públicas**: accede a los extremos y a la documentación de la API pública de Vendasta
- **Pruebas de integración**: configura entornos de sandbox para probar tus integraciones  
- **Productos de la API**: descubre qué productos tienen acceso a la API disponible
- **Integración con Zapier**: conéctate con Zapier para flujos de trabajo automatizados

### Herramientas para desarrolladores
- Documentación completa de la API y guías de referencia
- Entorno de sandbox para pruebas seguras
- Soporte y asistencia para la integración
- Ejemplos de código y mejores prácticas

## Guías completas

- [APIs y entorno](./apis-and-environment.mdx): APIs públicas, productos disponibles y entorno de sandbox para pruebas de integración
- [Integración con Zapier](./zapier-integration.mdx): guía completa de la integración con Zapier, activadores de automatización y configuración de flujos de trabajo

## Primeros pasos

1. **Revisa la documentación de la API**: visita [https://developers.vendasta.com/platform](https://developers.vendasta.com/platform) para ver la referencia completa de la API
2. **Verifica los requisitos de suscripción**: asegúrate de que tu suscripción incluya acceso a la API
3. **Solicita acceso al sandbox**: contacta a soporte para obtener el entorno de pruebas de integración
4. **Planifica tu integración**: determina qué APIs y productos satisfacen tus necesidades

## Soporte y recursos

Si necesitas ayuda con la integración de la API o tienes preguntas sobre los recursos para desarrolladores, contacta a [support@vendasta.com](mailto:support@vendasta.com) o comunícate con nuestro equipo de soporte.
