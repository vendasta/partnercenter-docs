Esta sección cubre la administración de cuentas de servicio para el acceso automatizado y las integraciones de sistema a sistema dentro de la plataforma de Vendasta.

:::info Seguridad de la API y del acceso
Vendasta mantiene un informe SOC 2® Tipo 2 vigente que cubre sus controles de seguridad. Para obtener detalles sobre cómo se protegen el acceso automatizado y las claves de API, consulta [Seguridad y privacidad](/getting-started/security-and-privacy) o visita el [Centro de confianza de Vendasta](https://trust.vendasta.com/).
:::

## Administración de cuentas de servicio

- Creación de cuentas: configura cuentas de servicio para procesos automatizados
- Administración de permisos: configura los niveles de acceso y los permisos de las cuentas de servicio
- Administración de claves de API: genera y administra claves de API para la autenticación de las cuentas de servicio
- Monitoreo de acceso: rastrea y supervisa el uso y la actividad de las cuentas de servicio
- Prácticas recomendadas de seguridad: pautas para una implementación segura de las cuentas de servicio

Si necesitas ayuda con las cuentas de servicio o tienes preguntas sobre el acceso automatizado, comunícate con nuestro equipo de soporte.
