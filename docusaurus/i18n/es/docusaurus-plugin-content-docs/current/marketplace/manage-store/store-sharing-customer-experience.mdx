Tu tienda de Marketplace es un escaparate orientado al cliente donde los prospectos pueden descubrir soluciones, comparar opciones y comprar. Compártela mediante incrustación en tu sitio web, enlaces directos o dentro de campañas de marketing.

## Descripción general del uso compartido de la tienda

Usa la `Public Store` como una tienda independiente e incrustable que se integra con tu gestión de clientes. Compártela mediante incrustación en tu sitio web, enlaces directos o dentro de campañas de marketing.

## Incrusta tu tienda en tu sitio web

1. Ve a `Partner Center` → `Marketplace` → `Manage Store` → `Public Store`
2. Elige una versión de incrustación:
   - `Store with sign-in`: incluye opciones de autenticación de clientes
   - `Store without sign-in`: experiencia simplificada sin interfaz de autenticación
   - `Store without sign-in and top bar`: interfaz mínima para una integración sencilla en el sitio web
3. Copia el fragmento de código de incrustación
4. Pégalo en el editor de HTML de tu sitio web

**Beneficios**
- Los productos y paquetes nuevos aparecen automáticamente en tu sitio web
- El contenido de la tienda aparece como parte de tu sitio web
- La configuración del tema garantiza la consistencia de marca
- Elige el mejor método de integración para el diseño de tu sitio

### Quita el botón "Sign In" al incrustar

Si quieres ocultar el botón Sign In en la Public Store incrustada:

1. Ve a `Partner Center` → `Marketplace` → `Manage Store` → `Public Store`
2. En Embed Code, selecciona `Store without sign-in` (o `Store without sign-in and top bar` para un encabezado mínimo)
3. Copia el código actualizado y reemplaza cualquier versión incrustada anteriormente en tu sitio web

## Comparte un enlace directo

1. Ve a `Partner Center` → `Marketplace` → `Manage Store` → `Public Store`
2. Copia la `Share URL`: un enlace directo a tu tienda independiente
3. Distribúyelo mediante firmas de correo electrónico, redes sociales, campañas de marketing o comunicación directa con el cliente

Encuentra la URL de tu tienda independiente en `Partner Center` → `Marketplace` → `Manage Store` → `Public Store` → `Copy Share URL`.

## Gestión de tiendas multimercado

Para los partners que usan Markets para atender a diferentes segmentos de clientes, elige qué tienda de mercado aparece en tu sitio web usando el `Market Selector` en `Marketplace` → `Manage Store`.
