## Que sont les API de Vendasta?

Vendasta propose des API publiques qui vous permettent d'effectuer des tâches en dehors de Partner Center de manière programmatique. Nous offrons également un environnement bac à sable pour effectuer des tests d'intégration en toute sécurité avant de passer en production. Ce guide complet couvre la disponibilité des API, les produits pris en charge et les environnements de test.

## Pourquoi les API sont-elles importantes?

Les API (interfaces de programmation d'application) vous permettent de :
- Intégrer Vendasta à vos systèmes existants
- Automatiser les flux de travail et la synchronisation des données
- Créer des applications et des solutions personnalisées
- Étendre les fonctionnalités des produits Vendasta
- Créer des expériences utilisateur cohérentes sur toutes les plateformes

## Ce que vous pouvez faire avec les API de Vendasta

| Fonctionnalité | Description |
|---------|-------------|
| **Accès à l'API publique** | Connectez-vous à la plateforme de Vendasta de manière programmatique |
| **Intégration de produits** | Intégrez des produits Vendasta spécifiques via leurs API |
| **Tests en bac à sable** | Testez vos intégrations en toute sécurité avant le déploiement en production |
| **Développement personnalisé** | Créez vos propres produits à l'aide des API fournisseur de Vendasta |

## Comment accéder aux API de Vendasta

### Disponibilité de l'API publique

Pour les partenaires ayant certains [niveaux d'abonnement payants](https://www.vendasta.com/pricing/), nous proposons un certain nombre d'API qui vous permettent d'effectuer des tâches en dehors de Partner Center.

**API de plateforme et de produit :**
Une documentation détaillée sur les API de la plateforme et des produits Vendasta est disponible sur [https://developers.vendasta.com/platform](https://developers.vendasta.com/platform)

**API fournisseur :**
La documentation des API pour créer vos propres produits est disponible sur [https://developers.vendasta.com/vendor](https://developers.vendasta.com/vendor) (aucun abonnement requis)

### Exigences d'accès à l'API

- Les API sont disponibles pour les partenaires ayant certains niveaux d'abonnement payants
- Consultez la [page de tarification de Vendasta](https://www.vendasta.com/pricing/) pour connaître les détails de l'abonnement
- Les API fournisseur permettant de créer vos propres produits ne nécessitent aucun abonnement

## API de produit disponibles

### Produits avec accès à l'API

Nous proposons des API pour les produits suivants :

- **Brand Analytics** - Accédez aux données d'analyse et de rapport
- **Business App** - Intégrez les fonctionnalités de l'application d'entreprise  
- **Partner Center** - Gérez les comptes, les utilisateurs et les paramètres de la plateforme
- **Local SEO** - Contrôlez les fonctionnalités d'optimisation pour la recherche locale
- **Reputation AI** - Gérez les avis et les données de réputation
- **Social AI** - Automatisez la publication et la gestion sur les réseaux sociaux
  - *Remarque : l'API ne prend pas en charge toutes les fonctionnalités disponibles dans le produit pour Social AI*

### Produits sans accès actuel à l'API

Nous n'avons actuellement pas d'API pour les produits/services suivants :

- **Snapshot Report** - Outil de rapport ponctuel
- **Task Manager** - Fonctionnalités de gestion des tâches et des flux de travail
- **Rapports de facturation** - Accès aux données financières et de facturation

:::tip Développement d'API
Consultez la [documentation pour développeurs](https://developers.vendasta.com/platform) pour obtenir la liste la plus à jour des API disponibles et de leurs fonctionnalités.
:::

## Environnement bac à sable

### Qu'est-ce que l'environnement bac à sable?

Vendasta propose un environnement bac à sable pour le travail de développement initial avec les nouveaux partenaires qui souhaitent s'intégrer à Vendasta via API et/ou SSO. Cet environnement utilise des données en direct et constitue un excellent moyen d'effectuer des tests d'intégration.

### Avantages de l'environnement bac à sable

- **Tests sécurisés** - Testez vos intégrations sans affecter les données de production
- **Accès aux données en direct** - L'environnement utilise des données réelles pour des tests réalistes
- **Assistance du support** - Notre équipe d'assistance répond aux questions pendant les tests en bac à sable
- **Validation avant production** - Assurez-vous d'être à l'aise avant de migrer vers l'environnement de production

### Comment accéder à l'environnement bac à sable

L'environnement bac à sable est disponible pour les partenaires qui envisagent des intégrations API et/ou SSO :

1. **Contactez le support** - Contactez [support@vendasta.com](mailto:support@vendasta.com) pour obtenir un accès
2. **Fournissez les détails de l'intégration** - Partagez des informations sur votre intégration prévue
3. **Recevez l'accès au bac à sable** - Obtenez des identifiants et un accès à l'environnement de test
4. **Commencez les tests** - Démarrez le travail de développement dans l'environnement bac à sable sécurisé

### Migration du bac à sable vers la production

Notre équipe d'assistance :
- Vous guidera tout au long des tests en bac à sable
- Répondra aux questions relatives à l'intégration
- S'assurera que vous êtes à l'aise avec votre intégration
- Vous aidera à migrer vers l'environnement de production lorsque vous serez prêt

## Démarrer avec les API

### Prérequis

Avant de commencer l'intégration de l'API :
- Assurez-vous que votre abonnement inclut l'accès à l'API
- Consultez la documentation d'API pertinente
- Planifiez les exigences de votre intégration
- Envisagez de demander un accès au bac à sable pour les tests

### Processus d'intégration

1. **Phase de planification**
   - Définissez les objectifs et les exigences de l'intégration
   - Consultez les API disponibles pour votre cas d'utilisation
   - Déterminez quels produits nécessitent un accès à l'API

2. **Phase de développement**
   - Demandez l'accès à l'environnement bac à sable
   - Commencez le développement et les tests dans le bac à sable
   - Mettez en œuvre l'authentification et la gestion des erreurs

3. **Phase de test**
   - Testez minutieusement tous les points d'intégration
   - Validez le flux de données et les scénarios d'erreur
   - Travaillez avec l'équipe d'assistance pour résoudre les problèmes

4. **Phase de production**
   - Effectuez les tests et validations finaux
   - Migrez vers l'environnement de production
   - Surveillez les performances de l'intégration
