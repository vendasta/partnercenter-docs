Cette section fournit des informations complètes sur les offres d'API de Vendasta et les options d'intégration pour les développeurs. Vous y trouverez des guides détaillés, de la documentation et des ressources pour vous connecter à la plateforme de Vendasta de manière programmatique.

## Ce qui est disponible

### Ressources API
- **API publiques** - Accédez aux points de terminaison de l'API publique de Vendasta et à sa documentation
- **Tests d'intégration** - Configurez des environnements bac à sable pour tester vos intégrations  
- **Produits API** - Découvrez quels produits disposent d'un accès à l'API
- **Intégration Zapier** - Connectez-vous à Zapier pour des flux de travail automatisés

### Outils pour développeurs
- Documentation complète et guides de référence sur l'API
- Environnement bac à sable pour des tests sécurisés
- Support et assistance à l'intégration
- Exemples de code et bonnes pratiques

## Guides complets

- [API et environnement](./apis-and-environment.mdx) - API publiques, produits disponibles et environnement bac à sable pour les tests d'intégration
- [Intégration Zapier](./zapier-integration.mdx) - Guide complet sur l'intégration Zapier, les déclencheurs d'automatisation et la configuration des flux de travail

## Démarrer

1. **Consultez la documentation de l'API** - Visitez [https://developers.vendasta.com/platform](https://developers.vendasta.com/platform) pour la référence complète de l'API
2. **Vérifiez les exigences d'abonnement** - Assurez-vous que votre abonnement inclut l'accès à l'API
3. **Demandez un accès au bac à sable** - Contactez le support pour obtenir un environnement de test d'intégration
4. **Planifiez votre intégration** - Déterminez quelles API et quels produits répondent à vos besoins

## Support et ressources

Si vous avez besoin d'aide pour l'intégration de l'API ou si vous avez des questions sur les ressources pour développeurs, contactez [support@vendasta.com](mailto:support@vendasta.com) ou joignez notre équipe d'assistance.
