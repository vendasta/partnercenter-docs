Configurez le fonctionnement des commandes et les actions que les vendeurs et les administrateurs peuvent effectuer. `Partner Center` → `Administration` → `Order Settings`.

## Ce que vous pouvez contrôler

### Configuration des étapes du workflow (vendeurs)

Activez ou restreignez des comportements pour les utilisateurs de vente :

- Configurer les étapes du workflow pour les vendeurs
- Retirer `Terms and Conditions` uniquement lors du renvoi d'une commande pour approbation
- Autoriser les vendeurs à modifier les formulaires de commande jusqu'à l'activation
- Exiger que les vendeurs remplissent tous les champs du formulaire avant d'envoyer une commande
- Empêcher les vendeurs de vendre des produits autonomes sur les opportunités et les commandes
- Empêcher les vendeurs d'ajouter des tags aux commandes
- Autoriser les clients à envoyer une commande aux administrateurs depuis une page de boutique

### Actions de soumission des vendeurs

Contrôlez ce que les vendeurs peuvent faire lors de la soumission des commandes :

- Autoriser les vendeurs à envoyer directement les commandes aux administrateurs
- Autoriser les vendeurs à débiter le moyen de paiement enregistré du client lors de la soumission d'une commande
- Autoriser les vendeurs à envoyer les commandes aux clients pour approbation
- Les commandes envoyées pour approbation par les vendeurs peuvent accepter un paiement

### Actions de soumission des administrateurs

- Les administrateurs peuvent contourner le workflow d'approbation et activer les commandes instantanément

### Contenu par défaut

Vous pouvez ajouter des formulaires de référence internes à chaque commande.

:::info
Les champs de contenu par défaut sont réservés à un usage interne et **ne seront pas visibles pour les fournisseurs**.
:::

### Conditions de service pour le client

Définissez les conditions de service qui apparaissent sur une commande lorsqu'elle est envoyée pour approbation au client.

### Modèles d'e-mail

Configurez ces e-mails destinés aux clients :

- **Contrat en attente d'approbation**
- **Commande traitée**
- **Commande refusée**
