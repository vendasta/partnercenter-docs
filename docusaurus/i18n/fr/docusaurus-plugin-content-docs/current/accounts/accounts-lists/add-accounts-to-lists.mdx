## Ajouter des comptes individuels à des listes

Pour ajouter un compte individuel à une liste :

1. Allez dans `Partner Center` → `Accounts` → `Manage Accounts`.
2. Trouvez le compte que vous souhaitez ajouter à la liste. Cliquez sur l'icône `menu` ![Menu icon](./img/accounts/lists/menu-icon.jpg) à la fin de la ligne.
3. Cliquez sur `Add to List`.
4. Ajoutez le compte à une liste :
   a. Si vous souhaitez ajouter les comptes à une liste existante :
      i. Sélectionnez la liste existante dans le menu déroulant.
      ii. Cliquez sur `Add`.
   b. Si vous souhaitez ajouter les comptes à une nouvelle liste :
      i. Allez dans l'onglet `Create New List`.
      ii. Entrez un nom pour la liste.
      iii. Cliquez sur `Create and Add`.

## Ajouter plusieurs comptes à des listes

Pour ajouter plusieurs comptes à une liste :

1. Allez dans `Partner Center` → `Accounts` → `Manage Accounts`.
2. Filtrez et recherchez les comptes que vous souhaitez ajouter à une liste.
   :::note
   Vous pouvez utiliser les filtres et la barre de recherche pour trouver vos comptes.
   :::
3. Cliquez sur `Add # to List`.
4. Ajoutez les comptes à une liste :
   a. Si vous souhaitez ajouter les comptes à une nouvelle liste :
      i. Entrez un nom pour la liste.
      ii. Cliquez sur `Create and Add`.
   b. Si vous souhaitez ajouter les comptes à une liste existante :
      i. Allez dans l'onglet `Add to List`.
      ii. Sélectionnez la liste existante dans le menu déroulant.
      iii. Cliquez sur `Add`.

## Supprimer des comptes de listes

1. Allez dans `Partner Center` → `Accounts` → `Lists`.
2. Cliquez sur le nom de la liste.
3. Trouvez le compte, ouvrez le menu de la ligne et sélectionnez `Remove from list`.
4. Confirmez la suppression.

## Foire aux questions

<details>
<summary>Puis-je ajouter le même compte à plusieurs listes ?</summary>

Oui. Vous pouvez ajouter un compte à autant de listes que nécessaire. Cela est utile lorsque vous souhaitez organiser les comptes de différentes manières, par exemple en ayant un compte à la fois dans une liste « Abonnés à la newsletter » et dans une liste « Clients Premium ».
</details>

<details>
<summary>Que se passe-t-il si j'essaie d'ajouter un compte déjà présent dans la liste ?</summary>

Le système empêche les doublons. Si vous essayez d'ajouter un compte déjà présent dans une liste, le compte n'est pas ajouté à nouveau, et aucun message d'erreur ne s'affiche.
</details>

<details>
<summary>Existe-t-il une limite au nombre de comptes que je peux ajouter à une liste en une seule fois ?</summary>

Lorsque vous utilisez la fonction d'ajout en masse, vous pouvez ajouter n'importe quel nombre de comptes filtrés à une liste. Cependant, pour des performances optimales, il est recommandé de travailler par lots pouvant aller jusqu'à 1000 comptes à la fois lors des opérations en masse.
</details>
