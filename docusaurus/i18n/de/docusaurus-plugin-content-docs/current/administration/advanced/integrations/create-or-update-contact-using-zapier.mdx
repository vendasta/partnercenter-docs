Die Vendasta App in Zapier ermöglicht es Ihnen, Ihr Vendasta CRM mit mehreren Drittsystemen über Zapier zu verbinden. Sie können jedes in Zapier verfügbare Drittsystem als Trigger auswählen, der eine Aktion im Vendasta CRM auslöst.

## Schritt 1: Den Trigger auswählen

In diesem Schritt wählen Sie den Trigger aus, der eine Aktion in Ihrem Workflow auslöst. Als Beispiel kann ein neuer Kunde in Quickbooks Online als Trigger verwendet werden, Sie können aber auch aus verschiedenen anderen in Zapier verfügbaren Triggern wählen.

## Schritt 2: Die Aktion auswählen

Nachdem Sie den Trigger ausgewählt haben, müssen Sie die App auswählen, die die gewünschte Aktion ausführt. In diesem Szenario wäre das die Vendasta App. Das bedeutet, dass immer dann, wenn in Quickbooks Online ein neuer Kunde hinzugefügt wird, eine Aktion im Vendasta CRM ausgeführt wird. Im Rahmen der Vendasta App in Zapier sind verschiedene Aktionen möglich.

![Auswahl der Zapier-Aktion](./img/integrations/zapier/zapier_action.jpg)

## Schritt 3: Die Aktion „Erstellen oder aktualisieren“ auswählen

In diesem Schritt legen Sie die Aktion fest, die ausgeführt werden soll, wenn das Trigger-Ereignis eintritt. Für dieses Szenario besteht die Aktion darin, einen Kontakt im Vendasta CRM zu erstellen oder zu aktualisieren.

Denken Sie daran, dass Sie die Aktion jederzeit ändern können, indem Sie auf das Dropdown-Menü klicken und eine andere Option auswählen. Klicken Sie nach der Auswahl der Aktion auf `Continue`, um mit dem nächsten Schritt fortzufahren.

![Auswahl der Zapier-Aktion „Erstellen/Aktualisieren“](./img/integrations/zapier/zapier_select_action.jpg)

## Schritt 4: Anmelden

In diesem Schritt verbinden Sie Ihr Vendasta-Konto. Klicken Sie auf `Sign in`, um zur Anmeldeseite weitergeleitet zu werden. Geben Sie dort Ihre Partner-ID oder die Account-ID des KMU ein, für das Sie Zapier einrichten, und erteilen Sie die erforderlichen Berechtigungen. Danach werden Sie automatisch zurück zu Zapier weitergeleitet.

:::note
Sie müssen diesen Vorgang nur einmal durchführen. Künftig werden Sie bei der Nutzung der Vendasta App automatisch bei Ihrem Konto angemeldet.
:::

![Zapier-Kontoverbindung](./img/integrations/zapier/zapier_connect.jpg)

![Zapier-Authentifizierung](./img/integrations/zapier/zapier_auth.jpg)

## Schritt 5: Die Organisations-ID eingeben

In diesem Schritt müssen Sie die Organisations-ID eingeben, die ein Pflichtfeld ist. Diese ID wird automatisch anhand der Account-ID ausgefüllt, mit der Sie sich angemeldet haben.

![Zapier-Organisations-ID](./img/integrations/zapier/zapier_org_id.jpg)

## Schritt 6: Felder zum Erstellen oder Aktualisieren: Suchfelder

Im Abschnitt `Fields to Create or Update` können Sie Werte für die Felder eingeben, die Sie erstellen oder aktualisieren möchten. Diese Werte können aus vorherigen Schritten in Zapier stammen.

Um die Erstellung doppelter Einträge zu vermeiden, geben Sie unbedingt Werte für mindestens ein Suchfeld an. Dies können die standardmäßig bereitgestellten Felder E-Mail oder Telefonnummer sein, oder jedes andere Suchfeld, das Sie im Bereich „Advanced“ einrichten können.

![Zapier-Suchfelder](./img/integrations/zapier/zapier_search_fields.jpg)

## Schritt 7: Felder zum Erstellen oder Aktualisieren: Standardfelder

Dieser Abschnitt enthält eine Reihe von Standardfeldern, die Sie beim Erstellen oder Aktualisieren eines Kontakts verwenden können. Sie können diese Felder mit Werten aus vorherigen Schritten in Zapier befüllen.

Außerdem finden Sie hier ein Dropdown-Menü `Additional Fields`. Verwenden Sie dieses, um dem Abschnitt `Fields to Create or Update` weitere Felder hinzuzufügen. Nach dem Hinzufügen können Sie diesen Feldern Werte zuweisen.

![Zapier-Standardfelder](./img/integrations/zapier/zapier_standard_fields.jpg)

## Schritt 8: Bereich „Advanced“: zusätzliche Suchfelder

Im Bereich `Advanced` haben Sie die Möglichkeit, Ihre Kontaktsuche zu verfeinern. Standardmäßig sucht das System zunächst nach Kontakten anhand der E-Mail-Adresse und dann anhand der Telefonnummer. Sie können jedoch zusätzliche eindeutige Felder angeben, um Kontakte während der Suche zu identifizieren.

Verwenden Sie dazu das Dropdown-Menü `Additional Search Fields`. Damit können Sie zusätzliche Felder für die Suche auswählen. Sie können diese Felder in der Reihenfolge ihrer Priorität auflisten, um eine passgenauere Suche zu erhalten.

:::note
Sie können zusätzliche Suchfelder nur aus den im Abschnitt `Fields to Create or Update` vorhandenen Feldern auswählen. Wenn Sie ein neues Feld verwenden möchten, fügen Sie es zunächst über die Option `Additional Fields` im Abschnitt `Fields to Create or Update` hinzu. Danach können Sie es im Dropdown-Menü `Additional Search Fields` auswählen.
:::

![Zusätzliche Zapier-Suchfelder](./img/integrations/zapier/zapier_additional_search.jpg)

## Schritt 9: Bereich „Advanced“: vorhandene Daten überschreiben

Standardmäßig werden im Abschnitt `Fields to Create or Update` nur Felder ohne aktuellen Wert aktualisiert. Wenn Sie dies ändern und vorhandene Daten überschreiben möchten, verwenden Sie die Option `Overwrite Existing Data`.

Klicken Sie auf das Dropdown-Menü `Overwrite Existing Data`, um bestimmte Felder auszuwählen, die immer überschrieben werden sollen, unabhängig davon, ob sie leer sind oder bereits Daten enthalten.

:::note
Das Überschreiben vorhandener Daten kann in bestimmten Szenarien nützlich sein, sollte aber mit Vorsicht verwendet werden, um unbeabsichtigten Datenverlust zu vermeiden.
:::

![Zapier vorhandene Daten überschreiben](./img/integrations/zapier/zapier_overwrite.jpg)

## Schritt 10: Ein Unternehmen zuordnen

In diesem Schritt haben Sie die Möglichkeit, ein Unternehmen mit dem Kontakt zu verknüpfen, den Sie erstellen oder aktualisieren. Wenn Sie dies tun möchten, geben Sie die Unternehmens-ID in das dafür vorgesehene Textfeld `Company ID for Association (Optional)` ein.

:::note
Dies ist ein optionaler Schritt. Wenn Sie die Unternehmens-ID nicht zur Hand haben, können Sie das Feld leer lassen und mit dem nächsten Schritt fortfahren.
:::

![Zapier-Unternehmenszuordnung](./img/integrations/zapier/zapier_company.jpg)

## Schritt 11: Rückgabefelder aus dem CRM auswählen

Nachdem ein Kontakt im CRM erstellt oder aktualisiert wurde, können Sie auswählen, welche Felder zurückgegeben werden sollen. Diese Felder können in späteren Schritten dieses Zaps verwendet werden.

Um die Rückgabefelder auszuwählen, klicken Sie auf das Dropdown-Menü unter `Return Fields` und wählen Sie die spezifischen Felder aus, die aus dem CRM zurückgegeben werden sollen.

:::note
Die Kontakt-ID ist standardmäßig immer als Rückgabefeld enthalten.
:::

![Zapier-Rückgabefelder](./img/integrations/zapier/zapier_return_fields.jpg)
