Wenn Sie der Meinung sind, dass eine Belastung auf Ihrer Vendasta-Rechnung falsch ist, oder Sie eine Rückerstattung beantragen möchten, reichen Sie eine Abrechnungsanfrage ein. Sie geht direkt an unser Finance-Team, das jede Anfrage prüft und per E-Mail antwortet.

Einreichen unter: **[billingrequests.vendasta.com](https://billingrequests.vendasta.com)**

## Bevor Sie beginnen

Halten Sie Folgendes bereit, bevor Sie eine Anfrage einreichen:

- Ihre **Partner ID (PID)**
- Die **Purchase ID** für jede Belastung, zu der Sie eine Frage haben
- Eine kurze Erklärung dessen, was passiert ist
- Optional: Screenshots, Rechnungen oder E-Mails, die Ihre Anfrage untermauern

## So reichen Sie eine Abrechnungsanfrage ein

### Finden Sie Ihre Partner ID

1. Melden Sie sich bei [Partner Center](https://partners.vendasta.com) an
2. Ihre PID erscheint auf den meisten Seiten oben links sowie in der Adressleiste Ihres Browsers
3. Kopieren Sie sie in das Feld Partner ID im Formular

<img src={require('./img/find-partner-id.png').default} alt="Partner ID (PID) oben links in Partner Center hervorgehoben" style={{width: '100%', border: '1px solid #e0e0e0', borderRadius: '8px', boxShadow: '0 2px 8px rgba(0,0,0,0.08)'}} />

### Finden Sie Ihre Purchase ID

1. Gehen Sie in Partner Center zu `Administration` → `My billing`
2. Suchen Sie die Belastung, zu der Sie eine Frage haben
3. Kopieren Sie deren Purchase ID in das Formular

<img src={require('./img/find-purchase-id.png').default} alt="Purchase ID im Tab By Purchase von Billing & Payments hervorgehoben" style={{width: '100%', border: '1px solid #e0e0e0', borderRadius: '8px', boxShadow: '0 2px 8px rgba(0,0,0,0.08)'}} />

:::tip
Um mehr als eine Belastung anzugeben, geben Sie eine Purchase ID ein, drücken Sie **Enter** und fügen Sie die nächste hinzu.
:::

### Reichen Sie Ihre Anfrage ein

1. Gehen Sie zu **billingrequests.vendasta.com**
2. Geben Sie Ihre Unternehmensinformationen ein, einschließlich Ihrer PID
3. Wählen Sie die Grundkategorie, die am besten passt: **Activation error**, **Product failure / bug**, **Billing error / duplicate charge**, **Dissatisfaction**, **Cancellation within window** oder **Other**
4. Erklären Sie, was passiert ist, wann, und was Sie stattdessen erwartet hätten – konkrete Details führen zu schnelleren Entscheidungen
5. Geben Sie den Betrag ein. Ihre beste Schätzung reicht aus; Finance bestätigt den endgültigen Betrag
6. Fügen Sie alles an, was Ihre Anfrage untermauert. Anfragen mit Nachweisen werden schneller bearbeitet
7. Senden Sie die Anfrage ab. Sie erhalten eine Bestätigung mit Ihrer Anfragenummer (beginnt mit **CR**). Bewahren Sie diese für eine mögliche Nachverfolgung auf

## Was als Nächstes passiert

1. Sie erhalten eine Bestätigungs-E-Mail mit Ihrer CR-Nummer
2. Finance prüft die Anfrage innerhalb von **2 Werktagen** (bis zu 5 in stark ausgelasteten Zeiten) und schreibt Ihnen per E-Mail, falls weitere Details benötigt werden
3. Sie erhalten die Entscheidung mit dem Ergebnis der Anfrage per E-Mail

## Berechtigung

Berechtigung und Fristen werden durch die **Terms of Service** von Vendasta festgelegt, verfügbar unter [trust.vendasta.com](https://trust.vendasta.com/). Wenn eine Belastung falsch erscheint, reichen Sie eine Anfrage ein, sobald Sie es bemerken.

## Häufig gestellte Fragen

<details>
<summary>Kann ich mehrere Belastungen in einer Anfrage angeben?</summary>

Ja. Geben Sie jede Purchase ID ein und drücken Sie zwischen ihnen **Enter**.
</details>

<details>
<summary>Bekomme ich mein Geld zurück?</summary>

Finance prüft jede Anfrage und entscheidet von Fall zu Fall über das Ergebnis. Das Einreichen einer Anfrage ist keine Garantie dafür, dass sie genehmigt wird.
</details>

<details>
<summary>Wie lange dauert eine Entscheidung?</summary>

In der Regel 2 Werktage, bis zu 5 in stark ausgelasteten Zeiten.
</details>

<details>
<summary>Muss ich Unterlagen hochladen?</summary>

Es ist optional, wird aber dringend empfohlen. Anfragen mit Nachweisen werden schneller entschieden.
</details>
