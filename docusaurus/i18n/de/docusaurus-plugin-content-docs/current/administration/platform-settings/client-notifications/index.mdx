# Benachrichtigungseinstellungen von Partner Center

Benachrichtigungen von Partner Center halten Sie und Ihr Team über Aktivitäten bei Bestellungen, Aufgaben, Produkten und mehr auf dem Laufenden. Bevor eine einzelne Benachrichtigung ausgelöst werden kann, muss der Hauptschalter aktiviert sein.

## Der Hauptschalter für Benachrichtigungen

Der Hauptschalter steuert alle Benachrichtigungen. Wenn er ausgeschaltet ist, werden keine Benachrichtigungen gesendet – unabhängig von den einzelnen Einstellungen.

So aktivieren Sie ihn:

1. Gehen Sie zu `Partner Center` → `Administration` → `Client Notifications`
2. Suchen Sie **Global Settings** (in einigen Ansichten auch **All Notifications** genannt)
3. Schalten Sie den Schalter **on**

Sobald der Hauptschalter aktiviert ist, können die Benachrichtigungseinstellungen für jeden Produkt- und Plattformbereich einzeln konfiguriert werden.

:::warning
Wenn Sie Benachrichtigungen für bestimmte Produkte aktiviert haben, aber nichts erhalten, prüfen Sie zuerst den Hauptschalter – das ist die häufigste Ursache.
:::

## Platform Settings vs. User Settings

Benachrichtigungen können auf zwei verschiedenen Ebenen konfiguriert werden:

| Ebene | Wer konfiguriert sie | Was sie steuert |
|---|---|---|
| **Platform Settings** | Partner-Center-Administrator | Benachrichtigungen für das gesamte Partnerkonto (z. B. alle Verkaufsaufträge, unabhängig davon, wer sie aufgegeben hat) |
| **User Settings** | Einzelner Benutzer | Benachrichtigungen, die nur für diesen Benutzer relevant sind (z. B. nur Verkaufsaufträge, an denen er beteiligt ist) |

**Wann Platform Settings verwendet werden sollten:** Nutzen Sie diese Ebene für teamweite Transparenz – zum Beispiel, um Ihr gesamtes Verkaufsteam zu benachrichtigen, wenn eine Bestellung aufgegeben wird.

**Wann User Settings verwendet werden sollten:** Nutzen Sie diese Ebene für persönliche Relevanz – zum Beispiel für einen Verkäufer, der nur über seine eigenen Konten oder Aufgaben benachrichtigt werden möchte.

:::info
Platform Settings werden von Administratoren verwaltet und gelten für das gesamte Team. Benutzer können ihre eigenen User Settings anpassen, ohne andere zu beeinflussen.
:::

## Zustellung per App oder E-Mail

Für jede Benachrichtigung können Sie wählen, wie sie zugestellt wird:

- **App** — Die Benachrichtigung erscheint im Benachrichtigungsbereich von Partner Center
- **Email** — Die Benachrichtigung wird an die E-Mail-Adresse des Benutzers gesendet
- Beide Optionen können gleichzeitig aktiviert werden

Konfigurieren Sie die Zustellung für jeden Benachrichtigungstyp unter `Administration` → `Client Notifications` und erweitern Sie dann das jeweilige Produkt oder den jeweiligen Bereich.

## Benachrichtigungen pro Produkt konfigurieren

Nachdem Sie den Hauptschalter aktiviert haben, erweitern Sie jeden Produktabschnitt, um dessen Benachrichtigungen zu konfigurieren:

- **Business App** — Aktivitäten innerhalb der Business App Ihrer Kunden
- **Review Management** — neue Bewertungen und Antworten
- **Social AI** — Veröffentlichung von Beiträgen und Kampagnenaktivitäten
- **WordPress Hosting** — Website-Änderungen und Warnungen
- **Orders and Commerce** — Bestellungen, Auftragsabwicklung und Abrechnungsereignisse
- **Task Manager** — Aufgabenzuweisungen, Updates und Abschlüsse

Aktivieren oder deaktivieren Sie einzelne Benachrichtigungstypen innerhalb jedes Abschnitts und legen Sie die Zustellung per App und/oder E-Mail für jeden Typ fest.

## Häufige Fragen

**Ich habe eine Benachrichtigung aktiviert, erhalte sie aber nicht.**
Prüfen Sie den Hauptschalter unter `Administration` → `Client Notifications` → `Global Settings`. Wenn er ausgeschaltet ist, werden unabhängig von den einzelnen Einstellungen keine Benachrichtigungen ausgelöst.

**Ich erhalte zu viele Benachrichtigungen.**
Wechseln Sie von Platform Settings zu User Settings, damit Sie nur Benachrichtigungen zu Ihrer eigenen Aktivität erhalten, statt zu allen Aktivitäten im gesamten Konto.

**Die Benachrichtigungen eines Teammitglieds funktionieren nicht.**
Bestätigen Sie, dass der Hauptschalter aktiviert ist, und prüfen Sie dann, ob der jeweilige Benachrichtigungstyp unter Platform Settings aktiviert ist. Der einzelne Benutzer kann auch seine eigenen User Settings überprüfen.

**Benachrichtigungen sind aktiviert, aber die E-Mail kommt nicht an.**
Bestätigen Sie, dass die E-Mail-Zustellung für diesen Benachrichtigungstyp aktiviert ist. Prüfen Sie außerdem den Spam- oder Junk-Ordner und überprüfen Sie die E-Mail-Adresse des Benutzers in seinem Profil.
