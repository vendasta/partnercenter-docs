Visual Visitor verfügt über ein eigenes Benachrichtigungssystem, das von den Benachrichtigungen von Partner Center getrennt ist. Die Benachrichtigungsregeln von Visual Visitor werden **innerhalb des Produkts Visual Visitor** konfiguriert, nicht unter `Partner Center` → `Administration` → `Client Notifications`.

## Wo Sie die Benachrichtigungsregeln finden

1. Öffnen Sie `Business App`
2. Navigieren Sie zu `Visual Visitor`
3. Gehen Sie zu `Lead Handling` → `Notification Rules`

## Verfügbare Regeltypen

Visual Visitor bietet fünf Arten von Benachrichtigungsregeln:

| Regeltyp | Was sie bewirkt |
|---|---|
| `Instant Email Alert` | Sendet sofort eine E-Mail, wenn eine verfolgte Besucheraktivität auftritt |
| `Daily Email Report` | Sendet eine Zusammenfassung der Besucheraktivität des Vortags |
| `Weekly Email Report` | Sendet eine Zusammenfassung der Besucheraktivität der Vorwoche |
| `Watch List Email Alert` | Sendet eine Benachrichtigung, wenn ein bestimmtes Unternehmen oder ein Kontakt auf Ihrer Watch List Sie besucht |
| `URL Email Alert` | Sendet eine Benachrichtigung, wenn ein Besucher auf einer von Ihnen verfolgten bestimmten URL landet |

## So aktivieren und konfigurieren Sie eine Regel

1. Suchen Sie unter `Lead Handling` → `Notification Rules` den Regeltyp, den Sie konfigurieren möchten
2. Aktivieren Sie die Regel über den Schalter
3. Legen Sie die Empfänger fest (E-Mail-Adressen, die benachrichtigt werden sollen)
4. Konfigurieren Sie alle Filter oder Schwellenwerte, die für diesen Regeltyp spezifisch sind
5. Klicken Sie auf `Update My Notification Rules`, um zu speichern

:::tip
Klicken Sie nach jeder Änderung auf `Update My Notification Rules`, da nicht gespeicherte Änderungen sonst nicht wirksam werden.
:::

## Versandzeiten der Berichte

- **Daily Email Reports** werden jeden Morgen gegen **3:00 Uhr Eastern Time** gesendet und umfassen die Aktivität des Vortags
- **Weekly Email Reports** werden montags gegen **3:00 Uhr Eastern Time** gesendet und umfassen die Aktivität der Vorwoche

## Häufige Fragen

**Ich habe in Partner Center → Notifications nachgesehen, konnte aber keine Einstellungen für Visual Visitor finden.**
Benachrichtigungen von Visual Visitor werden innerhalb des Produkts Visual Visitor selbst verwaltet, nicht in den zentralen Benachrichtigungseinstellungen von Partner Center. Gehen Sie zu `Business App` → `Visual Visitor` → `Lead Handling` → `Notification Rules`.

**Ich habe eine Regel aktiviert, erhalte aber keine E-Mails.**
Bestätigen Sie, dass Sie nach dem Aktivieren der Regel auf `Update My Notification Rules` geklickt haben. Überprüfen Sie außerdem, ob die als Empfänger angegebene E-Mail-Adresse korrekt ist.

**Zu welcher Uhrzeit kommt der Daily Report an?**
Tägliche Berichte werden jeden Morgen gegen 3:00 Uhr Eastern Time gesendet.

**Kann ich mit einer Regel mehrere Personen benachrichtigen?**
Ja. Fügen Sie beim Konfigurieren der Regel mehrere E-Mail-Adressen als Empfänger hinzu.
