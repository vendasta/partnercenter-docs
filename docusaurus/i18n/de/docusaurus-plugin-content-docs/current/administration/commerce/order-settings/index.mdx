Konfigurieren Sie, wie sich Bestellungen verhalten und welche Aktionen Vertriebsmitarbeiter und Admins ausführen können. `Partner Center` → `Administration` → `Order Settings`.

## Was Sie steuern können

### Workflow-Schrittkonfiguration (Vertriebsmitarbeiter)

Aktivieren oder beschränken Sie Verhaltensweisen für Vertriebsbenutzer:

- Workflow-Schritte für Vertriebsmitarbeiter konfigurieren
- `Terms and Conditions` nur beim erneuten Senden einer Bestellung zur Genehmigung entfernen
- Vertriebsmitarbeitern erlauben, Bestellformulare bis zur Aktivierung zu bearbeiten
- Vertriebsmitarbeiter verpflichten, alle Formularfelder auszufüllen, bevor eine Bestellung gesendet wird
- Vertriebsmitarbeitern den Verkauf von Einzelprodukten bei Opportunities und Bestellungen untersagen
- Vertriebsmitarbeitern das Hinzufügen von Tags zu Bestellungen untersagen
- Kunden erlauben, eine Bestellung von einer Store-Seite aus an Admins zu senden

### Sendeaktionen für Vertriebsmitarbeiter

Steuern Sie, was Vertriebsmitarbeiter beim Absenden von Bestellungen tun können:

- Vertriebsmitarbeitern erlauben, Bestellungen direkt an Admins zu senden
- Vertriebsmitarbeitern erlauben, beim Absenden einer Bestellung die gespeicherte Zahlungsmethode des Kunden zu belasten
- Vertriebsmitarbeitern erlauben, Bestellungen zur Genehmigung an Kunden zu senden
- Zur Genehmigung von Vertriebsmitarbeitern gesendete Bestellungen können Zahlungen akzeptieren

### Sendeaktionen für Admins

- Admins können den Genehmigungs-Workflow umgehen und Bestellungen sofort aktivieren

### Standardinhalte

Sie können jeder Bestellung interne Referenzformulare hinzufügen.

:::info
Standardinhaltsfelder sind nur für den internen Gebrauch bestimmt und **werden für Vendoren nicht sichtbar sein**.
:::

### Allgemeine Geschäftsbedingungen für Kunden

Legen Sie die Allgemeinen Geschäftsbedingungen fest, die bei einer Bestellung angezeigt werden, wenn sie zur Genehmigung an den Kunden gesendet wird.

### E-Mail-Vorlagen

Konfigurieren Sie diese kundenseitigen E-Mails:

- **Vertrag wartet auf Genehmigung**
- **Bestellung verarbeitet**
- **Bestellung abgelehnt**
