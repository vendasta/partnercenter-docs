Standard-Abrechnungseinstellungen wenden Ihre gewählte Konfiguration für die Abonnementabrechnung auf jedes neue Konto an, das Sie erstellen. Sie legen sie einmal fest; neue Konten erhalten diese Einstellungen automatisch. Bestehende Konten bleiben unverändert.

## Was es ist

Die Abonnementabrechnung erstellt und versendet Rechnungen oder belastet gespeicherte Zahlungsmethoden für wiederkehrende Abonnements. Standardeinstellungen unter `Administration` → `Default billing settings` gelten für alle neuen Konten, sodass Sie die Abrechnung nicht für jedes Konto manuell konfigurieren müssen.

## Warum es wichtig ist

- **Weniger manueller Aufwand** – Neue Konten erhalten automatisch Ihre bevorzugte Abrechnungskonfiguration
- **Konsistenz** – Gleiche Abrechnungspraktiken bei allen neuen Kunden
- **Flexibilität** – Ändern Sie ein einzelnes Konto über dessen eigene Abrechnungseinstellungen unter `Accounts` → `Manage Accounts`

## Was Sie konfigurieren können

- **`Subscriptions`** – Ein Schalter, der die Abonnementabrechnung für neue Konten aktiviert. Standardmäßig auf `Off`
- **`Payment collection`** – Wie Sie die Zahlung für ein Abonnement einziehen
- **`Subscription renewal`** – Was bei der Verlängerung eines Abonnements passiert. Zu den Optionen gehören `Do nothing` und `Create a draft invoice`
- **`Subscription scheduling`** – Ob jedes Abonnement zu seinem eigenen Startdatum verlängert wird oder alle Abonnements auf ein gemeinsames Datum ausgerichtet werden
- **`Memo`** – Freitext, der unten auf jeder Rechnung erscheint, die die Abonnementabrechnung erstellt

Die Seite zeigt einen Hinweis, dass diese Einstellungen nur für Konten gelten, die **nach** dem Speichern erstellt werden. Bestehende Konten behalten ihre aktuellen Einstellungen.

## So konfigurieren Sie die Standard-Abrechnung

1. Gehen Sie zu `Partner Center` → `Administration` → `Default billing settings`
2. Aktivieren Sie den Schalter `Subscriptions`. Standardmäßig ist er auf `Off`
3. Legen Sie unter `Payment collection` die Methode fest, mit der Sie die Zahlung einziehen möchten
4. Legen Sie `Subscription renewal` fest. Wählen Sie `Do nothing`, wenn bei der Verlängerung nichts erzeugt werden soll, oder `Create a draft invoice`, wenn Sie eine Rechnung vor dem Versand prüfen möchten
5. Legen Sie `Subscription scheduling` fest. Verlängern Sie jedes Abonnement zu seinem eigenen Startdatum, oder richten Sie Abonnements an einem gemeinsamen Datum aus
6. Fügen Sie ein `Memo` hinzu, wenn Sie einen festen Text unten auf jeder Rechnung der Abonnementabrechnung wünschen
7. Prüfen Sie die Einstellungen und wählen Sie `Save`

![Konfigurationsseite für Standard-Abrechnungseinstellungen](./img/administration/default-billing-settings/default-billing-settings.png)

Neue Konten erhalten diese Einstellungen automatisch in ihrer Abrechnungskonfiguration.

:::warning
Standard-Abrechnungseinstellungen ändern bestehende Konten nicht. Nur Konten, die nach dem Speichern erstellt werden, verwenden diese Standardwerte.
:::

## Abrechnung für ein einzelnes Konto ändern

Sie können die Abrechnung für jedes Konto jederzeit ändern:

1. Gehen Sie zu `Partner Center` → `Accounts` → `Manage Accounts`
2. Öffnen Sie das Konto
3. Ändern Sie die eigenen Abrechnungseinstellungen dieses Kontos

Mehr zur kontobezogenen Abrechnung finden Sie unter [Subscription management](/commerce/subscriptions/subscription-management).

## Marktspezifische Standardwerte

Bei mehreren Märkten können Sie unterschiedliche Standard-Abrechnungseinstellungen pro Markt festlegen. Verwenden Sie dazu den Marktwähler auf der Seite `Default billing settings`.

## Anforderung an die Produktpreisgestaltung

Damit die Automatisierung korrekt abrechnet:

- **Verkaufspreise** müssen für jedes Produkt festgelegt sein
- **Abonnementeinstellungen** müssen für wiederkehrende Produkte korrekt sein

:::info
Um automatisch auf Basis aktiver Produkte abzurechnen, müssen Sie Verkaufspreise für jedes Produkt festlegen. Ohne Preisgestaltung kann die Automatisierung die Beträge nicht berechnen.
:::

## Häufig gestellte Fragen

<details>
<summary>Wirken sich Standard-Abrechnungseinstellungen auf bestehende Konten aus?</summary>

Nein. Sie gelten nur für Konten, die nach dem Speichern erstellt werden. Bestehende Konten behalten ihre aktuellen Abrechnungseinstellungen.
</details>

<details>
<summary>Kann ich die Abrechnung für ein Konto ändern, nachdem die Standardwerte angewendet wurden?</summary>

Ja. Gehen Sie zu `Accounts` → `Manage Accounts`, öffnen Sie das Konto und ändern Sie die eigenen Abrechnungseinstellungen dieses Kontos.
</details>

<details>
<summary>Muss ich Produktpreise festlegen, damit die Automatisierung funktioniert?</summary>

Ja. Legen Sie Verkaufspreise für jedes Produkt fest, damit die automatische Abrechnung Beträge berechnen kann.
</details>

<details>
<summary>Kann ich unterschiedliche Standardwerte pro Markt haben?</summary>

Ja. Wählen Sie jeden Markt auf der Seite `Default billing settings` aus und speichern Sie unterschiedliche Einstellungen pro Markt.
</details>

<details>
<summary>Was macht die Einstellung `Payment collection`?</summary>

`Payment collection` legt fest, wie Sie die Zahlung für ein Abonnement bei einem neuen Konto einziehen. Öffnen Sie das Feld auf der Seite `Default billing settings`, um die für Ihr Konto verfügbaren Methoden zu sehen, und wählen Sie diejenige, die Ihrer gewünschten Zahlungsweise entspricht.
</details>

<details>
<summary>Wofür ist das Feld `Memo`?</summary>

Alles, was Sie in `Memo` eingeben, erscheint unten auf jeder Rechnung, die die Abonnementabrechnung erstellt. Nutzen Sie es für festen Text wie Zahlungsbedingungen oder einen Überweisungshinweis.
</details>

<details>
<summary>Kann ich die Standard-Abonnementabrechnung später wieder ausschalten?</summary>

Ja. Gehen Sie zu `Default billing settings`, stellen Sie den Schalter `Subscriptions` auf `Off` und speichern Sie. Neue Konten erhalten dann keine Standardwerte mehr; bestehende Konten bleiben unverändert.
</details>

<details>
<summary>Meine Kunden erhalten unerwartete Rechnungs-E-Mails: Wie stoppe ich das?</summary>

Dies passiert, wenn die Abonnementabrechnung aktiviert ist und so eingestellt ist, dass bei Verlängerung Rechnungen erstellt werden. So stoppen Sie den Versand von Rechnungs-E-Mails:

1. Gehen Sie zu `Partner Center` → `Administration` → `Default billing settings` und prüfen Sie, ob der Schalter `Subscriptions` aktiviert ist
2. Stellen Sie `Subscription renewal` auf `Do nothing`, damit bei Verlängerungen keine Rechnung mehr erstellt wird, und wählen Sie dann `Save`
3. Dies ändert den Standard nur für neue Konten. Ändern Sie für ein Konto, das bereits Rechnungen versendet, die eigenen Abrechnungseinstellungen dieses Kontos

Die Kontoeinstellungen finden Sie unter `Partner Center` → `Accounts` → `Manage Accounts`; öffnen Sie dort das betroffene Konto.

</details>
