# Account Templates

Mit Account Templates konfigurieren Sie ein Konto einmal und verwenden dieses Setup überall wieder. Wenn eine Vorlage angewendet wird, werden AI Employees, Web-Chat-Einstellungen, CRM-Felder, Kampagnen, Automatisierungen, Formulare und mehr innerhalb von Sekunden auf das Zielkonto übertragen – ganz ohne manuelle Schritte.

Vorlagen sind besonders nützlich für Partner, die Kunden in großem Maßstab onboarden, das Setup innerhalb einer Branchenvertikale standardisieren oder SMB-Self-Signup anbieten.

## Was Account Templates enthalten

Eine Vorlage erfasst die vollständige Konfiguration eines Quellkontos, einschließlich:

- AI Employees
- Web-Chat-Widgets und -Einstellungen
- Formulare
- CRM-Felder
- CRM-Feldlayouts
- Kampagnen
- Automatisierungen

![Dialog zur Erstellung einer Account Template mit dem Schritt „Configure“, der Kontrollkästchen für AI Employees, CRM Custom Fields, Promotions und andere Komponenten zeigt](./img/account-templates1.png)

## Zugriff

Um Vorlagen anzuzeigen, zu erstellen, zu aktualisieren oder manuell anzuwenden, gehen Sie in Partner Center zu `Accounts` → `Account Templates`.

![Liste der Account Templates mit Name, Quellkonto, Inhalt und Erstellungsdatum einer Vorlage](./img/account-templates3.png)

## Manuelles Anwenden einer Vorlage

Um eine Vorlage direkt auf ein Konto anzuwenden, öffnen Sie die Vorlage über Partner Center → `Accounts` → `Account Templates`, wählen Sie ein Zielkonto aus, legen Sie fest, welche Funktionen angewendet werden sollen, und klicken Sie auf **Apply**.

![Dialog zum Anwenden einer Account Template mit Auswahl des Zielkontos und Kontrollkästchen für Funktionen](./img/account-templates2.png)

## Vorlagen automatisch anwenden

### Eine Vorlage mit einer Unternehmenskategorie verknüpfen

Verknüpfen Sie eine Account Template mit einer Unternehmenskategorie, und jedes neue Konto, das in dieser Kategorie erstellt wird – per API, manuell oder über SMB-Self-Signup – erhält automatisch die passende Vorlage angewendet. Kein manuelles Setup erforderlich.

### Die Automatisierungsaktion „Apply an account template“ verwenden

Vorlagen können auch aus einer Automatisierung heraus angewendet werden, was Ihnen volle Kontrolle darüber gibt, wann und wie sie ausgelöst werden.

So richten Sie das ein:

1. Gehen Sie in Partner Center zu **Automations**.
2. Wählen Sie eine Automatisierung aus oder erstellen Sie eine neue.
3. Fügen Sie die Aktion **Apply account template** hinzu.
4. Wählen Sie die anzuwendende Vorlage aus.

So können Sie eine Vorlage basierend auf jeder Bedingung anwenden oder erneut anwenden, die eine Automatisierung auswerten kann.

## CRM-Feldlayouts einbeziehen

Ein [Feldlayout](/administration/data-management/crm-objects/field-layouts) – die Gruppierung und Reihenfolge von Feldern auf Kontakt-, Unternehmens-, Opportunity- und Custom-Object-Datensätzen – kann mit einer Vorlage ausgerollt werden, sodass jedes Konto seine Datensätze auf die gleiche Weise darstellt.

- Es werden nur angepasste Layouts erfasst. Objekttypen, die noch das Standardlayout verwenden, werden übersprungen.
- Wenn ein Layout auf Custom-Felder oder einen Custom-Object-Typ verweist, den das Zielkonto nicht hat, werden diese dort zuerst erstellt und das Layout wird darauf umgeleitet.
- Das Anwenden einer Vorlage ersetzt das Layout des Zielkontos für diesen Objekttyp. Jede bereits am Zielkonto vorgenommene Layoutanpassung wird überschrieben.

## Formulare und Web-Chat-Widgets einbeziehen

Formulare und Web-Chat-Widgets, die auf dem Quellkonto konfiguriert sind, können in die Vorlage aufgenommen und auf jedes Konto ausgerollt werden, auf das die Vorlage angewendet wird. Das ist besonders nützlich, wenn:

- Eine anfängliche Web-Chat-Nachricht in einer anderen Sprache verfasst sein muss.
- Datenschutzerklärungen je nach Region unterschiedlich sind.

## Konten in großem Maßstab aktualisieren

Nachdem Sie das Quellkonto verbessert haben, aus dem eine Vorlage erstellt wurde, klicken Sie auf **Update template**, um die Vorlage mit den neuesten Änderungen zu aktualisieren. Kein Neuaufbau erforderlich. Die Aktualisierungen werden angewendet, sobald die Vorlage das nächste Mal verwendet wird.

## Vorlagenanwendung als Automatisierungsauslöser verwenden

Wenn die Anwendung einer Vorlage abgeschlossen ist, erhält das Zielkonto einen Eintrag im Aktivitätsprotokoll. Automatisierungen können auf diesen Eintrag reagieren und nachgelagerte Arbeiten an eine abgeschlossene Vorlagenanwendung anknüpfen, etwa die Zuweisung eines Mitarbeiters oder die Einrichtung eines Coupon-Formulars.

## Grenzwerte für Custom Objects

Jedes Konto kann bis zu 3 [CRM Custom Objects](/crm/custom-objects) haben. Würde das Anwenden einer Vorlage ein Zielkonto über diesen Grenzwert hinausbringen, schlägt die Anwendung für dieses Konto fehl, und Partner Center zeigt einen Fehler an, der die Ursache benennt, anstatt stillschweigend zu scheitern.

## Für wen das gedacht ist

- Partner, die Konten in großem Maßstab onboarden (Enterprise-Rollouts, Reseller-Kanäle, Migrationen)
- Partner, die das Setup über mehrere Konten innerhalb derselben Branchenvertikale standardisieren
- Partner, die SMB-Self-Signup anbieten
