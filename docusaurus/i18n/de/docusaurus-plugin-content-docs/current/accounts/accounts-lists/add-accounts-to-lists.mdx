## Einzelne Konten zu Listen hinzufügen

So fügen Sie ein einzelnes Konto zu einer Liste hinzu:

1. Gehen Sie zu `Partner Center` → `Accounts` → `Manage Accounts`.
2. Suchen Sie das Konto, das Sie der Liste hinzufügen möchten. Klicken Sie auf das Symbol `menu` ![Menu icon](./img/accounts/lists/menu-icon.jpg) am Ende der Zeile.
3. Klicken Sie auf `Add to List`.
4. Fügen Sie das Konto einer Liste hinzu:
   a. Wenn Sie die Konten zu einer bestehenden Liste hinzufügen möchten:
      i. Wählen Sie die bestehende Liste aus dem Dropdown-Menü aus.
      ii. Klicken Sie auf `Add`.
   b. Wenn Sie die Konten zu einer neuen Liste hinzufügen möchten:
      i. Gehen Sie zum Tab `Create New List`.
      ii. Geben Sie einen Namen für die Liste ein.
      iii. Klicken Sie auf `Create and Add`.

## Mehrere Konten zu Listen hinzufügen

So fügen Sie mehrere Konten zu einer Liste hinzu:

1. Gehen Sie zu `Partner Center` → `Accounts` → `Manage Accounts`.
2. Filtern und suchen Sie nach den Konten, die Sie einer Liste hinzufügen möchten.
   :::note
   Sie können Filter und die Suchleiste verwenden, um Ihre Konten zu finden.
   :::
3. Klicken Sie auf `Add # to List`.
4. Fügen Sie die Konten einer Liste hinzu:
   a. Wenn Sie die Konten zu einer neuen Liste hinzufügen möchten:
      i. Geben Sie einen Namen für die Liste ein.
      ii. Klicken Sie auf `Create and Add`.
   b. Wenn Sie die Konten zu einer bestehenden Liste hinzufügen möchten:
      i. Gehen Sie zum Tab `Add to List`.
      ii. Wählen Sie die bestehende Liste aus dem Dropdown-Menü aus.
      iii. Klicken Sie auf `Add`.

## Konten aus Listen entfernen

1. Gehen Sie zu `Partner Center` → `Accounts` → `Lists`.
2. Klicken Sie auf den Listennamen.
3. Suchen Sie das Konto, öffnen Sie das Zeilenmenü und wählen Sie `Remove from list` aus.
4. Bestätigen Sie das Entfernen.

## Häufig gestellte Fragen

<details>
<summary>Kann ich dasselbe Konto zu mehreren Listen hinzufügen?</summary>

Ja. Sie können ein Konto so vielen Listen hinzufügen, wie Sie benötigen. Das ist nützlich, wenn Sie Konten auf unterschiedliche Weise organisieren möchten – zum Beispiel ein Konto sowohl in einer Liste „Newsletter-Abonnenten" als auch in einer Liste „Premium-Kunden" zu führen.
</details>

<details>
<summary>Was passiert, wenn ich versuche, ein Konto hinzuzufügen, das bereits in der Liste ist?</summary>

Das System verhindert doppelte Einträge. Wenn Sie versuchen, ein Konto hinzuzufügen, das bereits in einer Liste enthalten ist, wird das Konto nicht erneut hinzugefügt, und es wird keine Fehlermeldung angezeigt.
</details>

<details>
<summary>Gibt es eine Begrenzung, wie viele Konten ich auf einmal zu einer Liste hinzufügen kann?</summary>

Bei Verwendung der Funktion zum Massenhinzufügen können Sie eine beliebige Anzahl gefilterter Konten zu einer Liste hinzufügen. Für optimale Leistung wird jedoch empfohlen, bei Massenvorgängen mit Batches von bis zu 1000 Konten gleichzeitig zu arbeiten.
</details>
