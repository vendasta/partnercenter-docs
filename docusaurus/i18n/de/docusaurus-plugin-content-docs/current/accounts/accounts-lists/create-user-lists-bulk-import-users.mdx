Nachdem Sie [eine Liste erstellt haben](./create-account-lists.mdx) in Business App, können Sie Benutzer per CSV-Datei importieren. Mit Benutzerlisten können Sie große Benutzerlisten einfach importieren, anzeigen und verwalten.

## So importieren Sie Benutzer per CSV

### Schritt 1: `Import users` (CSV) auswählen

Wählen Sie auf Ihrer Listenseite die Schaltfläche `Import users` (CSV), um das Import-Fenster zu öffnen.

<img src={require('./img/accounts/users/import-users-step1.jpg').default} alt="Import users step 1" style={{width: '100%', border: '1px solid #e0e0e0', borderRadius: '8px', boxShadow: '0 2px 8px rgba(0,0,0,0.08)'}} />

### Schritt 2: Die CSV-Vorlage herunterladen

Wenn Sie zum ersten Mal Benutzer importieren, laden Sie die CSV-Vorlage herunter, um die korrekte Formatierung sicherzustellen. Sie können auch eine zuvor exportierte Benutzerliste als Vorlage verwenden.

<img src={require('./img/accounts/users/import-users-step2.jpg').default} alt="Import users step 2" style={{width: '100%', border: '1px solid #e0e0e0', borderRadius: '8px', boxShadow: '0 2px 8px rgba(0,0,0,0.08)'}} />

### Schritt 3: Die CSV-Vorlage ausfüllen

Öffnen Sie die Vorlage in einem Tabellenkalkulationsprogramm wie Excel oder Google Sheets und füllen Sie die erforderlichen Felder aus:

- `email`: Die E-Mail-Adresse des Benutzers (erforderlich)
- `first_name`: Vorname des Benutzers
- `last_name`: Nachname des Benutzers
- `job_title`: Position oder Jobtitel des Benutzers
- `department`: Abteilung des Benutzers
- `address`: Physische Adresse des Benutzers
- `city`: Stadt des Benutzers
- `region`: Bundesland/Provinz des Benutzers
- `country`: Land des Benutzers
- `postal_code`: Postleitzahl des Benutzers
- `phone`: Telefonnummer des Benutzers

Nur die E-Mail-Adresse ist erforderlich, aber das Hinzufügen zusätzlicher Informationen hilft Ihnen, Ihre Benutzer besser zu segmentieren und gezielt anzusprechen.

### Schritt 4: Ihre CSV-Datei hochladen

Kehren Sie zum Import-Fenster in Business App zurück und:

1. Laden Sie Ihre CSV-Datei hoch, indem Sie auf `Choose File` klicken
2. Prüfen Sie Ihre Daten in der Vorschau, um sicherzustellen, dass alles korrekt aussieht
3. Klicken Sie auf `Import`

<img src={require('./img/accounts/users/import-users-step3.jpg').default} alt="Import users step 3" style={{width: '100%', border: '1px solid #e0e0e0', borderRadius: '8px', boxShadow: '0 2px 8px rgba(0,0,0,0.08)'}} />

### Schritt 5: Auf den Abschluss des Imports warten

Nachdem Sie auf `Import` geklickt haben, verarbeitet das System Ihre Datei. Dies kann je nach Größe Ihrer Liste einige Minuten dauern. Sie erhalten eine Benachrichtigung, sobald der Import abgeschlossen ist.

<img src={require('./img/accounts/users/import-users-step4.jpg').default} alt="Import users step 4" style={{width: '100%', border: '1px solid #e0e0e0', borderRadius: '8px', boxShadow: '0 2px 8px rgba(0,0,0,0.08)'}} />

## Fehlerbehebung bei Importfehlern

### Häufige CSV-Formatprobleme

- **Ungültiges E-Mail-Format**: Stellen Sie sicher, dass alle E-Mail-Adressen dem Standardformat entsprechen (z. B. user@domain.com)
- **Doppelte E-Mail-Adressen**: Jede E-Mail-Adresse sollte in Ihrer CSV-Datei nur einmal vorkommen
- **Sonderzeichen**: Einige Sonderzeichen können Importfehler verursachen
- **Falsche Spaltenüberschriften**: Stellen Sie sicher, dass Ihre Spaltenüberschriften genau mit der Vorlage übereinstimmen

### Was zu tun ist, wenn Ihr Import fehlschlägt

1. Laden Sie den Fehlerbericht herunter (falls verfügbar)
2. Beheben Sie die festgestellten Probleme in Ihrer CSV-Datei
3. Versuchen Sie den Import erneut

## Best Practices für Benutzerlisten

- Halten Sie Ihre Listen organisiert, indem Sie klare Namenskonventionen erstellen
- Aktualisieren Sie Ihre Listen regelmäßig, um die Genauigkeit zu gewährleisten
- Verwenden Sie Tags und benutzerdefinierte Felder, um Ihre Benutzer weiter zu segmentieren
- Exportieren Sie Ihre Listen regelmäßig als Sicherung
