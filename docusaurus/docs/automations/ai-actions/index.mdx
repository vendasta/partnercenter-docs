# AI Actions

AI actions let you add intelligence to your automations without writing code. Use them to summarize, classify, or analyze text as part of any workflow.

| Action | What it does |
| --- | --- |
| [Summarize with AI](./summarize-with-ai) | Condenses text into a concise summary you can use in later steps |
| [Categorize with AI](./categorize-with-ai) | Classifies text into categories you define, creating branching paths |
| [Analyze sentiment with AI](./analyze-sentiment-with-ai) | Detects positive, neutral, or negative tone and branches accordingly |
| [Send a prompt to AI](./send-a-prompt-to-ai) | Sends a free-form text prompt to an AI model and returns the response |
| [Send a request to an AI employee](./send-a-request-to-an-ai-employee) | Sends a prompt to a specific AI employee that uses its knowledge base and capabilities |
