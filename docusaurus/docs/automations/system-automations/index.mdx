# Built-in automations

Built-in automations are pre-built workflows provided by Vendasta. They handle common platform tasks automatically — no setup required. You can enable or disable them, but you cannot edit them directly.

## How built-in automations work

- **Enabled by default** — new partner accounts have all built-in automations turned on. You only need to take action if you want to disable one.
- **Read-only workflows** — click a built-in automation's name to view its trigger and steps, but you cannot modify them.
- **Duplicate to customize** — if you need a version you can edit, duplicate the built-in automation. The copy becomes a regular automation in **My automations** that you fully control.
- **Scoped to your account** — enabling or disabling a built-in automation only affects your partner account or the specific account group you're managing.

## Manage built-in automations

1. In Partner Center, go to **Automations**.
2. Select the **Built-in automations** tab. The tab appears only when there are built-in automations available.
3. Review each built-in automation in the table. Use the tooltip on the tab to learn what built-in automations are and what actions you can take.
4. Use the **toggle** on each row to enable or disable it.

The tab shows this message: "Your provider set these up and keeps them updated. Turn one on, or duplicate it to make your own."

### Enable a built-in automation

Flip the toggle to **on**. The automation starts processing trigger events immediately.

### Disable a built-in automation

1. Flip the toggle to **off**.
2. A confirmation dialog appears: **"Turn off [automation name]?"**
3. Click **Turn off** to confirm, or **Cancel** to keep it enabled.

Once disabled, the automation stops processing new trigger events. Any runs already in progress will complete.

## Duplicating a built-in automation

If a built-in automation does most of what you need but requires changes, duplicate it:

1. Click the built-in automation's name to open its workflow view.
2. From the **More actions** menu, select **Duplicate**.
3. The copy appears in **My automations** as a regular automation you can edit, rename, and configure.
4. Optionally disable the original built-in automation if you only want your customized version running.
