# Automation template – Create companies from Visual Visitor

## Template name

Create Companies from Visual Visitor.

## Purpose

This template helps you create companies in the CRM using data available in Business App so you can streamline processes and manage company information in one place.

## Configuration

The template creates companies with a set of minimum required details. You can customize it to pull in additional fields from Visual Visitor. Visual Visitor provides a wide set of data points that can be mapped into Business App.

For a full list of data provided by Visual Visitor, see their support page: [Integrate Our Data with Any System You Like](https://support.visualvisitor.com/portal/en/kb/articles/integrate-our-data-with-any-system-you-like).
