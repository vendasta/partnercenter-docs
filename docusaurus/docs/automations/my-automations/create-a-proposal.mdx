# Create a proposal

**Create a proposal** generates a sales proposal on the account in scope. Use it to automatically create proposals when an opportunity reaches a specific stage or when a qualifying event occurs. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the **Create a proposal** step with an account in scope
2. The step creates a sales proposal using the configuration you provide
3. The proposal is associated with the account
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales**, select **Create a proposal**
3. Configure the proposal details as prompted

## Outputs

This action produces no outputs available to downstream steps.
