`Approve order` approves a pending sales order so it can proceed to activation or payment.

## How it works

1. The automation reaches the step with an order in scope
2. The step approves the pending order
3. The order moves forward in the pipeline
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under `Sales orders`, select `Approve order`

## Outputs

This action produces no outputs available to downstream steps.
