# Reopen opportunity

**Reopen opportunity** returns a previously closed opportunity to an active pipeline stage. Use it when a churned customer re-engages or when a lost deal comes back to life. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the **Reopen opportunity** step with an account and opportunity in scope
2. The step changes the opportunity's status from closed back to active
3. The opportunity reappears in the active pipeline
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales**, select **Reopen an opportunity**
3. The opportunity to reopen is determined by the one currently in scope — use a preceding **Get an opportunity** step if needed

## Outputs

This action produces no outputs available to downstream steps.
