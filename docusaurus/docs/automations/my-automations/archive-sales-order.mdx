# Archive a sales order

**Archive a sales order** archives a sales order, removing it from active views while retaining the record. Use it to clean up stale draft orders or completed orders.

## How it works

1. The automation reaches the step with an order in scope
2. The step archives the sales order
3. The order is removed from active views but the record is preserved
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales orders**, select **Archive the order**

## Outputs

This action produces no outputs available to downstream steps.
