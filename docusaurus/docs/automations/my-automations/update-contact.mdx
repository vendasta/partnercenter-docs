# Update contact

**Update contact** updates one or more fields on the contact record in scope. Supports appending to or clearing existing field values. This action is available on contact-scoped triggers.

## How it works

1. The automation reaches the step with a contact in scope
2. The step updates the fields you configured with the values you provide
3. The contact record is updated in the CRM
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Businesses**, select **Update contact**
3. Select the fields to update and provide values

:::tip
Use **Add dynamic content** to populate field values from previous steps. For multi-value fields, you can choose to **append** to existing values rather than replacing them.
:::

## Outputs

This action produces no outputs available to downstream steps.
