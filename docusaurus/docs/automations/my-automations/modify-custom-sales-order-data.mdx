# Modify custom sales order data

**Modify custom sales order data** writes or updates custom data fields on a sales order. Use it to enrich orders with computed values or external data.

## How it works

1. The automation reaches the step with an order in scope
2. The step writes the values you configured to the specified custom data fields
3. The order's custom data is updated immediately
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Advanced**, select **Modify custom sales order data**
3. Configure the custom data fields and values

:::tip
Use **Add dynamic content** to populate values from previous steps.
:::

## Outputs

This action produces no outputs available to downstream steps.
