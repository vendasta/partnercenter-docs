# Add tags to order

**Add tags to order** applies one or more tags to a sales order for tracking and filtering. Tags appear on the order record immediately and can be used to segment orders in reports and lists.

## How it works

1. The automation reaches the **Add tags to order** step with an order in scope
2. You define one or more tags to apply
3. When the step runs, each tag is written to the order record
4. If a tag already exists on the order, it is not duplicated
5. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Tags** or **Sales orders**, select **Add tags to order**
3. Configure the fields:

| Field | Required | Description |
| --- | --- | --- |
| **Tags** | Yes | One or more tags to apply to the order. Enter each tag and press Enter to add it. |

:::tip
Use **Add dynamic content** in the tag field to insert a value from a previous step. Dynamic values are resolved at runtime.
:::

## Outputs

This action produces no outputs available to downstream steps.
