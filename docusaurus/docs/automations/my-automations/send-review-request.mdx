# Send a review request

**Send a review request** sends a review request to a contact, prompting them to leave a review on a connected platform (Google, Facebook, etc.). Use it after a service is completed to build online reputation. This action is available on contact-scoped triggers.

## How it works

1. The automation reaches the step with a contact in scope
2. The step sends a review request to the contact
3. The contact receives a prompt to leave a review
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Conversations**, select **Send a review request**
3. Configure the review platform and message

## Outputs

This action produces no outputs available to downstream steps.
