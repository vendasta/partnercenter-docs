# Decline a sales order

**Decline a sales order** declines a pending sales order, preventing it from proceeding to activation.

## How it works

1. The automation reaches the step with an order in scope
2. The step declines the pending order
3. The order is marked as declined
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales orders**, select **Decline the order**

## Outputs

This action produces no outputs available to downstream steps.
