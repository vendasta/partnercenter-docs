# Modify custom product data

**Modify custom product data** writes or updates custom data fields on the account's product records. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the step with an account in scope
2. The step writes the values you configured to the specified custom product data fields
3. The product's custom data is updated immediately
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Advanced**, select **Modify custom product data**
3. Configure the custom data fields and values

:::tip
Use **Add dynamic content** to populate values from previous steps.
:::

## Outputs

This action produces no outputs available to downstream steps.
