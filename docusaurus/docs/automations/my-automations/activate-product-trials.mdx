# Activate product trials

**Activate product trials** activates a product trial for the account in scope. Use it to automatically start trial periods when accounts meet certain criteria. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the step with an account in scope
2. The step activates the selected product trial for the account
3. The trial period begins
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Products**, select **Activate product trials**
3. Select the product and trial configuration

## Outputs

This action produces no outputs available to downstream steps.
