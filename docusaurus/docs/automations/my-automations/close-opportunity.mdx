# Close opportunity

**Close opportunity** closes a specific opportunity on the account in scope. Use it to mark a deal as won or lost when a qualifying event occurs. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the step with an opportunity in scope
2. The step closes the opportunity
3. The opportunity is removed from active pipeline views
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales**, select **Close opportunity**

## Outputs

This action produces no outputs available to downstream steps.
