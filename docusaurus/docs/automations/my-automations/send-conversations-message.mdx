# Send a Conversations message

**Send a Conversations message** sends a message to the account's Conversations inbox. Use it to automatically post welcome messages, status updates, or follow-ups. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the step with an account in scope
2. The step sends a message to the account's Conversations inbox
3. The message appears in the inbox for the account's users
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Conversations**, select **Send a Conversations message**
3. Configure the message content

:::tip
Use **Add dynamic content** to personalize the message with data from previous steps.
:::

## Outputs

This action produces no outputs available to downstream steps.
