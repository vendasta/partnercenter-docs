# Send an SMS message to a phone number

**Send an SMS message to a phone number** sends an SMS text message to any phone number you specify, including numbers not in your CRM. Use it to notify on-call staff, send alerts to external numbers, or reach people outside your contact list.

## How it works

1. The automation reaches the step
2. The step sends an SMS to the phone number you configured
3. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Conversations**, select **Send an SMS message to a phone number**
3. Configure the fields:

| Field | Required | Description |
| --- | --- | --- |
| **Phone number** | Yes | The phone number to send the SMS to. Can be a static number or dynamic content from a previous step. |
| **Message** | Yes | The text message content. |

:::tip
Use **Add dynamic content** to pass a phone number from a webhook payload or previous step, and to personalize the message.
:::

## Outputs

This action produces no outputs available to downstream steps.
