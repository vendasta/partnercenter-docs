# Query opportunities

**Query opportunities** searches for opportunities based on filter criteria and brings matching results into scope. Use it to check for existing opportunities before creating new ones, or to inspect the pipeline before taking action. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the step with an account in scope
2. The step queries opportunities on the account using the filters you configured
3. Matching opportunities are brought into scope
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales**, select **Query opportunities**
3. Configure the filter criteria

## Outputs

After the step runs, matching opportunity data is available to downstream steps via **Add dynamic content**.
