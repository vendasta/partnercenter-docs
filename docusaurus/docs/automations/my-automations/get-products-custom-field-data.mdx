# Get products' custom field data

**Get products' custom field data** retrieves custom field data for the account's products and brings it into scope for downstream steps. Use it when you need to make decisions or populate content based on product-specific custom data.

## How it works

1. The automation reaches the step with an account in scope
2. The step retrieves custom field data for the account's active products
3. The custom field data is available to downstream steps via dynamic content
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Products**, select **Get products' custom field data**

## Outputs

After the step runs, custom field data for the account's products is available to downstream steps via **Add dynamic content**.
