# Create a Snapshot Report

**Create a Snapshot Report** generates a Snapshot Report for the account or company in scope. Snapshots assess a business's online presence across categories like listings, reviews, social, and SEO. Use this action to automatically generate reports for new leads or after key milestones.

## How it works

1. The automation reaches the **Create a Snapshot Report** step with an account or company in scope
2. The step initiates a Snapshot Report
3. Web scraping begins to gather data for the report
4. The automation continues to the next step

:::warning
Snapshot Reports typically start with F ratings because web scraping takes time to complete. Add a **Delay** step before using Snapshot data in downstream steps to ensure accurate ratings are available.
:::

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales**, select **Create a Snapshot Report**
3. Configure the Snapshot settings as prompted

## Outputs

This action produces no outputs available to downstream steps.
