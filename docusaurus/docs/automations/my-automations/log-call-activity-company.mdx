# Log a call activity to the company

**Log a call activity to the company** records a call on the company's activity timeline. Use it to automatically log calls from integrations, webhooks, or other automation steps. This action is available on company-scoped triggers.

## How it works

1. The automation reaches the step with a company in scope
2. The step creates a call activity record with the details you configured
3. The call appears on the company's activity timeline
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Advanced**, select **Log a call activity to the company**
3. Configure the call details as prompted

:::tip
Use **Add dynamic content** to populate call details from a previous step — for example, pull call duration or notes from a webhook payload.
:::

## Outputs

This action produces no outputs available to downstream steps.
