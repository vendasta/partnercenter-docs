# Add account to Task Manager

**Add account to Task Manager** activates Task Manager for the account in scope so tasks and projects can start generating. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the **Add account to Task Manager** step with an account in scope
2. The step activates Task Manager for the account
3. Product-based tasks and projects can now be created for the account
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Fulfillment**, select **Add account to Task Manager**

This action has no configuration fields — it activates Task Manager for the account in scope.

## Outputs

This action produces no outputs available to downstream steps.
