# Pause a campaign for the user

**Pause a campaign for the user** pauses an ongoing email campaign for the user.

## How it works

1. The automation reaches the step with a user in scope
2. The step pauses the selected campaign for the user
3. No further campaign emails are sent to this user
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Campaigns and emails**, select **Pause a campaign for the user**
3. Select the campaign to pause

## Outputs

This action produces no outputs available to downstream steps.
