# Submit order for customer approval

**Submit order for customer approval** submits a sales order for customer approval before it can proceed. Use it for renewal orders or quotes that require the customer's confirmation.

## How it works

1. The automation reaches the step with an order in scope
2. The step sends the order to the customer for review
3. The order is placed in a pending customer approval state
4. The customer must approve before the order proceeds
5. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales orders**, select **Submit order for customer approval**

## Outputs

This action produces no outputs available to downstream steps.
