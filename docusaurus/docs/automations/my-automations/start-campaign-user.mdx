# Start a campaign for the user

**Start a campaign for the user** enrolls a user in a specified email campaign.

## How it works

1. The automation reaches the step with a user in scope
2. The step enrolls the user in the selected campaign
3. The user begins receiving campaign emails
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Campaigns and emails**, select **Start a campaign for the user**
3. Select the campaign to start

## Outputs

This action produces no outputs available to downstream steps.
