# Send a coupon

**Send a coupon** sends a coupon or discount code to the account or contact. Use it to incentivize conversions, reward milestones, or prevent churn.

## How it works

1. The automation reaches the step
2. The step sends the configured coupon to the target
3. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Conversations**, select **Send a coupon**
3. Configure the coupon details

## Outputs

This action produces no outputs available to downstream steps.
