# Unassign salespeople

**Unassign salespeople** removes the primary salesperson and all additional salesperson assignments from the account. Use it when an account churns, changes ownership model, or needs a clean slate before reassignment. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the **Unassign salespeople** step with an account in scope
2. The step removes both the primary assigned salesperson and any additional salespeople
3. The account's salesperson fields are cleared
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales**, select **Unassign salespeople**

This action has no configuration fields — it removes all salesperson assignments from the account in scope.

## Outputs

This action produces no outputs available to downstream steps.
