# Create a user from a contact

**Create a user from a contact** creates a Business App user from an existing CRM contact record. Use it to automatically give contacts access to Business App when they're qualified, onboarded, or reach a specific stage in your workflow. This action is available on contact-scoped triggers.

## How it works

1. The automation reaches the **Create a user from a contact** step with a contact in scope
2. The step creates a new Business App user using the contact's details (name, email)
3. The user is associated with the contact's account
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Users**, select **Create a user from a contact**

This action uses the contact currently in scope — no additional configuration is needed.

## Outputs

This action produces no outputs available to downstream steps.
