# Create a fulfillment task

**Create a fulfillment task** creates a task in Task Manager for the account in scope. You can assign it to the default fulfillment agent or a specific individual. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the step with an account in scope
2. The step creates a task in Task Manager with the details you configured
3. The task is assigned to the specified fulfillment agent
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Fulfillment**, select **Create a fulfillment task**
3. Configure the task details

:::info
If the assigned fulfillment agent doesn't exist, the task is created with no assignee.
:::

## Outputs

This action produces no outputs available to downstream steps.
