# Send a WhatsApp message to a contact

**Send a WhatsApp message to a contact** sends an approved WhatsApp message template to a contact via Conversations. This action is available on contact-scoped triggers.

:::info
Requires a connected WhatsApp Business account and an approved message template. WhatsApp requires all business-initiated messages to use pre-approved templates.
:::

## How it works

1. The automation reaches the step with a contact in scope
2. The step sends the selected WhatsApp message template to the contact
3. The message appears in the contact's WhatsApp and your Conversations thread
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Conversations**, select **Send a WhatsApp message to a contact**
3. Select the approved message template and configure any template variables

## Outputs

This action produces no outputs available to downstream steps.
