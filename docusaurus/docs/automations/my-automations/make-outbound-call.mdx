# Make outbound call with an employee

**Make outbound call with an employee** places an outbound AI phone call to a contact using a selected AI employee. Use it to automatically qualify leads, confirm appointments, or follow up on events.

## How it works

1. The automation reaches the step with a contact in scope
2. The step initiates an outbound phone call from the selected AI employee to the contact
3. The AI employee handles the conversation using its configured knowledge base and instructions
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Conversations**, select **Make outbound call with an employee**
3. Configure the fields:

| Field | Required | Description |
| --- | --- | --- |
| **AI employee** | Yes | The AI employee to make the call. Select from your configured AI employees. |

## Outputs

This action produces no outputs available to downstream steps.
