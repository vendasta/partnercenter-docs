# Submit order for admin approval

**Submit order for admin approval** submits a sales order for admin approval before it can be activated. Use it to enforce approval workflows for high-value or sensitive orders.

## How it works

1. The automation reaches the step with an order in scope
2. The step submits the order for admin review
3. The order is placed in a pending approval state
4. An admin must approve or decline the order before it can proceed
5. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales orders**, select **Submit the order for admin approval**

## Outputs

This action produces no outputs available to downstream steps.
