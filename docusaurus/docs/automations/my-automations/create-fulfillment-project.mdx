# Create a fulfillment project for the account

**Create a fulfillment project for the account** creates a project in Task Manager from the template you select. If Task Manager is inactive for the account, it will be activated automatically. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the step with an account in scope
2. The step creates a Task Manager project from the selected template
3. If Task Manager is inactive, it is activated for the account
4. The automation continues to the next step

:::warning
Using this step twice in one workflow for the same account results in a rejected activation. Use one project creation step per automation run.
:::

## Set up the action

1. Open the automation builder and add a new step
2. Under **Fulfillment**, select **Create a fulfillment project for the account**
3. Select the project template to use

## Outputs

This action produces no outputs available to downstream steps.
