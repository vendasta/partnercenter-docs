# Create a CRM sales task for the company

**Create a CRM sales task for the company** creates a task on the company record in scope. Use it to automatically generate follow-up tasks, assign work to team members, or create action items triggered by events. This action is available on company-scoped triggers.

## How it works

1. The automation reaches the step with a company in scope
2. The step creates a CRM sales task with the details you configured
3. The task appears on the company record and in the assigned person's task list
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Advanced**, select **Create a CRM sales task for the company**
3. Configure the task details:

| Field | Required | Description |
| --- | --- | --- |
| **Task title** | Yes | The name of the task. Supports dynamic content. |
| **Description** | No | Additional details about the task. Supports dynamic content. |
| **Assignee** | No | The team member to assign the task to. |
| **Due date** | No | When the task is due. |

:::tip
Use **Add dynamic content** in the title and description to include context from previous steps — for example, "Follow up with {{company name}} about {{opportunity name}}."
:::

## Outputs

This action produces no outputs available to downstream steps.
