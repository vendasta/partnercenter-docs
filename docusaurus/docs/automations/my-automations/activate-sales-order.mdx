# Activate a sales order

**Activate a sales order** activates a sales order for the account, beginning fulfillment of the ordered products. Use it after an order has been approved or reaches the right status.

## How it works

1. The automation reaches the step with an order in scope
2. The step activates the sales order
3. Product fulfillment begins for the ordered items
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales orders**, select **Activate a sales order**

## Outputs

This action produces no outputs available to downstream steps.
