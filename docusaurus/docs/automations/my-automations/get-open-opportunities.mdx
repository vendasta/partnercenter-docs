# Get open opportunities

**Get open opportunities** retrieves all open opportunities on the account in scope and brings them into scope for downstream steps. Use it to inspect the active pipeline before taking action — for example, logging a summary of open deal value before closing all opportunities on churn. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the step with an account in scope
2. The step retrieves all open opportunities on the account
3. The opportunity data is available to downstream steps
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales**, select **Get open opportunities**

This action has no configuration fields — it retrieves all open opportunities on the account in scope.

## Outputs

After the step runs, open opportunity data is available to downstream steps via **Add dynamic content**.
