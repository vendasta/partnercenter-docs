# Send an SMS message via Conversations

**Send an SMS message via Conversations** sends an SMS text message to a contact through your Conversations inbox. Use it to send timely follow-ups, reminders, or notifications to contacts. This action is available on contact-scoped triggers.

## How it works

1. The automation reaches the step with a contact in scope
2. The step sends an SMS to the contact's phone number via your Conversations inbox
3. The message appears in both the contact's text messages and your Conversations thread
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Conversations**, select **Send an SMS message via Conversations**
3. Configure the message content

:::tip
Use **Add dynamic content** to personalize the message with contact or account data from previous steps.
:::

## Outputs

This action produces no outputs available to downstream steps.
