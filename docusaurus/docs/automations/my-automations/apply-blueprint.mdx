# Apply blueprint

**Apply blueprint** deploys a [blueprint](/accounts/manage-accounts/blueprints) to the target account. Components in the blueprint are created or updated on that account. Campaigns are created once and never updated on later applies. The apply runs in the background, so the automation continues immediately without waiting for it to finish. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the step with an account in scope
2. You select the blueprint to deploy
3. The step triggers the deployment asynchronously
4. The automation continues to the next step immediately — deployment happens in the background

The blueprint's [current version](/accounts/manage-accounts/blueprints#versions) is the one applied. To deploy a different version, use `Make v{N} current` on the blueprint's `Version history` tab first.

## Set up the action

1. Open the automation builder and add a new step
2. Under **Advanced**, select **Apply blueprint**
3. Configure the field:

| Field | Required | Description |
| --- | --- | --- |
| **Blueprint** | Yes | The blueprint to deploy to the account. Select from your available blueprints. |

:::tip
Use data passing for dynamic blueprint selection, so you can choose different blueprints based on trigger data or earlier step outputs.
:::

## Outputs

This action produces no outputs available to downstream steps.

## Tips

- **The automation does not wait for the blueprint to finish.** If downstream steps depend on resources the blueprint creates, such as AI employees or automations, add a **Delay** step to allow time.
- **Check the result on the blueprint.** The `Applied accounts` tab shows whether the apply succeeded, which version landed, and per-component errors when it failed.
- **Campaigns are created once, never updated.** If the target account already has a campaign from an earlier apply, the campaign component will fail with `Campaign updates are not yet supported`. Other components still apply. See [Campaigns are created once, never updated](/accounts/manage-accounts/blueprints#campaigns-are-created-once-never-updated) for details.
