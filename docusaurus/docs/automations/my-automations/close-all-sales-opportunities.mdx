# Close all sales opportunities

**Close all sales opportunities** closes every open sales opportunity on the account in scope. Use it in churn or deactivation workflows to clean up the pipeline when an account is lost. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the **Close all sales opportunities** step with an account in scope
2. The step finds all open opportunities associated with the account
3. Each opportunity is closed
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales**, select **Close all Sales Opportunities**

This action has no configuration fields — it closes all open opportunities on the account in scope.

## Outputs

This action produces no outputs available to downstream steps.
