# Update company

**Update company** updates one or more fields on the company record in scope. Use it to sync data from external systems, update fields based on automation logic, or keep company records current as events occur. This action is available on company-scoped triggers.

## How it works

1. The automation reaches the step with a company in scope
2. The step updates the fields you configured with the values you provide
3. The company record is updated in the CRM
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Businesses**, select **Update company**
3. Select the fields to update and provide values

:::tip
Use **Add dynamic content** to populate field values from previous steps. Dynamic values are resolved at runtime.
:::

## Outputs

This action produces no outputs available to downstream steps.
