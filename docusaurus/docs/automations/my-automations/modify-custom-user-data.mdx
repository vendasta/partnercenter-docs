# Modify custom user data

**Modify custom user data** writes or updates custom data fields on a user record. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the step with an account and user in scope
2. The step writes the values you configured to the specified custom data fields
3. The user's custom data is updated immediately
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Advanced**, select **Modify custom user data**
3. Configure the custom data fields and values

:::tip
Use **Add dynamic content** to populate values from previous steps.
:::

## Outputs

This action produces no outputs available to downstream steps.
