# Get order data

**Get order data** retrieves sales order data and brings it into scope for downstream steps. Use it when you need to access order details — products, pricing, status — in later steps.

## How it works

1. The automation reaches the step with an order in scope
2. The step retrieves the full order data
3. Order details are available to downstream steps via dynamic content
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales orders**, select **Get order data**

## Outputs

After the step runs, order data (products, pricing, status, tags) is available to downstream steps via **Add dynamic content**.
