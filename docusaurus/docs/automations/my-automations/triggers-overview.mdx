# Triggers overview

Every automation starts with a trigger — the event that kicks off the workflow.

## Trigger types

| Type | How it works | Best for | Example |
|---|---|---|---|
| **Event** | Fires instantly when something happens | Reacting in real time | Form submitted, contact created, opportunity changed |
| **Time-based** | Fires on a daily, weekly, or monthly schedule | Recurring tasks | Every Monday at 9 AM, 1st of each month |
| **Manual** | Fires when you click "Run" on a record | One-off tasks | Run for a specific account, company, or contact |
| **Advanced** | Fires from an external system | Third-party integrations | Webhook received, Zapier, API request |

## Trigger scope

Your trigger determines which actions are available downstream.

| Scope | What's in context | Example triggers |
|---|---|---|
| **Account** | Account data (tags, products, salesperson) | Account created, product activated |
| **Company** | Company + its account | Form submitted, company added to list |
| **Contact** | Contact + company + account | Contact created, web chat lead captured |
| **No entity** | Nothing — create records from scratch | Webhook, API trigger, on a schedule |

:::tip
Need data from a different scope? Use a **lookup step** (Find company, Find contact) to bring additional records into context.
:::

## Trigger conditions

Add conditions to filter which events qualify:

| Logic | How it works | Example |
|---|---|---|
| **AND** | All conditions must be true | Industry is "Healthcare" AND city is "Edmonton" |
| **OR** | Any condition can be true | Form A submitted OR Form B submitted |
