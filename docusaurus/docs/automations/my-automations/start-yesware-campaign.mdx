# Start a Yesware campaign for the contact

**Start a Yesware campaign for the contact** enrolls a contact in a Yesware email sequence. This action is available on contact-scoped triggers.

## How it works

1. The automation reaches the step with a contact in scope
2. The step enrolls the contact in the selected Yesware campaign
3. The contact begins receiving the Yesware email sequence
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Campaigns and emails**, select **Start a Yesware campaign for the contact**
3. Select the Yesware campaign

## Outputs

This action produces no outputs available to downstream steps.
