# Remove contact from Kixie powerlist

**Remove contact from Kixie powerlist** removes a contact from a Kixie powerlist, stopping automated calling for that contact. Use it when a lead converts, opts out, or no longer needs outbound outreach.

## How it works

1. The automation reaches the **Remove contact from Kixie powerlist** step with a contact in scope
2. The step removes the contact from the specified Kixie powerlist
3. The contact is no longer queued for automated calling in Kixie
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Integrations**, select **Remove contact from Kixie powerlist**
3. Configure the powerlist selection as prompted

## Outputs

This action produces no outputs available to downstream steps.
