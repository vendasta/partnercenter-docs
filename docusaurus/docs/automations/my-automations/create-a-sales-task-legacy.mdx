# Create a sales task (legacy)

**Create a sales task (legacy)** creates a legacy-format sales task on the account in scope. This action is available on account-scoped triggers.

:::warning
This is a legacy action. New automations should use **Create a CRM sales task for the company** or **Create a CRM sales task for the contact** instead, which create tasks in the modern CRM task system.
:::

## How it works

1. The automation reaches the **Create a sales task** step with an account in scope
2. The step creates a legacy sales task using the configuration you provide
3. The task appears in the account's sales task list
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales**, select **Create a sales task (legacy)**
3. Configure the task details as prompted

## Outputs

This action produces no outputs available to downstream steps.
