# Create and activate a sales order

**Create and activate a sales order** creates a new sales order and immediately activates it in a single step, beginning fulfillment of the ordered products. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the step with an account in scope
2. The step creates a sales order with the products and configuration you specified
3. The order is immediately activated
4. Product fulfillment begins
5. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales orders**, select **Create and activate a sales order**
3. Configure the order details including products, pricing, and billing

## Outputs

This action produces no outputs available to downstream steps.
