# Send a public system message

**Send a public system message** sends a public system message visible to everyone on the account. Use it for announcements, outage notifications, or milestone updates. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the step with an account in scope
2. The step sends a system message to the account
3. The message is visible to all users on the account
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Conversations**, select **Send a public system message**
3. Configure the message content

## Outputs

This action produces no outputs available to downstream steps.
