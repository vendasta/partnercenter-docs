# Set account lifecycle stage

**Set account lifecycle stage** changes the lifecycle stage of the account in scope to Lead, Prospect, or Customer. Use it to automatically progress accounts through your sales pipeline as they hit milestones. This action is available on account-scoped triggers.

## How it works

1. The automation reaches the **Set account lifecycle stage** step with an account in scope
2. The step updates the account's lifecycle stage to the value you selected
3. The account's stage is changed immediately
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Businesses**, select **Set account lifecycle stage**
3. Configure the field:

| Field | Required | Description |
| --- | --- | --- |
| **Lifecycle stage** | Yes | The stage to set. Options: **Lead**, **Prospect**, or **Customer**. |

## Outputs

This action produces no outputs available to downstream steps.
