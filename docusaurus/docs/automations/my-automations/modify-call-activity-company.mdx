# Modify a call activity for the company

**Modify a call activity for the company** updates an existing call activity on a company record. Use it to add notes, change the status, or update details on a previously logged call. This action is available on company-scoped triggers.

## How it works

1. The automation reaches the step with a company and call activity in scope
2. The step updates the call activity with the new details you configured
3. The updated call appears on the company's activity timeline
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Advanced**, select **Modify a call activity for the company**
3. Configure the fields you want to update

## Outputs

This action produces no outputs available to downstream steps.
