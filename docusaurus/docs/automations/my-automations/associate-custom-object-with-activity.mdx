# Associate custom object with activity

**Associate custom object with activity** links a custom object record to a CRM activity for tracking. Use it when you want to connect custom records (tickets, projects, properties) to specific activities in the CRM timeline.

## How it works

1. The automation reaches the step with a custom object and an activity in scope
2. The step creates a link between the custom object and the activity
3. The association is recorded in the CRM
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Custom objects**, select **Associate custom object with activity**

This action uses the custom object and activity currently in scope.

## Outputs

This action produces no outputs available to downstream steps.
