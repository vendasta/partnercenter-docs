# Add a note to the company

**Add a note to the company** creates a note on the company record in scope. Use it to log milestones, summarize conversations, or capture context from earlier automation steps. This action is available on company-scoped triggers.

## How it works

1. The automation reaches the step with a company in scope
2. The step creates a note with the content you configured
3. The note appears on the company's activity timeline
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Advanced**, select **Add a note to the company**
3. Configure the fields:

| Field | Required | Description |
| --- | --- | --- |
| **Note** | Yes | The text content of the note. Supports dynamic content from previous steps. |

:::tip
Use **Add dynamic content** to include data from earlier steps — for example, an AI-generated summary or a form submission body. This creates a rich, contextual note without manual input.
:::

## Outputs

This action produces no outputs available to downstream steps.
