# Activate products for the order

**Activate products for the order** activates the products associated with a sales order. Use it as part of an order fulfillment workflow to ensure products are turned on when an order is processed.

## How it works

1. The automation reaches the step with an order in scope
2. The step activates all products listed on the sales order
3. The products become available on the account
4. The automation continues to the next step

## Set up the action

1. Open the automation builder and add a new step
2. Under **Sales orders**, select **Activate products for the order**

## Outputs

This action produces no outputs available to downstream steps.
