# Automations overview

Automations in Partner Center run actions for you when a trigger happens, such as assigning a salesperson when a new client account is created. You build each workflow from a trigger, optional conditions, and the actions to perform.

## What can you do with automations? {#what-you-can-do-with-automations}

### Welcome new clients
When an account is created, send a welcome email campaign, assign a salesperson, and create a task for the salesperson to connect with the client.

### Drive product upgrades
When a client activates a Standard product, send an email campaign about Pro edition benefits and notify your team when they open or click.

### Keep track of failed payments
When a customer has a failed payment, receive a notification so you can follow up quickly.

## How do automation triggers work? {#understanding-automation-triggers}

Triggers are the events that start a workflow. Some are ready to use (e.g. **An account is created**). Others need **trigger options** — for example, **A sales order status is changed** requires you to set the order origin and the status it changes to.

![Trigger options example](./my-automations/img/automations/trigger-options.jpg)

### Trigger conditions
Conditions filter when the workflow runs. You can filter on tags, salespeople, account location, account categories, active products, and more. When you add multiple conditions, choose **AND** or **OR**:

- **OR** — The trigger runs when **any** condition in the group is met.
- **AND** — The trigger runs only when **all** conditions in the group are met.

![Trigger conditions example](./my-automations/img/automations/trigger-conditions.jpg)

When you choose a CRM field while building a condition, its field description appears below the field selector so you can confirm you've picked the right field, including any expected format or unit. The description only appears for fields that have one set. See [CRM Objects](/administration/data-management/crm-objects) to add or edit field descriptions.
For a complete list of triggers and how to choose the right one, see [Triggers overview](./my-automations/triggers-overview.mdx).

## How do I create my first automation? {#creating-your-first-automation}

1. In Business App go to **Settings** then **Automations**.
2. Click **Create** (top right).
3. Enter **Name**, optional **Description**, and **Status** (on/off).
4. Define the **trigger** (When) and optional **conditions** (If).
5. Set up the **action** that runs when the trigger and conditions are met.
6. Review and click **Create Automation**.

The automation runs whenever the trigger conditions are met (if it's turned on).

## Best practices

- **Start simple** — Build and test simple automations before complex workflows.
- **Use clear names** — So your team understands each automation's purpose.
- **Monitor regularly** — Check that automations are running as expected.
- **Consider impact** — Think through how automations affect the rest of your workflow.
- **Test first** — Run with a small group before enabling for all accounts.

## Frequently asked questions

<details>
<summary>What is an automation?</summary>

An automation is a workflow that follows a set of instructions: **when** this trigger happens, **then** perform this action. For example, when a new client is added, assign a salesperson to the account.

</details>

<details>
<summary>How do I add a trigger to an automation?</summary>

When you create an automation, define the **trigger** (When) and any optional **conditions** (If), then set up the **action**. Some triggers are ready to use, such as **An account is created**, while others need trigger options, such as the order origin and status for **A sales order status is changed**.

</details>

<details>
<summary>Can I limit which accounts an automation runs for?</summary>

Yes. Add trigger conditions to filter on tags, salespeople, account location, account categories, active products, and more. With multiple conditions, choose **OR** to run when any condition is met or **AND** to run only when all conditions are met.

</details>

<details>
<summary>Can I start from a pre-built automation instead of building one?</summary>

Yes. [Templates](/automations/templates/) give you pre-built workflows to get started quickly, and [System automations](/automations/system-automations/) are pre-built workflows provided by Vendasta that you can enable or disable per account.

</details>

<details>
<summary>Does an automation run as soon as I create it?</summary>

The automation runs whenever its trigger and conditions are met, as long as its **Status** is turned on.

</details>

<details>
<summary>Where can I check whether my automations ran?</summary>

Use [Automation history](/automations/automation-history/) to monitor runs, troubleshoot errors, retry failed automations, and fix permissions.

</details>
