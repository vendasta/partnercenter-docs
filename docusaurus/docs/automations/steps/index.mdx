# Step deep-dives

Most automation steps are simple enough that the [Automation steps reference](../automation-steps-reference.mdx) tells you everything you need to know. The pages here cover steps that have richer configuration, multiple outputs, or use cases that benefit from a walkthrough.

## In this section

- **[Categorize with AI](./categorize-with-ai.mdx)** — Classify text into categories you define and branch the automation based on the result.
- **[Find company](./find-company.mdx)** — Search for an existing CRM company by field criteria and bring it into scope for downstream steps.
- **[Find custom object](./find-custom-object.mdx)** — Search for an existing custom object record and bring it into scope for downstream steps.
- **[Copy assistant automation](./copy-assistant-automation.mdx)** — Replicate an AI employee's configuration from a source account to other companies.
