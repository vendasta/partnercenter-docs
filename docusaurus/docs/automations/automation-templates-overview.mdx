# Automation Templates Overview

We have a great collection of example templates that can help you get started using automation within the platform. [Here](https://partners.vendasta.com/automations/create-from-template), you will find a list of example templates along with a description of what they do, how to use them, and some possible next steps.

This article can serve as a manual, providing extra context as you [create your own automation](https://partners.vendasta.com/automations) in the platform.

## Getting Started with Templates

Templates provide pre-built automation workflows that you can customize for your specific needs. They're designed to address common business scenarios and can save you significant time in setting up your automations.

### How to Use Templates

1. Navigate to **Partner Center** > **Automations**
2. Click **Create Automation**
3. Select **From Template**
4. Browse available templates by category or objective
5. Click **Use Template** on your chosen template
6. Customize the template settings for your needs
7. Test and activate your automation

The blank template is the canvas from which you can create your own automations from scratch. When you set up a new blank template, you will be prompted to choose a trigger (the condition that kicks off the rest of the workflow) and steps (the actions that your automation does after the automation is triggered).

To learn more about how to use automation, see [Automations overview](./index.mdx). You can also find all [available triggers](./automation-triggers-reference.mdx) and [available steps](./automation-steps-reference.mdx) to learn what they do and how they work.

## Featured Templates

### Auto-assign a salesperson to new accounts

Automatically assign a specific salesperson (or a member of a sales team) to every account that gets created.

**Setup:**

1. Go to **Partner Center** → **Automations** → **Create automation** and select **Blank Template**.

   ![Blank automation template](./img/automations/my-automations/auto-assign-salesperson-blank-template.jpg)

2. Under **Start the automation when**, select **An account is created** and click **Save**. Add conditions only if you want to limit which accounts trigger the automation.

   ![Account created trigger](./img/automations/my-automations/auto-assign-salesperson-trigger.jpg)

3. Click the **+** under the trigger, scroll to **Sales**, and select **Assign a salesperson** (or **Assign a sales team** for round-robin assignment across a team).

   ![Assign a salesperson step](./img/automations/my-automations/auto-assign-salesperson-action.jpg)

4. Pick the salesperson (or team) and click **Save**.
5. Toggle the automation **On**.

### Recurring Sales Task

This automation creates a recurring sales task on weekdays from 9 to 5 every 30 days for a full year.

**Customization Options:**
- Change how often the task is created by editing the number of days in the delay step
- Edit how many times this process repeats by modifying the jump to a step action at the end of the automation

### Segment Accounts Into Lists

### AGOGE Task Sequence on Company (Advanced Automation)

This automation template is triggered manually and creates an opportunity if there isn't one open for the company. It follows the AGOGE sequence to create tasks on day 1, day 3, day 4, day 7, day 10, day 14, day 17, day 19, and day 24. It sends reminders to the assigned salesperson if tasks aren't completed within 1 day for up to 5 times.

**Prerequisites:**
- Pipeline set up to create sales opportunities
- Product or package added to opportunities

**How It Works:**
- Creates tasks following the AGOGE methodology
- Sends reminders for incomplete tasks
- Stops when no open opportunities exist or tasks aren't completed within 5 days

## System Automations

System automations are pre-built automations that run automatically in the background to enhance your platform experience. These automations are managed by Vendasta and help streamline common processes.

### What Are System Automations?

System automations are built-in workflows that:
- Run automatically without user configuration
- Handle common platform tasks
- Improve user experience and data consistency
- Cannot be modified by users (but can often be disabled)

### Common System Automations

**Hot Lead Detection**
- Automatically identifies engaged prospects
- Flags accounts showing high interest
- Triggers notifications to sales teams

**Product Activation Workflows**
- Handles standard onboarding processes
- Creates necessary accounts and permissions
- Sends welcome communications

**Data Synchronization**
- Keeps information consistent across systems
- Updates related records automatically
- Maintains data integrity

**Notification Systems**
- Sends alerts for important events
- Manages communication preferences
- Handles escalation procedures

### Managing System Automations

While you cannot modify system automations, you can:
- View their activity in automation history
- Disable specific system automations if needed
- Create complementary custom automations
- Monitor their impact on your workflows

## Template Customization Best Practices

### Before You Start

1. **Understand Your Process**: Map out your current manual process
2. **Identify Key Triggers**: Determine what events should start the automation
3. **Define Success Metrics**: Know how you'll measure the automation's effectiveness
4. **Plan for Edge Cases**: Consider unusual scenarios that might occur

### Customization Guidelines

1. **Start Simple**: Use the template as-is first, then add complexity
2. **Test Thoroughly**: Test with real data before going live
3. **Document Changes**: Keep track of modifications you make
4. **Monitor Performance**: Watch how the automation performs over time

### Common Customizations

**Adding Conditions**
- Filter triggers based on account properties
- Add geographic or demographic criteria
- Include/exclude specific account types

**Extending Workflows**
- Add additional notification steps
- Include more comprehensive data collection
- Create parallel processes for different scenarios

**Integration Enhancements**
- Connect to external systems via API
- Add webhook notifications
- Sync with third-party tools
