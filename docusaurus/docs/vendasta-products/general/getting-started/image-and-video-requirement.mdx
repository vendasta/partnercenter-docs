# Image and Video Requirements

Social Marketing helps you post to all of your most important social media accounts.  
Each social network has specific requirements for images and videos.  
Follow these guidelines to ensure your posts display correctly across all platforms.

---

## Image Requirements

Social Marketing supports the following image types: **PNG**, **JPEG**, and **GIF**.  

**Recommended:**  
If posting to multiple social networks, use **square images (1:1)** for best consistency.

### Facebook

| | |
| --- | --- |
| **Recommended Dimensions** | 1200 × 1200 px (square 1:1) <br />1080 × 1350 px (vertical 16:9) |
| **Minimum Dimensions** | 600 × 315 px |
| **Maximum File Size** | 4 MB |
| **Notes** | - PNGs over 1 MB may appear pixelated. <br /> - Supports up to 10 images per post. <br /> - Facebook arranges multiple images based on the first uploaded one. <br /> - Use consistent image sizes for best results. |

---

### Instagram

| | |
| --- | --- |
| **Recommended Dimensions** | 1080 × 1080 px (square 1:1) <br />1080 × 566 px (landscape 1.91:1) <br />1080 × 1350 px (portrait 4:5) |
| **Minimum Dimensions** | 640 × 640 px |
| **Maximum File Size** | 30 MB |
| **Notes** | - PNGs over 1 MB may appear pixelated. <br /> - Supports up to 10 images or videos per carousel post. |

---

### Google Business Profile

| | |
| --- | --- |
| **Recommended Dimensions** | 720 × 720 px (square 1:1) |
| **Minimum Dimensions** | 250 × 250 px |
| **Maximum File Size** | 5 MB (must be greater than 10 KB) |
| **Notes** | - One image per post. <br /> - Image should be clear, well-lit, and realistic (no excessive filters or edits). |

---

### X (formerly Twitter)

| | |
| --- | --- |
| **Recommended Dimensions** | 1200 × 675 px (landscape 16:9) |
| **Minimum Dimensions** | 600 × 335 px (landscape 1.79:1) |
| **Maximum File Size** | 5 MB (PNG/JPEG) <br />15 MB (GIF) |
| **Notes** | - Supports up to 4 images per post. <br /> - GIFs must meet the following: <br /> • Resolution ≤ 1280 × 1080 px <br /> • ≤ 350 frames <br /> • Total pixels ≤ 300 million <br /> • Must loop or it will upload as a still image. |

---

### LinkedIn

| | |
| --- | --- |
| **Recommended Dimensions** | 1200 × 627 px (landscape 1.91:1) |
| **Minimum Dimensions** | 200 px width |
| **Maximum File Size** | 10 MB |
| **Notes** | - Supports up to 9 images per post. |

## Best Practices

- Keep all media within the file size and duration limits.  
- Use high-quality, on-brand visuals.  
- Maintain consistent image ratios when posting to multiple networks.  
- Always preview your post before publishing.
