# Docusaurus docs content rules

- Keep `<details>` blocks formatted with blank lines after the `<summary>` and before the closing `</details>` tag. Each tag should be on its own line to avoid MDX compilation errors.
- Close every HTML tag you open in Markdown, especially `<details>` and `<summary>` pairs.
- Follow the Documentation agent playbook in `/docs/agents.md` for tone, structure, and link conventions.
