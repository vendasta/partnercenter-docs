Pipelines in Partner Center track how sales opportunities progress through stages and forecast revenue. Use the default four-stage pipeline or create custom pipelines at `Administration` → `Pipelines` with your own stages and forecast percentages.

## Default pipeline

The default pipeline has four stages: **Lead**, **Contact**, **Qualified**, and **Proposal**, with forecast percentages of 0%, 20%, 40%, and 60% respectively. Revenue forecasts are based on the probability you set for each stage. If the default doesn't fit your business, you can create custom pipelines and define your own stages and percentages.

## Pipeline management

- **Create pipelines** – Set up new sales and workflow pipelines
- **Pipeline stages** – Configure stages and progression rules
- **Pipeline automation** – Set up automated actions and triggers
- **Pipeline analytics** – Track performance and conversion rates across stages
- **Pipeline templates** – Use and create reusable templates

## How do I create a pipeline? {#how-to-create-a-pipeline}

1. Go to `Partner Center` → `Administration`, then click `Pipelines`.

   ![Pipeline menu in Administration](../img/data-management/pipeline-menu.jpg)

2. Edit the existing pipeline or click `Create pipeline` to add a new one. Stages appear in your pipeline in the order of the probability of success you assign them.

   ![Create pipeline interface](../img/data-management/create-pipeline.jpg)

## Frequently asked questions

<details>
<summary>Can I enter the same value for multiple pipeline stages?</summary>

No. Each pipeline stage must have a unique numerical value for close probability. If you enter the same value for multiple stages, the system will show an error.
</details>

<details>
<summary>What are the default pipeline stages?</summary>

The default pipeline has four stages: **Lead**, **Contact**, **Qualified**, and **Proposal**, with forecast percentages of 0%, 20%, 40%, and 60% respectively.
</details>

<details>
<summary>How do I customize the default pipeline?</summary>

Go to `Partner Center` → `Administration`, then click `Pipelines`. Edit the existing pipeline, or click `Create pipeline` to add a custom pipeline with your own stages and forecast percentages.
</details>

<details>
<summary>How are pipeline revenue forecasts calculated?</summary>

Revenue forecasts are based on the probability you set for each stage.
</details>

<details>
<summary>How is the order of pipeline stages set?</summary>

Stages appear in your pipeline in the order of the probability of success you assign them.
</details>
