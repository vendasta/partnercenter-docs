Customize your platform’s appearance with your own logos, colors, company name, and visual elements. White-label branding keeps your identity consistent everywhere customers see the platform: Business App, email campaigns, and client communications.

## Why it matters

Strong branding gives a unified, professional experience and reinforces your business. White-labeling removes other brands so clients see only yours, which builds trust and matches how you present your business elsewhere.

## What's included

- **Brand identity** – Company name, logos, color themes, favicon
- **White-label** – Replace external brand references across the platform
- **Multi-market** – Different branding per market; generic or market-specific logos for login
- **Technical** – File format and size guidance; changes apply quickly

## Set up company name and primary branding

1. Go to `Partner Center` → `Administration` → `Partner branding`
2. Set `Company Name` – Enter the name you want in client communications and across the platform
3. Save

## Configure color theme

1. In `Partner branding`, open the `Theme` section
2. Set `Primary` (and any secondary/background) colors
3. Preview, then save

The theme applies across customer-facing areas.

## Manage logos

### Upload primary logo

1. Go to `Partner Center` → `Administration` → `Partner branding` → `Logo`
2. Upload your logo (PNG or JPG; transparent PNG recommended)
3. Use a high-resolution file for clear display on different devices
4. Position and save

![Partner branding logo settings](./img/administration/partner-branding/partner-branding-logo.jpg)

### Market-specific branding

1. In `Partner branding`, use the `All Markets` dropdown (top right) to select a market
2. Set logos, colors, and company name for that market
3. Save; repeat for other markets

### Login page branding

1. In `Partner branding` → `Logo`, upload the logo you want on the login page
2. **Note:** The login page cannot be fully white-labeled. With multiple markets, you can use a generic logo for the default market so that market-specific branding appears after login.

![Business App Login Page](./img/administration/partner-branding/business-app-login.jpg)

:::info
You cannot fully white-label the login page. Using a generic logo for the default market lets market-specific branding show once users are in Business App.
:::

## Favicon and browser icons

### Upload favicon

1. Go to `Partner Center` → `Administration` → `Partner branding` → `Favicon`
2. Use an `ICO` file (e.g. favicon.ico). PNG/JPG are not accepted.
3. Recommended size: 16×16 or 32×32 px
4. Upload and check that it appears in browser tabs

![Favicon upload error message](./img/administration/partner-branding/favicon-error.png)

### Favicon troubleshooting

- **Wrong format** – Use .ico only. Convert PNG/JPG to ICO if needed.
- **Blurry or distorted** – Use 16×16 or 32×32 px; keep the design simple.
- **Not updating** – Clear browser cache or try a private window; favicons are cached.

### Company avatar / shortcut icon

1. In `Partner branding`, set `Company Avatar` (square image for profiles, small contexts)
2. Set `Shortcut Icon` for mobile home screen and bookmarks (512×512 px; GIF, JPG, or PNG)
3. Save and test on different devices

## Where branding appears

- **Business App** – Logos in navigation and headers, brand colors, company name, favicon in tabs
- **Emails** – Logo, brand colors, company name in headers, footers, and sender info
- **Login and client areas** – Branded login (with limits above); market-specific branding after login

## Frequently asked questions

<details>
<summary>Can I completely white-label the platform?</summary>

Yes, for most areas. You can replace logos, colors, company name, and most visual elements. Some options may depend on your subscription.
</details>

<details>
<summary>Why is my favicon not uploading?</summary>

Favicons must be ICO files (e.g. image.ico, not image.png or image.jpg). Go to `Partner Center` → `Administration` → `Partner branding` → `Favicon`.

If it still fails: check the file is .ico, keep size small (16×16 or 32×32), or try recreating the ICO. If the problem continues, contact support.
</details>

<details>
<summary>Can I customize the Business App login page?</summary>

You cannot fully white-label the login page. With multiple markets, use a generic logo for the default market; that logo shows on login, and market-specific branding shows inside Business App after login.

To change branding: `Partner Center` → `Administration` → `Partner branding` → `Logo`. For multiple markets, use the `All Markets` tab (top right) and customize per market.
</details>

<details>
<summary>How quickly do branding changes take effect?</summary>

Most changes apply immediately. Favicons can lag due to browser caching.
</details>

<details>
<summary>What file formats work best for logos?</summary>

PNG with a transparent background is best. Use high resolution for clarity on different devices.
</details>

<details>
<summary>Can I have different branding for different markets?</summary>

Yes. Use the market selector in Partner branding to set logos, colors, and company name per market.
</details>

<details>
<summary>What if I don't set up custom branding?</summary>

The platform uses default visuals. Custom branding gives a more professional, consistent experience.
</details>

<details>
<summary>Are there subscription limits on branding?</summary>

Some white-label options may vary by plan. Check your subscription or contact support for details.
</details>

<details>
<summary>How do I test branding before rolling it out?</summary>

Use any preview options in the settings, and test with a small group before applying everywhere.
</details>

<details>
<summary>What if my branding isn't displaying correctly?</summary>

Check file formats, image sizes, and clear browser cache. If it still fails, contact support with the specifics.
</details>
