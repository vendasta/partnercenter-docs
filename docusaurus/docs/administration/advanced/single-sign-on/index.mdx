# Single Sign-On

Single Sign-On (SSO) lets clients access Vendasta products using your organization's logins. SSO is available for partners on **Premium** or **Custom** subscriptions. Configure it from `Partner Center` → `Administration` → `Advanced` → `Single Sign-On`.

:::info Authentication security
Vendasta maintains a current SOC 2® Type 2 report covering its security controls. For details on how authentication and access are secured, see [Security and privacy](/getting-started/security-and-privacy) or visit the [Vendasta Trust Center](https://trust.vendasta.com/).
:::

## What SSO is

SSO in Partner Center is an authentication mechanism that lets users access the platform with a single set of credentials. It streamlines the login process and improves user experience by enabling access without repeatedly entering usernames and passwords for different services.

## How it works

- **Less friction** – SSO reduces unnecessary authorization steps, especially on first-time launches of integrated tools. Users can be routed directly into Partner Center or associated applications without extra authorization dialogs.
- **Return to your page** – The SSO flow captures the URL of the page you are on so you return to the same page after completing authentication. This keeps context and continuity in your workflow.
- **Session and access** – SSO manages session transfers and authentication states so users stay logged in and keep the right access. It supports role-based access control so permissions match each user’s role in the platform.

When issues occur (for example login failures or session transfer problems), troubleshooting usually involves checking session handling and authentication flows so the user is properly authenticated and redirected in Partner Center.

Overall, SSO simplifies access, maintains session integrity, and supports a smooth experience within the platform.

## What SSO covers

- **SSO setup** – Configure Single Sign-On for your organization

- **User management** – Manage user access and permissions through SSO
