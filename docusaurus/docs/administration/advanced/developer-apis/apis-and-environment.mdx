## What are Vendasta's APIs?

Vendasta offers public platform and product APIs on certain paid Partner Center subscription levels, plus vendor APIs with no subscription requirement for building your own products. Vendasta Support can give you access to a sandbox environment for integration testing.

The sandbox lets you test API and SSO integrations before you move to production. This article covers API availability, supported products, and testing environments.

## Why are APIs important?

APIs (Application Programming Interfaces) allow you to:
- Integrate Vendasta with your existing systems
- Automate workflows and data synchronization
- Build custom applications and solutions
- Extend the functionality of Vendasta products
- Create consistent user experiences across platforms

## What you can do with Vendasta APIs

| Feature | Description |
|---------|-------------|
| **Public API Access** | Connect to Vendasta's platform programmatically |
| **Product Integration** | Integrate with specific Vendasta products via their APIs |
| **Sandbox Testing** | Test integrations safely before production deployment |
| **Custom Development** | Build your own products using Vendasta's vendor APIs |

## How do I access Vendasta APIs? {#how-to-access-vendasta-apis}

### Public API availability

If you're on certain [paid subscription levels](https://www.vendasta.com/pricing/), we offer a number of APIs that enable you to complete work outside of Partner Center.

**Platform and Product APIs:**
Detailed API documentation for the platform and Vendasta products can be found at [https://developers.vendasta.com/platform](https://developers.vendasta.com/platform)

**Vendor APIs:**
API documentation for building your own products can be found at [https://developers.vendasta.com/vendor](https://developers.vendasta.com/vendor) (no subscription requirements)

### API access requirements

- APIs are available on certain paid subscription levels
- Check the [Vendasta pricing page](https://www.vendasta.com/pricing/) for subscription details
- Vendor APIs for building your own products have no subscription requirements

## Available product APIs

### Products with API access

We have APIs for the following products:

- **Brand Analytics** - Access analytics and reporting data
- **Business App** - Integrate with business application features  
- **Partner Center** - Manage accounts, users, and platform settings
- **Local SEO** - Control local search optimization features
- **Reputation AI** - Manage reviews and reputation data
- **Social AI** - Automate social media posting and management
  - *Note: the API does not support all features available in-product for Social AI*

### Products without API access {#products-without-current-api-access}

Vendasta doesn't have APIs for the following products and services:

- **Snapshot Report** - One-time reporting tool
- **Task Manager/Fulfillment** - Task management and workflow features
- **Billing reports** - Financial and billing data access

:::tip API Development
Check the [developer documentation](https://developers.vendasta.com/platform) for the most current list of available APIs and their capabilities.
:::

## Sandbox environment

### What is the sandbox environment?

Vendasta offers a sandbox environment for initial development work if you're new to integrating with Vendasta via API and/or SSO. This environment pulls in live data, so you can use it for integration testing.

### Sandbox environment benefits

- **Safe Testing** - Test integrations without affecting production data
- **Live Data Access** - Environment pulls in real data for realistic testing
- **Support Assistance** - Our Support team answers questions during sandbox testing
- **Pre-Production Validation** - Ensure comfort before migrating to production environment

### How do I access the sandbox environment? {#how-to-access-the-sandbox-environment}

The sandbox environment is available if you're planning API and/or SSO integrations:

1. **Contact Support** - Reach out to [support@vendasta.com](mailto:support@vendasta.com) for access
2. **Provide Integration Details** - Share information about your planned integration
3. **Receive Sandbox Access** - Get credentials and access to the testing environment
4. **Begin Testing** - Start development work in the safe sandbox environment

### Sandbox to production migration

Our Support team will:
- Guide you through sandbox testing
- Answer integration questions
- Ensure you're comfortable with your integration
- Assist with migration to the production environment when ready

## How do I get started with Vendasta APIs? {#getting-started-with-apis}

### Prerequisites

Before beginning API integration:
- Ensure your subscription includes API access
- Review the relevant API documentation
- Plan your integration requirements
- Consider requesting sandbox access for testing

### Integration process

1. **Planning phase**
   - Define integration goals and requirements
   - Review available APIs for your use case
   - Determine which products need API access

2. **Development phase**
   - Request sandbox environment access
   - Begin development and testing in sandbox
   - Implement authentication and error handling

3. **Testing phase**
   - Thoroughly test all integration points
   - Validate data flow and error scenarios
   - Work with Support team to resolve issues

4. **Production phase**
   - Complete final testing and validation
   - Migrate to production environment
   - Monitor integration performance

## FAQs

<details>
<summary>Does Vendasta have public APIs?</summary>

Yes, on certain paid subscription levels, we offer APIs that enable you to complete work outside of Partner Center. Detailed documentation is available at [https://developers.vendasta.com/platform](https://developers.vendasta.com/platform).

</details>

<details>
<summary>Which products have API access available?</summary>

APIs are available for Brand Analytics, Business App, Partner Center, Local SEO, Reputation AI, and Social AI. APIs are not available for Snapshot Report, Task Manager/Fulfillment, and Billing reports.

</details>

<details>
<summary>Is there a sandbox environment for testing?</summary>

Yes, Vendasta offers a sandbox environment for integration testing. The environment uses live data and is intended for development work. Contact [support@vendasta.com](mailto:support@vendasta.com) to request access.

</details>

<details>
<summary>Do I need a paid subscription to access APIs?</summary>

Platform and product APIs require certain paid subscription levels. However, vendor APIs for building your own products have no subscription requirements. Check the [pricing page](https://www.vendasta.com/pricing/) for details.

</details>

<details>
<summary>How do I get started with API integration?</summary>

Start by reviewing the API documentation at [https://developers.vendasta.com/platform](https://developers.vendasta.com/platform), then contact [support@vendasta.com](mailto:support@vendasta.com) to discuss sandbox access and integration planning.

</details>

Yes, APIs have rate limiting and usage guidelines. Review the specific documentation for each API at [https://developers.vendasta.com/platform](https://developers.vendasta.com/platform) for detailed information about limits and best practices.
