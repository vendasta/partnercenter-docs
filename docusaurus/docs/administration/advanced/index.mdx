# Advanced

Advanced in **Administration** gives you APIs, integrations, service accounts, single sign-on, and translation tools. Use them to connect external systems, automate workflows, and tailor the platform for your organization.

## What you can do

- **Use public APIs** – Integrate with Vendasta programmatically; sandbox available for testing
- **Connect third-party tools** – QuickBooks, Google Meet, Zoom, Zapier; authentication and connection setup in one place
- **Manage service accounts** – Create accounts for system-to-system access; API keys and permissions
- **Configure SSO** – Single sign-on with your identity provider for centralized authentication
- **Translate and customize** – Use Weblate to translate and customize platform language and UI for your markets

## How it works

APIs and integrations use secure connections and depend on your subscription; a sandbox is available for testing before production. Service accounts provide machine access for automated integrations; SSO delegates user sign-in to your identity provider. Connection types (API key, SSO, vendor-managed) are set per integration under **Partner Center** → **Administration** → **Integrations**.

## Get started

1. **APIs** – Go to [Developer APIs](./developer-apis/index.mdx) and [developers.vendasta.com](https://developers.vendasta.com/platform); confirm your plan includes API access and request sandbox if needed.
2. **Integrations** – Go to **Partner Center** → **Administration** → **Integrations**. Start with [Authentication and connections](./integrations/authentication-and-connections.mdx), then add QuickBooks, Google Meet/Zoom, or Zapier as needed.
3. **SSO or service accounts** – Go to [Single Sign-On](./single-sign-on/index.mdx) for user authentication or [Service Accounts](./service-accounts/index.mdx) for automated integrations.

:::tip
Use the sandbox environment to test API and integration changes before going live. Contact support for sandbox access if needed.
:::

## Error handling and troubleshooting

- **API or integration failures** – Check API keys, subscription API access, and endpoint URLs; confirm webhook URLs and data formats for integrations.
- **SSO issues** – Verify identity provider configuration, certificate validity, and user attribute mapping.
- **Permission errors** – Ensure service accounts have the right access and that API permissions are configured correctly.

If you run into persistent issues, contact [support@vendasta.com](mailto:support@vendasta.com) with error details and integration context.
