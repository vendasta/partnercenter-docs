# Google Analytics 4 Complete Build

## Overview

GA4 Complete Build is a quick, done-for-you solution where an advertising specialist creates a new Google Analytics 4 (GA4) property, installs and connects Google Tag Manager (GTM), and sets up to three goals—so analytics are ready to go. The service level agreement (SLA) for delivery is **3 business days**.

## What's Included

- Set up a new Google Tag Manager (GTM) container
- Add the GTM code to the website
- Create a new GA4 property
- Connect GTM with GA4
- Set up new goals in GA4 (up to 3 goals)
- Review goal setup after 48 hours to ensure proper syncing

:::note Additional goals
We set up to three goals. If more are needed, activate the hourly-rate add-on for each set of three additional goals.
:::

## Prerequisites

- **Website access** — needed to add the GTM code to the site.
- **A Google login ID and password** — needed to set up GA4 and GTM.
- **A list of expected goals** — if goals aren't provided, our team will request them and suggest goals based on the website. You must **approve the goals** for us to set them up, or the goal setup option is forfeited.

## Getting Started

1. **Order and fulfillment form** — Our team receives the fulfillment form and begins creating and installing the new GA4 account and Google Tag Manager. If we have questions, we'll reach out by email.
2. **GA4 + GTM setup (Day 1)** — We set up Google Tag Manager, add the GTM code to the website, create a new GA4 property, connect GTM with GA4, and set up your goals (up to 3). This takes 1–3 business days.
3. **48-hour wait period** — After the final setup steps, a 48-hour wait period confirms the goals have migrated and are syncing properly.
4. **Final check (3rd business day)** — Our team confirms the setup was completed correctly and reviews the goal setup after 48 hours. We'll reach out by email if there are issues to correct (which could delay the SLA).
5. **Confirmation** — We send an email confirming the build is complete and that all goals are set up and syncing.

The SLA is **3 business days**, though it may be delayed if data is missing or issues need to be corrected.
