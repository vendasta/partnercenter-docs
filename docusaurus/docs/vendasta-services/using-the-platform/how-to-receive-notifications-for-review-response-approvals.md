To receive Vendasta Services review response approval emails, add the person as a user on the account in Partner Center, then enable the `Review`, `Review Response`, and `Review Response Approval` instant email notifications for Reputation AI.

Vendasta Services review response services for Reputation AI can include an optional approval process for responses to negative reviews. Users can receive email notifications with the proposed responses.

To receive these email notifications, you must [add the respective person as a user to the account in Partner Center](../../accounts/manage-users/) and configure the applicable user notifications.

## How do I configure user notifications? {#configuring-user-notifications}

Reputation AI must be active on the account.  
  

1.  In Partner Center, click on `Accounts` → `Manage Users`.  
    ![PC Manage Users.png](./img/23186071999127-0fd7c6820f.png)  
      
    
2.  Next to the applicable user, click the 3 dots, then `Edit Notifications` from the drop-down menu.  
    ![PC User Notifications.png](./img/23186071999127-d1dbd5820c.png)  
      
    
3.  You see a list of accounts that the user has been added to. Click on the drop-down arrow next to the applicable account to expand the notifications list.
    1.  Click on `Reputation AI` to display the notifications associated with the Reputation AI platform.  
        ![PC User Notifications Rep Man.png](./img/23186071999127-1139105d2a.png)  
          
        
4.  When you first add a user to an account, all of the notifications for that user/account will be enabled by default. Ensure that the following `Instant Email` notifications are enabled:

    - `Review`
    - `Review Response`
    - `Review Response Approval`

With these notifications enabled, the user will receive email notifications when there is a review response that requires their approval, such as a response to a negative review. The email will look like this:

**Subject:** New Review Response Approval for Business Name

![Fake Review Response Approval Email.png](./img/23186071999127-3601f8e360.png)

The user can click `Approve or Request Changes` within the email to be redirected to the platform, where they can provide feedback on the review response directly to the fulfillment team.

## Frequently asked questions

<details>
<summary>Does the person approving responses need to be a user on the account?</summary>

Yes. To receive review response approval emails, the person must be [added as a user to the account in Partner Center](../../accounts/manage-users/), with the applicable user notifications enabled.

</details>

<details>
<summary>Does Reputation AI need to be active on the account?</summary>

Yes. Reputation AI must be active on the account for its notifications, including review response approvals, to be available.

</details>

<details>
<summary>Which notification settings should I check?</summary>

In `Accounts` → `Manage Users`, click the 3 dots next to the user, then `Edit Notifications`. Expand the account, click `Reputation AI`, and make sure the `Review`, `Review Response`, and `Review Response Approval` instant email notifications are enabled.

</details>

<details>
<summary>Are review notifications enabled by default for new users?</summary>

Yes. When you first add a user to an account, all of the notifications for that user and account are enabled by default.

</details>

<details>
<summary>How does a user approve a proposed review response?</summary>

The user clicks `Approve or Request Changes` in the approval email. This opens the platform, where they can approve the response or send feedback directly to the fulfillment team.

</details>
