## Add individual accounts to lists

To add an individual account to a List:

1. Go to `Partner Center` → `Accounts` → `Manage Accounts`.
2. Find the account you want to add to the list, then click the `menu` icon at the end of the row.

<img src={require('./img/accounts/lists/menu-icon.jpg').default} alt="Menu icon" style={{width: '50px', border: '1px solid #e0e0e0', borderRadius: '8px', boxShadow: '0 2px 8px rgba(0,0,0,0.08)'}} />

3. Click `Add to List`.
4. Add the account to a list:
   - To add it to an existing list: select the list from the dropdown menu, then click `Add`.
   - To add it to a new list: go to the `Create New List` tab, enter a name for the list, then click `Create and Add`.

## Add multiple accounts to lists

To add multiple accounts to a List:

1. Go to `Partner Center` → `Accounts` → `Manage Accounts`.
2. Filter and search for the accounts you want to add to a List.
   :::note
   You can use filters and the search bar to find your accounts.
   :::
3. Click `Add # to List`.
4. Add the accounts to a list:
   - To add them to a new list: enter a name for the list, then click `Create and Add`.
   - To add them to an existing list: go to the `Add to List` tab, select the list from the dropdown menu, then click `Add`.

## Remove accounts from lists

1. Go to `Partner Center` → `Accounts` → `Lists`.
2. Click the list name.
3. Find the account, open the row menu, and select `Remove from list`.
4. Confirm removal.

## FAQs

<details>
<summary>Can I add the same account to multiple lists?</summary>

Yes. You can add an account to as many lists as you need. This is useful when you want to organize accounts in different ways - for example, having an account in both a "Newsletter Subscribers" list and a "Premium Customers" list.
</details>

<details>
<summary>What happens if I try to add an account that's already in the list?</summary>

The system prevents duplicate entries. If you try to add an account that's already in a list, the account isn't added again, and no error message displays.
</details>

<details>
<summary>Is there a limit to how many accounts I can add to a list at once?</summary>

When using the bulk add feature, you can add any number of filtered accounts to a list. However, for optimal performance, it's recommended to work with batches of up to 1000 accounts at a time when performing bulk operations.
</details>
