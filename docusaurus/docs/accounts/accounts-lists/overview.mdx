## What are Lists?

Lists let you group accounts for organization and bulk actions. You can create lists manually or by importing CSVs, add/remove accounts, and perform actions on all accounts in a list.

## Why are Lists important?

- Organize accounts by segment, region, or workflow
- Run bulk actions like exports, product activation, and automations
- Speed up onboarding using create/import flows and add/remove tools

## What’s included with Lists?

- Create and import lists
- Add and remove accounts
- Built-in list actions (export, add tags, activate products, trigger automations, and more)

1. Create or import a list
   - See: [Create and Import Lists](./create-account-lists)
2. Add or remove accounts as needed

3. Use list actions for common bulk tasks
