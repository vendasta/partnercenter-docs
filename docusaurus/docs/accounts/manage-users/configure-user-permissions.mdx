## Configure user permissions

1. Go to `Partner Center > Accounts > Manage Users` (or from an account’s `Users` tab).
2. Open the user menu and choose `Edit permissions`.
3. Add or remove account access, and toggle product/tab access as needed.

## Grant access to a multi-location group

From a Multi-Location Group, open `Users`, add the user, and save.
