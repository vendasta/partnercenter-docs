## What is Manage Users?

Manage Users lets you create user accounts, assign them to business accounts, and configure their permissions for Business App.

## Why it matters

- Give customers secure access to Business App
- Control what users can see and do
- Support multi-account and multi-location access when needed

## How to get started

1. Create a user
   - See: [Create User Accounts](./create-user-accounts)
2. Add the user to an account
   - See: [Add a User to an Account](./add-a-user-to-an-account)
3. Configure permissions
   - See: [Configure User Permissions](./configure-user-permissions)
