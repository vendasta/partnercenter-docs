---
title: Add a User to an Account
sidebar_label: Add a User to an Account
sidebar_position: 3
description: Add an existing or new user to a business account for Business App access.
---

To add a user to an account:

1. Go to `Partner Center > Accounts > Manage Accounts`.
2. Open the account and go to `Users`, then select `Add users`.
3. Select an existing user or create a new user and confirm.
