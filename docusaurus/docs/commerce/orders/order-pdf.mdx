# Order PDF

Admin users can download a PDF summary of any sales order. The PDF captures the full order at a point in time, making it useful for record-keeping, contract storage, and auditing.

:::info Admin only
Order PDF is available to admin users only.
:::

## What the PDF includes

- **Order details** — order number, status, salesperson name and email address, and the business name
- **Line items** — each product and edition with retail price and quantity
- **Retail summary** — a pricing summary across all line items
- **Order questions** — answers to any order-level questions, if present
- **Order form answers** — completed fulfillment form fields for each line item
- **Customer agreements** — if the order was sent for customer approval, the agreement section includes the approving user's name
