The CRM File Upload feature allows you to upload files directly to contact and company records, with AI-generated summaries to help you quickly understand file contents. This feature streamlines document management and keeps all relevant files organized within your CRM records.

## Why use File Upload?

Keep all client documents and communications in one place by uploading files directly to CRM records. AI-generated summaries help you quickly understand file contents without opening each document, saving time and improving organization.

## What's included

- **[CRM File Upload](./crm-file-upload.mdx)**: Complete guide to uploading files, viewing AI summaries, and managing files in CRM records

## Get started

1. **Navigate to a CRM record**
   - Go to `Partner Center` → `CRM` → `Contacts` or `Companies`
   - Select a contact or company record

2. **Upload a file**
   - Click the file upload option in the record
   - Select a file from your device
   - Wait for AI summary generation

3. **Review AI summary**
   - View the automatically generated summary
   - Use the summary to quickly understand file contents
   - Access the full file when needed

4. **Manage files**
   - View all files associated with a record
   - Download or delete files as needed
   - Organize files by type or date

## Common workflows

**Document Management**: Upload client documents, contracts, or communications to CRM records, review AI summaries for quick reference, and keep all files organized in one place.

**File Organization**: Associate files with specific contacts or companies, use AI summaries to quickly scan document contents, and maintain a complete record of all client interactions and documents.
