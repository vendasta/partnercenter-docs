## Overview

Upload files, including PDFs, images, documents, spreadsheets, and more, and associate them with any `Contact`, `Company`, or `Opportunity` in CRM. After upload, an AI-generated summary of the file content appears automatically.

---

## Why it matters

- **Improves context and organization**  
  Files are properly linked to CRM objects for easier access and review.

- **Enhances file discoverability**  
  AI-generated summaries help you understand the contents at a glance, without needing to open the file.

- **Enables automated file collection**  
  Support for form-based file uploads allows prospects to submit documents directly through lead capture forms, automatically organizing files in CRM with AI summaries.

---

## Where to find it

This feature is available in both **Partner Center** and **Business App**.

- Navigate to any `Contact`, `Company`, or `Opportunity` record
- Open the `Files` section to view or upload

## How to upload a file in CRM

**Steps (Partner Center and Business App):**

1. Open a CRM record (Contact or Company in Partner Center; Contact, Company, or Opportunity in Business App)
2. Go to the `Files` section
3. Click `Add a file`
4. Upload a supported file (e.g., PDF, PNG, JPEG)
5. After upload, an AI-generated summary appears automatically

![Add file](./img/add-file.jpg)

:::info
Business App supports file uploads to `Opportunity` records in addition to Contacts and Companies.
:::
---

## How to upload a file when logging an activity

**Steps:**

1. Navigate to a `Contact` or `Company` record
2. Click on the activity logger (`Log Activity`)
3. Click `Add a file`
4. Upload a supported file
5. Log the activity

![Add file to activity](./img/activity-add-file.jpg)

Uploaded files will appear in:
- The `Files` section
- The activity timeline under the associated log

## How to upload files via forms

You can enable file uploads directly through CRM Forms, allowing prospects and clients to submit documents during form submissions.

**Steps to set up form file uploads:**

1. Navigate to `Marketing` → `Forms` 
2. Create a new form or edit an existing form
3. In the form builder, click `Add fields` 
4. Search for `File` and select the file upload field type
5. Drag the file field to your desired location in the form
6. Configure the field settings:
   - Set field label (e.g., "Upload Document", "Attach Resume")
   - Add help text for your clients
   - Configure visibility settings (optional)
7. Click `Save` to add the field to your form

**When forms are submitted with files:**
- Files are automatically attached to the created Contact and Company records
- AI-generated summaries are created for each uploaded file
- Files appear in the `Files` section of the respective CRM records
- Form submissions trigger normal automation workflows with file data included

**Use cases for form file uploads:**
- **Lead qualification forms**: Allow prospects to upload RFPs, requirements documents, or business plans
- **Application forms**: Enable file submissions for job applications, vendor applications, or partnership requests  
- **Support requests**: Let customers attach screenshots, logs, or documentation with support tickets
- **Onboarding forms**: Collect necessary documents during customer onboarding processes
- **Quote requests**: Allow prospects to upload specifications, blueprints, or requirement documents

## Frequently asked questions (FAQ)

<details>
<summary>What file types support AI-generated summaries?</summary>

AI summaries are supported for the following file types:  
- **Images**: PNG, JPEG  
- **Documents**: PDF, DOC, DOCX, TXT, MD  
- **Spreadsheets**: XLS, XLSX, CSV  
- **Presentations**: PPT, PPTX  
</details>

<details>
<summary>Is this feature available in both Partner Center and Business App?</summary>

Yes.  
- Partner Center: Contacts and Companies  
- Business App: Contacts, Companies, and Opportunities  
</details>

<details>
<summary>Can I upload multiple files at once?</summary>

No. Only one file can be uploaded at a time.
</details>

<details>
<summary>Can I delete or replace an uploaded file?</summary>

Yes. You can delete files directly from the `Files` section. Uploading a new version will generate a new AI summary.
</details>

<details>
<summary>How long does it take to generate the AI summary?</summary>

Summaries typically appear within a few seconds after uploading, depending on file size and format.
</details>

<details>
<summary>Where do uploaded files appear in CRM?</summary>

Files show up in the `Files` section of the record (Contact, Company, or Opportunity), and under any associated activity if uploaded during logging.
</details>

<details>
<summary>Does uploading a file during activity logging associate it with the CRM record?</summary>

Yes. The file will be linked to the relevant Contact or Company and visible in both the activity and file sections.
</details>

<details>
<summary>Can I search for files by the content of the AI summary?</summary>

Summaries are not searchable.
</details>

<details>
<summary>Can I edit or customize the AI-generated summary?</summary>

No. Summaries are generated automatically and cannot be manually edited.
</details>

<details>
<summary>Are uploaded files public or private?</summary>

You can choose the file's visibility before upload:

- **Private**: Only you and authorized users can access the file.
- **Public**: Anyone with the file link can access it, even without CRM access.
</details>

<details>
<summary>How do form file uploads work?</summary>

Yes! You can now include file upload fields in CRM Forms. When visitors submit forms with files, the files are automatically attached to the created Contact and Company records with AI-generated summaries.

**How it works:**
1. Add a "File" field type to any form using the form builder
2. Configure the field label and help text for users
3. When forms are submitted, uploaded files are attached to the CRM records
4. AI summaries are automatically generated for all supported file types

**Key features:**
- **Supported file types**: Images (PNG, JPEG), Documents (PDF, DOC, DOCX, TXT, MD), Spreadsheets (XLS, XLSX, CSV), Presentations (PPT, PPTX)
- **Single file per field**: Each file upload field accepts one file per submission
- **Automatic organization**: Files appear in the `Files` section of Contact and Company records
- **AI summaries**: Generated automatically for easy file identification and searchability
- **Integration with automation**: File uploads can trigger automation workflows and be used in follow-up processes
- **Visibility control**: Files follow standard CRM visibility rules (private/public access)

**Common use cases:**
- Lead qualification documents (RFPs, requirements)
- Job applications and resumes  
- Support tickets with attachments
- Onboarding documentation
- Quote request specifications

</details>

<details>
<summary>What happens if I upload an unsupported file type?</summary>

Unsupported files do not upload, or upload without generating a summary.
</details>

<details>
<summary>Can I automate actions based on uploaded files?</summary>

Not at this time.
</details>

<details>
<summary>Is there a file size limit for uploads?</summary>

Yes, 10.0 MB max file size, up to 5 images, and the supported files types include PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX, TXT, CSV, MD files.
</details>
