# Ad Planner

Ad Planner lets you build advertising campaign proposals for your clients directly in Partner Center. Proposals can be created in Partner Center or MatchCraft.

## Preview a shareable plan

The **Preview Shareable Plan** link in the bottom-left of the campaign proposal page footer lets you view the client-facing version of a proposal without leaving the page. Clicking it opens the client-facing shareable plan in a new tab.

:::note
**Preview Shareable Plan** is disabled when unsaved changes are present. Save your changes to enable the link.
:::
