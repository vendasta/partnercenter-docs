## What is Book Appointments?

Book Appointments is a capability within the Chat Receptionist that allows the AI Workforce to schedule meetings using your Vendasta Calendar link. You can use either a personal, team, or service menu booking link.

## Why is Book Appointments important?

This feature helps convert user intent into scheduled meetings in real time, reducing drop-off and enabling seamless engagement. The AI can respond directly to booking cues, collect necessary details, and finalize the appointment within the conversation.

## What’s Included with Book Appointments?

When enabled, the feature includes:

- Support for personal, team, or service menu Vendasta Calendar links
- Real-time calendar availability lookups
- Dynamic meeting slot suggestions
- In-chat confirmation of bookings
- Optional integration with lead capture

## How to Set Up Book Appointments

![Booking Capability Configuration](./img/crm/my-meetings/book-with-ai.png)

1. Go to `AI Workforce` → `Chat Receptionist` → `Add a capability`.
2. Select `Book appointments in calendar`.
3. Select your Calendar link:
   - Use a **personal** link for individual meetings.
   - Use a **team** link for shared calendars.
   - Use a **service menu** link to give the assistant multiple service options to choose from.

:::info
You can switch between personal, team, or service menu links depending on your scheduling needs.
:::

## How Booking Works in Conversations

Once the `Book appointments` capability is active:

- The assistant listens for user interest in scheduling a meeting.
- It prompts the user to choose a preferred time.
- It checks availability via Vendasta Calendar and presents open time slots.
- The assistant collects necessary details (name, email, and phone if required).
- It confirms the booking within the conversation.

## Using a Service Menu

A service menu allows the AI to choose between multiple calendar links based on the user’s inquiry. Each service in the menu can be tied to a different booking link, enabling the AI to route users to the appropriate meeting type automatically.

### Benefits of the Service Menu:

- Handles multiple services or staff types
- Enables smarter booking decisions
- Reduces manual link management

## Frequently Asked Questions (FAQs)

<details>
<summary>How does "Book Appointment" work?</summary>

When enabled, the AI detects user intent to schedule a meeting and suggests available time slots using your Vendasta Calendar link.
</details>

<details>
<summary>What if "Lead Capture" is also enabled?</summary>

The AI will first gather contact information—name, email, and phone—before completing the booking. This helps preserve leads even if the user exits before scheduling.
</details>

<details>
<summary>What if "Lead Capture" is turned off?</summary>

Only the essential booking details will be collected, based on the requirements of your calendar setup.
</details>

<details>
<summary>Will it ask for a phone number twice?</summary>

No. If the assistant already collected a phone number, it won't ask again.
</details>

<details>
<summary>Can I use different links for different receptionists?</summary>

Each receptionist can be configured with its own booking link by updating its capability settings.
</details>

<details>
<summary>What if I change my Vendasta Calendar link?</summary>

Update the link in the `Configure` panel under the receptionist's settings to reflect the new URL.
</details>

<details>
<summary>Does it support group bookings?</summary>

Yes, if your team Vendasta Calendar link supports group bookings, the assistant will follow the same flow.
</details>

<details>
<summary>What happens if no time slots are available?</summary>

The assistant will notify the user and prompt them to try again later or provide an alternative.
</details>

<details>
<summary>Is timezone handled automatically?</summary>

Yes. Time zone adjustments are managed by Vendasta Calendar and reflected in the slot suggestions.
</details>

<details>
<summary>Can users reschedule via the assistant?</summary>

Not currently. Users must use the rescheduling options provided in the booking confirmation email.
</details>
