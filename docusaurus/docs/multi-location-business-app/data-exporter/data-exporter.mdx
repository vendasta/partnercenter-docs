Users of the Multi-Location Business App can export review, NPS, listing, or Google Business Profile data to a CSV, to allow flexibility in workflows, auditing, and internal reporting for many locations.

In Multi-Location Business App, go to **Data Exporter** in the left navigation menu. In **Data source**, choose one of the available export types:

- **All reviews**
- **Review summary by source**
- **Net Promoter Score (NPS)**
- **Google Business Profile summary**
- **Listing data**

After you select a data source, set any filters you need and then select **Export data to CSV**.

## Export NPS data

Select **Net Promoter Score (NPS)** in the data source dropdown to export NPS data to CSV.

NPS exports include a page-level filter so you can export data for the same page context used in NPS reporting.

Like review exports, NPS exports support filters to narrow the dataset before exporting.

The exported CSV includes NPS-specific columns, such as score classification (promoter, passive, detractor), score value, feedback details, and related location data.

## Configuration

The Data Exporter can be enabled or disabled on a group-by-group basis for all users:

1. In Partner Center, go to **Accounts** and open [Multi-location Groups](https://partners.vendasta.com/brands/manage?marketId=default).
2. Select a group.
3. Open **Features**.
4. Toggle **Data Exporter** on or off.
