# Legacy products overview

This section contains documentation for legacy products that are no longer actively sold or supported in the Vendasta Marketplace. These pages are maintained for historical reference and to assist partners who may still have active legacy product subscriptions.

## Why is this section here?

Legacy product documentation helps partners understand older products they may still be using or need to migrate away from. While these products are no longer available for new purchases, the documentation remains accessible for reference and migration planning.

## What's included

- **[General Legacy Products](./general/index.mdx)**: Documentation for general legacy products and features
- **[CalendarHero](./calendarhero/index.mdx)**: Legacy calendar and scheduling product documentation

## Important notes

:::warning Legacy Products
The products documented in this section are legacy and no longer available for new purchases. If you're currently using these products, consider migrating to current platform alternatives.
:::

For current product offerings, please refer to:
- **Marketplace** for available products and services
- **Product Documentation** in relevant sections (CRM, Marketing, etc.)
