# Getting started overview

Welcome to Vendasta! This section provides everything you need to get started with the platform, from understanding the core concepts to setting up your first workflows. Whether you're new to the platform or looking to expand your knowledge, these guides will help you succeed.

## Why start here?

Get oriented quickly with structured learning paths that take you from platform basics to advanced features. These guides eliminate the guesswork and help you avoid common pitfalls, ensuring you're set up for success from day one.

- **[Introduction to Vendasta](./intro-to-vendasta/vendasta-platform-overview.mdx)**: Understand the platform environments, trials, and continued learning resources

- **[Getting Started Guides](./getting-started-guides/index.mdx)**: Step-by-step guides for Partner Center, Vendasta Services, and Task Manager

## Get started

1. **Understand the platform**
   - Read the [Introduction to Vendasta](./intro-to-vendasta/vendasta-platform-overview.mdx) to learn about platform environments
   - Understand the difference between Partner Center, Business App, and Task Manager
   - Review trial limitations and subscription features

2. **Complete onboarding**
   - Schedule your free onboarding session with an Onboarding Specialist
   - Set up team roles, permissions, and salesperson profiles
   - Configure payment settings and branding

3. **Follow getting started guides**
   - Use the [Partner Center Getting Started Guide](./getting-started-guides/partner-center-getting-started-guide.mdx)
   - Learn about [Vendasta Services](./getting-started-guides/getting-started-with-vendasta-services.mdx) if using fulfillment
   - Set up [Task Manager Projects](./getting-started-guides/getting-started-with-projects-in-task-manager.mdx) for team collaboration

4. **Explore platform features**
   - Review documentation for CRM, Marketing, Commerce, and other sections
   - Set up your first automation or campaign
   - Configure AI employees and capabilities

## Platform environments

The Vendasta platform consists of three main environments:

- **Partner Center**: For administrators and salespeople to manage clients, products, and operations
- **Business App**: Client-facing dashboard where customers access products and services
- **Task Manager**: Fulfillment workspace for managing projects and team collaboration

Understanding how these environments work together is key to using the platform effectively.
