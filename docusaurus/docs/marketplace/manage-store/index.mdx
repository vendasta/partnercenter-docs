# Manage Store overview

Store Setup & Configuration is where you build and customize your Marketplace store. Your store is the primary interface for customers, so proper setup and configuration are critical for sales success.

## Why use Store Management?

A well-configured store drives better business results including direct customer purchases without sales intervention, brand consistency across all touchpoints, revenue growth through optimized design, scalability with automated processes, and improved customer satisfaction through intuitive navigation.

## What's included

- **[Store Setup & Configuration](./store-setup-configuration.mdx)**: Complete guide to setting up, configuring, and customizing your Marketplace store
- **[Shopping Cart & Payment Processing](./shopping-cart-payment-processing.mdx)**: Configure shopping cart functionality and payment processing
- **[Store Sharing & Customer Experience](./store-sharing-customer-experience.mdx)**: Optimize how customers discover and interact with your store

## Get started

1. **Navigate to Store Management**
   - Go to `Partner Center` > `Marketplace` > `Manage Store`
   - Review current store configuration

2. **Configure store basics**
   - Set up store theme and branding
   - Organize products into categories
   - Configure currency and payment settings

3. **Customize store appearance**
   - Customize visual theme and colors
   - Arrange products and packages
   - Configure store layout and navigation

4. **Set up payment processing**
   - Configure shopping cart settings
   - Set up payment methods
   - Test checkout process

## Common workflows

**Store Setup**: Configure store theme, organize products by category, set currency and payment methods, and customize store appearance.

**Store Optimization**: Arrange products strategically, create custom categories, optimize product visibility, and improve customer navigation.

**Payment Configuration**: Set up shopping cart, configure payment processing, test checkout flow, and ensure secure payment handling.
