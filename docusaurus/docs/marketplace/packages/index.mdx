# Packages overview

Packages let you bundle products and services into value-based combinations at different price points. Use Packages to design, price, and present complete solutions that appeal to a range of customers and maximize revenue.

## Why use Packages?

Package-based selling provides strategic benefits including efficient distribution, enhanced branding as a comprehensive solution provider, substantially higher average order values and profit margins, simpler customer decisions, and clear growth paths with natural upgrade opportunities.

## Get started

1. **Navigate to Packages**
   - Go to `Partner Center` > `Marketplace` > `Packages`
   - Review recommended packages or create custom bundles

2. **Create a package**
   - Click `Create Package` or use a recommended package
   - Select products to include in the bundle
   - Set bundle pricing and marketing materials

3. **Configure package settings**
   - Set retail pricing for the package
   - Configure market availability
   - Add marketing descriptions and value propositions

4. **Publish to store**
   - Review package details and preview
   - Publish to make available in your store
   - Share package links with customers

## Common workflows

**Package Creation**: Select products for bundle, set bundle pricing, create marketing materials, configure market availability, and publish to store.

**Package Management**: Edit published packages, organize packages in store, create shareable links, archive unused packages, and monitor package performance.

**Recommended Packages**: Browse Vendasta-curated packages, customize contents and pricing, assign to markets, and leverage proven combinations for customer value.
