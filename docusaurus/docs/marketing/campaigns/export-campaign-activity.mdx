## What is campaign activity export?
Campaign activity export lets you download the results shown in a campaign’s activity table, such as delivered, opened, clicked, bounced, or unsubscribed events. You can use filters to narrow the results before exporting.

## Why is campaign activity export important?
- Share results with your team
- Analyze performance outside the platform
- Combine data with other tools for deeper insights

## What’s included
The export contains the rows currently visible in the campaign activity table after you apply filters. The columns match what you see in that view.

:::warning
There is a hard limit of 10,000 rows per export. If your campaign has more than 10,000 matching records, the export includes only the first 10,000 rows that are visible in the table.
:::

## How to export campaign activity
1. Open the email campaign you want to review.
2. In the activity table, optionally use the `Email activity` filter (for example, set it to `Opened` to export only opens).
3. Select `Export` to download the file.

## Handle large datasets (over 10,000 rows)
If you need to export more than 10,000 results, use one or more of these options:

- Filter to reduce the result set below 10,000, then export. Depending on the table, you may be able to filter by `Email activity` (for example, `Opened` or `Clicked`).
- Export in multiple batches when additional filters are available (for example, by time range), and combine the files in a spreadsheet tool. Use a de-duplicate function to keep only unique rows if needed.
- If the table does not offer the filters you need and you cannot get below 10,000 results, submit a support request to ask for a full export.

:::info
Filter availability varies by view. Some campaign activity tables include only the `Email activity` filter. Date, user, or account filters may not be available.
:::

## Frequently Asked Questions (FAQs)

<details>
<summary>What is the maximum number of rows I can export?</summary>
You can export up to 10,000 rows per export from the campaign activity table.
</details>

<details>
<summary>Does the 10,000-row limit apply to all campaign activity exports?</summary>
Yes. The limit applies to exports from the campaign activity table across campaigns.
</details>

<details>
<summary>Can I export only contacts who opened an email?</summary>
Yes. Use the `Email activity` filter and set it to `Opened` before you export.
</details>

<details>
<summary>Why don’t I see results 10,001–20,000 in the exported file?</summary>
Exports include only the first 10,000 rows visible in the activity table. There is no in-platform pagination for exporting beyond this limit.
</details>

<details>
<summary>Can I filter the export by date range, account, or user?</summary>
Filter availability varies. Some campaign activity tables only include the `Email activity` filter and do not provide date, account, or user filters.
</details>

<details>
<summary>How can I export more than 10,000 rows?</summary>
Reduce the results using available filters and export multiple batches. If you cannot get below 10,000 due to limited filters, submit a support request to ask for a full export.
</details>

<details>
<summary>What data appears in the exported file?</summary>
The export matches the rows and columns displayed in the campaign activity table at the time of export.
</details>

<details>
<summary>Can I remove duplicates after exporting multiple batches?</summary>
Yes. Use your spreadsheet tool’s de-duplicate function to keep only unique rows.
</details>
