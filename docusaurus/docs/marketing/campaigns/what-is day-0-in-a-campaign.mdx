# What is “Day 0” in a campaign?

“Day 0” refers to the moment a campaign begins sending emails.

If you select **Day 0** when publishing a campaign, the first email will be sent **immediately**, as long as the **Included Days** settings allow delivery on that day (e.g., weekdays only, etc.).
