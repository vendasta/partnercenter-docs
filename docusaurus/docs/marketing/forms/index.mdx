Forms let you capture leads, qualify prospects, and trigger automated follow-ups from any website that lets you embed HTML code. Start with pre-built templates, customize with AI-generated styling, and connect to your CRM, email campaigns, and more.

## What you can build

- **Lead generation forms**: Capture contact information that automatically creates CRM records. Use templates for business leads, newsletter signups, or consultation requests.
- **Intake and qualification forms**: Collect detailed information with file uploads, conditional logic, and multi-step flows. Perfect for quotes, demos, or document collection.
- **Interactive forms with automations**: Trigger email campaigns, assign sales reps, create tasks, or start workflows when forms are submitted.

## Quick start guide

1. Go to **Marketing → Forms**
2. Click **Create form** and choose a template (Lead Generation works great for most cases)
3. Add or customize fields using the drag-and-drop builder
4. Style your form with AI or custom CSS
5. Set up automations to handle submissions
6. Embed on your website or share a direct link

## Field types and form building

Forms support different field types that map to your CRM:

- **Contact fields**: Information that attaches to the contact record (name, email, phone)
- **Company fields**: Business information (company name, industry, size)
- **Element fields**: Non-interactive content like instructions or dividers
- **Generic fields**: Information that doesn't map directly to CRM fields. This includes all common field types (eg. Text, Number...) and also allows you to add file upload fields.

### Advanced field features
- **Hidden fields**: Capture attribution data without showing to users
- **Dynamic fields**: Populate from URL parameters (like `?campaign=summer-promo`)
- **UTM tracking**: Automatically captures standard UTM parameters
- **File uploads**: Attach documents that get AI-summarized and stored in CRM

## Form settings and publishing

Configure how your form behaves:
- **Redirect after submit**: Send users to a thank-you page or custom URL
- **Conversations integration**: Create conversation threads from form submissions
- **Spam protection**: Enable reCAPTCHA to block automated submissions
- **Embed options**: Copy HTML code or get shareable links

## Integration and automation

Connect forms to your entire workflow:

- **CRM integration**: Auto-create contacts and companies
- **Email campaigns**: Trigger welcome sequences or nurture flows
- **Team assignments**: Auto-assign leads to salespeople
- **Task creation**: Generate follow-up work items
- **Webhooks**: Send data to external systems
- **Analytics**: Track submissions in Google Analytics

## Frequently asked questions

<details>
<summary>What field types should I use?</summary>

Use **Contact** and **Company** fields for CRM data, **Generic** fields for custom information, and **Element** fields for instructions or organization.

</details>

<details>
<summary>How do I prevent spam submissions?</summary>

Enable reCAPTCHA in Form settings. See [reCAPTCHA setup](./recaptcha-key.mdx) for complete instructions.

</details>

<details>
<summary>Can I customize the form appearance?</summary>

Yes! Use Design with AI for quick styling, or write custom CSS for full control. Forms are mobile-responsive by default.

</details>

<details>
<summary>Are forms mobile-responsive?</summary>

Yes. Forms are responsive by default and work great on all devices. You can further refine the mobile layout using Custom CSS or the Design with AI assistant. See [Styling forms with CSS](./style-form-with-css.mdx#7-mobile-responsiveness) for mobile-specific styling examples.

</details>

<details>
<summary>What happens to uploaded files?</summary>

Files attach to the created contact/company record and get AI-generated summaries for easy review.

</details>

<details>
<summary>How do I track form performance?</summary>

Forms auto-capture UTM parameters. For detailed analytics, see [GA4 tracking](./tracking-form-submissions-ga4.mdx).

</details>
