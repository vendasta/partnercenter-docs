Forms let you capture information on any website and kick off the right follow‑ups automatically. Start from a template, add the fields you need (including file upload), style with AI, and publish in minutes.

## Quick start

1. Go to Marketing → Forms
2. Click Create form
3. Choose a template (for example, Lead Generation) and select "Use template"
4. Open the Automations tab to review/finish setup (for example, attach a campaign) and toggle it on
5. Publish by copying the embed or share link

## Key features

- Templates: Start faster with prebuilt options, including a Lead generation template
- Sections: Organize longer forms into logical groups or steps
- File upload: Let visitors attach a single file; uploaded files attach to the created CRM record and get AI‑generated summaries
- Automations: Trigger actions on submit (assign owner, start campaign, create account/snapshot, activate products, notify team)
- Design with AI: Generate on‑brand styles by uploading a reference and prompting AI, then refine under Custom CSS

## Recommended uses

- Lead capture on marketing sites and landing pages
- Intake for quotes, demos, or contact requests
- Document intake via file upload

## Frequently asked questions

<details>
<summary>Where do uploaded files go?</summary>

Files are attached to the Contact and Company created from the submission. An AI summary is generated automatically.

</details>

<details>
<summary>Can I use automations with forms?</summary>

Yes. Use the form’s Automations tab to assign owners, start campaigns, create accounts/snapshots, activate products, and more.

</details>

<details>
<summary>How do I style forms?</summary>

Use Design with AI for a quick starting point, then refine with Custom CSS. See [Styling forms with CSS](./style-form-with-css.mdx).

</details>
