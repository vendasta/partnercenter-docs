Every Business App account with Local SEO active includes a demo of the Conversations AI lead capture web chat on the business's My Listing page, so you can try AI trained on that business's data before activating any paid products.

<iframe src="//www.youtube-nocookie.com/embed/-Gb_fm7BBoc" width="560" height="315" frameBorder="0" allowFullScreen></iframe>

The demo web chat can be configured and trained on custom data.

## How do I use the demo? {#how-to-use-this-demo}

Navigate to Partner Center and create a new account for any service type business. Make sure Local SEO (free) is active on the account.

Go to `Business App` → `Conversations AI Settings` for the account, and click on the `Try now` button on the My Listing Web Chat card. This will open the My Listing page with a web chat already active for the business. The AI can immediately answer basic questions using info from Business Profile.

Additionally, you can return to Conversations AI Settings and reload the page, and you'll see a button to configure the AI web chat. This is where custom knowledge can also be added.

You can demo AI lead capture to clients before activating anything, and it answers questions about that specific business.

## How do I make the chat widget appear on the My Listing page? {#enabling-the-chat-widget-on-the-my-listing-page}

To ensure the chat widget appears on the **My Listing** page, the `Conversations Messages` feature must be enabled in Partner Center.

You can enable this feature by navigating to:

`Partner Center` → `Administration` → `Customize Business App` → `Conversations Messages`

Make sure the `Show this page` option is turned on.

:::note
Even if Local SEO is active and the chat widget is fully configured, the widget will **not** appear on the My Listing page unless the Conversations Messages feature is enabled in this section.
:::

## Frequently asked questions

<details>
<summary>Where do I find the My Listing web chat demo?</summary>

Go to `Business App` → `Conversations AI Settings` for the account and click `Try now` on the My Listing Web Chat card. This opens the My Listing page with the web chat active for the business.

</details>

<details>
<summary>Do I need a paid product to try the demo?</summary>

No. The account only needs Local SEO (free) active. The AI can immediately answer basic questions using info from the Business Profile.

</details>

<details>
<summary>How do I add custom knowledge to the demo web chat?</summary>

Return to Conversations AI Settings and reload the page. A button to configure the AI web chat appears, and you can add custom knowledge there.

</details>

<details>
<summary>Why isn't the web chat appearing on the My Listing page?</summary>

The `Conversations Messages` feature must be enabled. Go to `Partner Center` → `Administration` → `Customize Business App` → `Conversations Messages` and make sure `Show this page` is turned on.

</details>
