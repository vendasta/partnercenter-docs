The AI-assisted Web Chat Widget in Conversations AI, included in all editions (Standard, Pro, and Premium), lets your clients answer website visitors with AI outside business hours and hand chats off to their team.

:::tip
Have a brand or franchise with one website covering many locations? See the [multi-location web chat widget](/multi-location-business-app/conversations/multi-location-web-chat), which lets visitors choose a location and chat with that location's own AI Chat Receptionist.
:::

## What does the web chat widget do? {#features-of-the-web-chat-widget}

### 24/7 availability with AI
- Answers customer questions outside of business hours
- Uses AI to understand and respond to queries
- Handles frequently asked questions effectively

### Team integration
- Notifies team members of new chats
- Allows team members to join conversations
- Hands conversations over from AI to human agents

### Customer engagement
- Initiates conversations with welcome messages
- Collects customer information for better service
- Supports multimedia messaging (images, attachments)

## Benefits for your clients

- **Faster responses**: Provides immediate responses to your clients' customer inquiries
- **Increased efficiency**: Handles routine queries automatically
- **Extended service hours**: Offers support outside business hours
- **Improved lead generation**: Captures visitor information
- **Team collaboration**: Allows multiple team members to assist customers

## How do I set up the web chat widget for a client? {#getting-started}

To start using the AI-assisted Web Chat Widget for a client:

1. Ensure the client has a Conversations AI subscription (Standard, Pro, or Premium)
2. Install the Web Chat Widget on the client's website
3. Configure the AI assistant with frequently asked questions
4. Set up team notifications for real-time alerts
5. Customize the appearance to match the client's brand

For more details on installation and configuration, please see our dedicated guides in this section.

## Frequently asked questions

<details>
<summary>Is an iframe embed available for Web Chat instead of the JavaScript snippet?</summary>

No. Web Chat supports install via the script snippet only. Iframe embedding is not offered, and the snippet does not work inside a custom iframe. You can whitelist the script on only the pages that need it.

</details>

<details>
<summary>What does a client need to purchase to get web chat?</summary>

The client needs a Conversations AI subscription. The AI-assisted Web Chat Widget is included in all editions: Standard, Pro, and Premium.

</details>

<details>
<summary>Can the Standard edition hand a chat off to a live agent?</summary>

Yes. The web chat widget is included in all Conversations AI editions, including Standard. It notifies team members of new chats and lets them join the conversation to take over from the AI.

</details>

<details>
<summary>How do I get the web chat code for a client's website?</summary>

Web Chat installs on the client's website with a JavaScript script snippet. See the installation guides in this section for the steps.

</details>

<details>
<summary>Does the web chat widget work outside business hours?</summary>

Yes. The AI answers customer questions outside of business hours, including frequently asked questions, and notifies your client's team so they can follow up.

</details>
