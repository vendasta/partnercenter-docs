# Conversations settings

Configure which messaging channels are available in Business App and access each channel’s setup from one place. The settings page shows cards for each channel with a status, quick actions, and a Configure button.

## Available channels in Conversations settings
- Phone & SMS (Pro/Premium) — assign a number and enable AI handling
- Web Chat (Pro) — install and configure the website widget
- Facebook Messenger — connect a verified Facebook Page
- Instagram Messages — connect via Facebook to gain access
- WhatsApp Business Messages — connect via Facebook to gain access
- Email — set sender details and connect
- Messaging templates — create reusable replies
