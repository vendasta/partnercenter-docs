# Integrations Overview

Business App supports various types of integrations that allow you to connect third-party services and automate workflows. This guide covers the different integration types and how to manage them.

## Types of Integrations

### 1. Direct Connections
Direct connections allow you to connect popular services like Google Analytics, Facebook, and QuickBooks directly through the Business App interface.

**To browse and manage direct connections:**
1. Navigate to **Business App > Administration > Connections**
2. Toggle between the **Browse** and **Manage** tabs as needed

![Business App Connections interface](../img/business-app/business-app-connections.png)

**Popular Direct Connections:**
- [Google Analytics (GA4)](/business-app/administration/connecting-google-analytics)
- [QuickBooks](/business-app/administration/connect-quickbooks)
- Google Business Profile
- Google Search Console
- Facebook

### 2. API-Key Based Integrations
API-key based integrations are third-party applications that integrate with the platform using API keys. These integrations can provide additional functionalities such as marketing services, analytics, and more.

**Finding and Connecting API-Key Based Integrations:**

1. Navigate to **Business App > Administration > Connections > Browse**
2. Look for integration cards that display "API-Key Based"
3. Click on an integration to view its marketing page
4. Click **Add Connection** and follow the prompts to configure settings

![Browse tab integration card](../img/api-key-based-integrations/browse-tab-integration-card.png)

**Managing API-Key Connections:**
- View all connections on the **Connections** page
- Monitor connection status indicators:
  - **Connected**: Integration is working properly
  - **Connection Issue**: Problem that needs attention
  - **Pending**: Connection in progress

### 3. SSO-Based Integrations
SSO (Single Sign-On) integrations allow you to connect services using your existing login credentials, providing seamless authentication.

**Setting Up SSO Integrations:**
1. Navigate to the integrations section
2. Select the SSO-based integration you want to connect
3. Follow the authentication prompts
4. Configure data sync and automation settings as needed

### 4. Vendor-Managed Integrations
Vendor-managed integrations are set up and maintained by third-party vendors, requiring minimal configuration from your end.

**Working with Vendor-Managed Integrations:**
- Contact the vendor directly for setup
- Follow vendor-specific documentation
- Monitor integration status through Business App

## Benefits of Integrations

Connecting accounts and services provides several key benefits:

1. **Unified Analytics**: Power analytics in the Executive Report and Marketing Funnel
2. **Automated Workflows**: Set up automated review requests and customer journey automation
3. **Enhanced Services**: Unlock features in Reputation Management, Local SEO, Social Marketing, and Website Pro
4. **Improved ROI**: Provide metrics that prove return on investment

## Troubleshooting Integrations

### Common Issues
- **Authentication Errors**: Re-authenticate your connection
- **Data Sync Issues**: Check permissions and API limits
- **Connection Timeouts**: Verify service availability

### Getting Help
1. Check the specific integration's documentation
2. Contact the third-party service's support team
3. Reach out to Vendasta Support for platform-related issues
