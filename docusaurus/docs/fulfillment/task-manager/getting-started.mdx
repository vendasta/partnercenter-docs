# Getting started with Task Manager

## What is Task Manager?

Task Manager is a project management tool that helps you organize work, track deliverables, and collaborate with team members. You can create projects, assign tasks, set deadlines, and monitor progress across multiple client accounts from a centralized dashboard.

## Why use Task Manager?

- Organize workload into clear projects and tasks
- Track due dates and avoid missed deadlines
- Prioritize important tasks within projects
- Collaborate with team members on shared projects
- Monitor progress across multiple client accounts

## What's included

- **Accounts** – Organize projects by client account for clear visibility.
- **Projects** – Create projects, assign team members, set deadlines, track progress.
- **Tasks** – View assigned tasks in one place; filter by status, due date, and more.
- **Templates** – Pre-built templates for common workflows (some include platform integration).
- **Settings** – Customize permissions, notifications, and workflow preferences.

## How to get started

1. Open **Task Manager** in Business App.
2. Review the dashboard (Projects and Tasks tabs).
3. Click **New Project** to create your first project.
4. Add tasks, assign team members, set due dates and priorities.
5. Use the dashboard to monitor progress and update statuses.

:::warning
You need appropriate permissions to create projects and assign tasks to other team members.
:::
