# Fulfillment overview

The Vendasta fulfillment platform provides comprehensive tools for managing work delivery, team collaboration, and client communication. Built to streamline fulfillment operations, the platform helps you organize projects, assign tasks, track progress, and deliver quality results to your clients efficiently.

## Why use Fulfillment?

Transform your fulfillment operations with powerful project management tools that keep your team organized and your clients informed. The fulfillment platform eliminates communication silos, automates task assignment, and provides visibility into work progress — helping you deliver consistent results and meet deadlines.

## What's included

- **[Task Manager](./open-task-manager/index.mdx)**: Organize projects, manage tasks, and collaborate with your team using Task Manager
- **[Projects](./projects/index.mdx)**: Manage fulfillment projects, communicate with teams and clients, track progress, and generate reports
- **[Users](./users/index.mdx)**: Manage users, groups, notifications, and permissions for team collaboration
- **[Productivity Reports](./report/index.mdx)**: Track team productivity and performance metrics

## Get started

1. **Set up your team**
   - Navigate to `Partner Center` > `Administration` > `My Team`
   - Add team members with Digital Agent role for Task Manager access
   - Configure user groups and permissions

2. **Open Task Manager**
   - Navigate to Task Manager from the main navigation
   - Review the Projects and Tasks tabs
   - Familiarize yourself with the interface

3. **Create your first project**
   - Click `Create Project` in Task Manager
   - Select an account and project type
   - Add tasks and assign team members
   - Set deadlines and track progress

4. **Configure project templates**
   - Create reusable templates for common workflows
   - Set up automated project creation when products activate
   - Customize templates to match your processes

## Common workflows

**Project Delivery**: Create a project from a template, assign tasks to team members, communicate with clients through Business App, and track progress to completion.

**Team Collaboration**: Organize users into groups, assign projects and tasks, set up notifications, and monitor team productivity through reports.

**Client Communication**: Share project updates with clients in real-time, respond to questions and comments, and provide visibility into work progress through Business App integration.
