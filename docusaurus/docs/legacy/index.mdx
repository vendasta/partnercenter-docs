# Legacy Documentation

This section contains documentation for deprecated tools and features that are no longer actively supported or available in the current Vendasta platform. These pages are maintained for historical reference and to help partners understand legacy functionality.

## Why is this section here?

Legacy documentation helps partners who may be transitioning from older features or need to understand historical context. While these features are no longer available, the documentation remains accessible for reference purposes.

## What's included

- **[CalendarHero](./calendarhero/index.mdx)**: Legacy calendar and scheduling product documentation
- **[Customer Voice](./customer-voice/index.mdx)**: Legacy customer feedback and review management system
- **[Proposals](./proposals/index.mdx)**: Legacy proposal builder and management tools

## Important notes

:::warning Deprecated Features
The tools documented in this section are deprecated and no longer available for new implementations. Please refer to current platform documentation for active features and recommended alternatives.
:::

If you're looking for current functionality, please refer to:
- **Commerce** for proposal creation and management
- **Reputation AI Premium** for reviews and NPS (replacement for Customer Voice)
- **Business App** for client-facing features, including scheduling
- **CRM** for customer relationship management
- **Marketing** for email campaigns and lead generation
