## Date unknown — Vendasta managed-services leadership team (vendor evaluation call)

**Source:** [CALL] Vendor demo — Vendasta's internal managed-services/AI-services leadership team evaluating a white-label AI-agent SEO/marketing platform, general AI-agent architecture and terminology

This call is useful primarily for the **general AI-agent vocabulary and design patterns** the vendor uses, independent of their specific product — worth comparing against how Vendasta frames its own AI Workforce concepts:
- **"Human-in-the-loop AI"**: the vendor's default operating mode is that the agent proposes/drafts/does the work but a human must explicitly approve before anything deploys live; the vendor also offers flipping off that approval gate entirely for full autonomy, framed as a dial the user controls rather than a fixed choice.
- **"Playbook"**: a pre-packaged, purpose-built prompt/workflow (the vendor's own analogy: "a prepackaged GPT with custom rules and instructions") that a non-technical user can run with one click without needing to know prompt engineering — e.g., "fix critical on-page SEO issues," "generate a complete backlink strategy." Playbooks are editable (add custom instructions on top of the default) or can be built fully custom by advanced users. This "playbook" pattern — templated, one-click agent workflows with an editable instruction layer underneath — is a useful mental model/vocabulary to borrow when describing how Vendasta's own automation templates or AI Workforce configuration should be explained to partners.
- **"Brand Vault" / knowledge base pattern**: a per-project RAG (retrieval-augmented generation) knowledge base is built by having the AI crawl the client's website (word counts, images, video, page structure) plus any uploaded PDFs/brand guidelines/call transcripts the user supplies. This becomes the single source of truth the AI references across every different tool/workflow run for that client (SEO, content, GBP, etc.) — directly analogous to the "knowledge base" concept used in Vendasta's own AI employee configuration (chat/voice receptionist, reputation specialist).
- **Force-multiplier framing for selling AI to skeptical staff/leadership**: the vendor's pitch line, worth capturing as a reusable sales analogy: "an average, competent SEO contributor who could handle 5 websites the old way can handle 50 the new way without breaking a sweat" — i.e., AI doesn't replace the specialist, it multiplies their throughput on the same portfolio.
- **Audit-trail / ROI-proof pattern**: every action any agent takes is logged, and a downloadable, multi-tab report is available covering (1) a narrative "journey" of work done, (2) time-saved-per-task calculations (translating agent actions into "hours this would have cost a human"), (3) remaining quota/credit balances, and (4) a full user-level action log (which team member ran which task, when, on which page) — useful for both proving ROI to a client and for internal team accountability/performance tracking. A useful framing from the Vendasta team's own discussion during the call: managing AI shifts the human's role from "the one doing the clicking" to a project-manager/QA layer over agent output rather than doing the manual work.
- **AI-visibility / GEO tracking concept**: the vendor has a module that tracks how a brand shows up in LLM answers (ChatGPT, Gemini, Claude, etc.), not just traditional search rankings. For a tracked business, it auto-generates several topics relevant to that business, and under each topic generates a fixed structure of query types: a brand-sentiment query (e.g., "is [business] a legit company"), a competitor-comparison query, and a non-branded/generic query (e.g., "which [product category] is best in 2026"). For any individual query you can drill into visibility-by-LLM-engine, see the full generated LLM response per engine, and see the specific citations/sources that produced that response — giving transparency into *why* an LLM said what it said about the brand. This "AI visibility" concept (sometimes called GEO — generative engine optimization) is a useful term to define clearly in any AI-foundations material, since a partner on the call asked about it unprompted ("does this report include anything about how our website performs on LLMs?").

Because the whole call concerns a third-party vendor being evaluated for a possible marketplace/fulfillment partnership, none of the specific tool names or branded feature names have been carried over here — only the generalizable architecture/vocabulary, which is broadly applicable to describing Vendasta's own AI Workforce concepts.
